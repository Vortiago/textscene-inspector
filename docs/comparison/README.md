# Godot ⇄ TextScene — node comparison sheets

How this previewer renders each Godot node type versus real Godot 4.6.3, from the
same camera. Images are regenerated by `scripts/compare-docs/capture.mjs`; the
browsable gallery is `index.html` (build with `scripts/compare-docs/build-gallery.mjs`).

## 3D

- [AnimationPlayer](sheets/animationplayer.md) — nothing itself; it drives other nodes' properties over time
- [AnimationTree](sheets/animationtree.md) — an empty group (a non-visual driver)
- [Area3D](sheets/area3d.md) — an invisible transform-only group
- [AreaLight3D](sheets/arealight3d.md) — a THREE.RectAreaLight
