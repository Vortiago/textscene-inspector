# Licences of the shader corpus

The files in `shaders/` are test data. The package does not publish them. `corpus.json` names the source and the licence of each file.

- `shaders/generator/`: the text that the material generators of Godot Engine 4.6.3 write. Godot Engine is MIT-licensed, copyright (c) 2014-present Godot Engine contributors, (c) 2007-2014 Juan Linietsky, Ariel Manzur.
- `shaders/demos/`: shaders from [godotengine/godot-demo-projects](https://github.com/godotengine/godot-demo-projects) at commit `b761b4cd`. MIT, copyright (c) 2014-present Godot Engine contributors, (c) 2007-2014 Juan Linietsky, Ariel Manzur.
- `shaders/docs/`: the code blocks that are whole shaders in `tutorials/shaders/` of [godotengine/godot-docs](https://github.com/godotengine/godot-docs) at commit `c5b3485c`. [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/), by Juan Linietsky, Ariel Manzur and the Godot community.
- `shaders/scenes/`: shaders of this repository's fixtures, under this repository's MIT licence.
- `shaders/rejected/`: each one change to a shader above, under the licence of the shader it changes. `corpus.json` names the change.
