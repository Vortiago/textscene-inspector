# Preprocessor and includes

Godot runs its preprocessor on a shader's text before it parses it (`shader_preprocessor.cpp`), and the transpiler runs a port of it (`preprocessor/`). The preprocessor removes the comments, reads each `#` line, writes only the taken branches and expands the macros. Every line keeps its number, so an error names the line of the original text.

When the preprocessor refuses a text, a game does not show the preprocessor's message: `Shader::set_code` hands the text unchanged to the compiler, which refuses it at its first `#` with `Tokenizer: Unknown character #35: '#'`. The transpiler does the same, so its refusal is Godot's.

A caller passes `ShaderOptions` to `transpileShadingLanguage` and `transpileSky`: `file`, the shader's `res://` path, `readInclude`, which answers the text of a `.gdshaderinc` file by its path, and `renderingMethod`, the project's `rendering/renderer/rendering_method`. `CURRENT_RENDERER` is 2 for `forward_plus`, 1 for `mobile` and 0 for `gl_compatibility`, and `forward_plus` when the caller gives none.

`pnpm godot:probes` records the text Godot's preprocessor makes of each probe of this chapter, and a test checks that the port makes the same text, byte for byte. The random programs hold no directive.

Godot 4.6.3-stable (official), probed on llvmpipe (LLVM 20.1.2). Each table shows at most 8 of a probe's rows, picked to show as many mixes of zero, subnormal, normal, infinite and NaN values as fit. The real-GL test (`pnpm test:shaders:gpu`) checks every row, bit for bit, NaN lanes compared as NaN. Generated by `pnpm godot:shader-language`: do not edit by hand.


## Macros

`#define` makes a macro, with or without arguments, and `#undef` removes one. At the end of each line, each macro in name order replaces its first use, pass after pass, until a pass replaces none. So a macro inside a macro expands, and Godot refuses a line that uses one macro 50 times, as the 51st pass ends the expansion with an error. A body stands between two spaces, `##` joins the words either side, and a `\` at a line's end continues the body. A macro made after a line of an include still expands in that line, because the including file expands the include's text again. Godot refuses a second `#define` of one name and `#undef` of `CURRENT_RENDERER` and the other built-in defines.

The transpiler emits `none: the preprocessor writes shading language text`. Rows: `#define`, `#undef`. Godot source: `servers/rendering/shader_preprocessor.cpp:398`.

Every row is native on WebGL 2. WebGPURenderer runs the same nodes and is untested (#1788).

## `#if`, `#elif` and `defined`

`#if` and `#elif` take their branch when the condition is true, and an `#elif` only when no branch before it was taken. Godot first replaces each `defined NAME` and `defined(NAME)` with `true` or `false`, then expands the macros, then runs the text with its Expression class, which the transpiler ports (`godot/expression/`). So a condition can use every Variant operator and constructor, such as `Vector2(1, 2) * 2 == Vector2(2, 4)`. A value is true when it is not its type's zero: `0.0`, `""` and `[]` are false. Godot evaluates an `#elif` after a taken branch too, so its errors still show. A failed operation still leaves a value: `1 / 0` leaves the text `Division by zero error`, so `#if 1 / 0` is true, and only a failure that leaves Nil, such as `"a" + 1`, is refused with `Condition evaluation error.`. Godot keeps the end of the last `defined` operand for a bare name at the end of the text, so `defined(A) || defined B` becomes `true || falsefined B`, which Godot refuses with `Condition evaluation error.`. A condition can call the utility functions too, such as `abs`, `lerp`, `max` and `type_convert`, which the transpiler ports from `variant_utility.cpp` (`godot/variant/utility/`). A refused argument still leaves the value the function returns: `floor("x")` leaves a text, so `#if floor("x")` is true. A random draw is Godot's only after a `seed` earlier in the same shader, because the editor seeds its generator from the clock: `#if str(seed(5))` then `#if randi() == 3066015881` is true, and a draw before any seed is refused with its row and #1828. `hash` gives Godot's `Variant::hash` of every type, so `#if hash("abc") == 193485963` is true. `var_to_str` writes Godot's text of every type, typed arrays and dictionaries included, such as `Array[int]([1])`. `str_to_var` reads Godot's text of every type, so `#if str_to_var("Vector2(1, 2)").x == 1` is true. An `Object(...)` of a class Godot can make, and a `Resource(...)` that names a path or a uid, make a Godot object. The transpiler stops on these with a message that it does not support them yet, and #1953. An `Object(...)` of a class Godot cannot make, a `Resource("")` and a parse fault give null, as in Godot. `var_to_bytes` and `bytes_to_var`, with their `_with_objects` forms, write and read Godot's bytes of every type, NaN sign bits included. `bytes_to_var` stops the same way on an object id other than 0 and on an object of a class Godot can make, after it reads the properties. It refuses a Signal whose object id is not 0, as `instance_from_id` does. A NodePath read from bytes keeps its text, so a name that holds `/` equals the NodePath of that text, where Godot keeps them apart. `weakref` of null or of an object makes a WeakRef object and stops the same way. `weakref` of another type fails Godot's argument check. A condition with an index or a method call is refused with its row and #1828 until the next part of this slice. `rid_allocate_id`, and `instance_from_id` of an id other than 0, answer from the running editor and are refused. A condition that ends Godot with SIGFPE, such as `(-9223372036854775807 - 1) / -1`, is refused.

The transpiler emits `none: the preprocessor writes the taken branch`. Rows: `#if`, `#elif`, `defined`. Godot source: `servers/rendering/shader_preprocessor.cpp:384`.

Every row is native on WebGL 2. WebGPURenderer runs the same nodes and is untested (#1788).

## `#error` and `#pragma`

`#error` refuses the shader, unless it stands in a skipped branch. `#pragma disable_preprocessor` stops the preprocessor: the rest of the text goes to the compiler as it is, so a later `#` line is refused and a macro is not expanded. Godot knows no other pragma.

The transpiler emits `none`. Rows: `#error`, `#pragma`, `#pragma disable_preprocessor`. Godot source: `servers/rendering/shader_preprocessor.cpp:396`.

Every row is native on WebGL 2. WebGPURenderer runs the same nodes and is untested (#1788).

## `#include`

`#include "path"` puts the preprocessed text of a `.gdshaderinc` file in place, between the markers `@@>path` and `@@<path`, which the tokenizer reads to name the include's file and lines in an error. A relative path is relative to the shader's folder. The defines of an include stay for the text after it. A file is included once. Godot refuses a missing file, a cycle and a chain deeper than 25. It finds a cycle by the hash of a file's text, so two files of the same text count as one. An include in a skipped branch is not read.

The transpiler emits `none: the preprocessor writes the included text`. Rows: `#include`. Godot source: `servers/rendering/shader_preprocessor.cpp:402`.

Every row is native on WebGL 2. WebGPURenderer runs the same nodes and is untested (#1788).
