# Uniforms

A uniform is a value the material gives the shader. `transpileShadingLanguage` and `transpileSky` give back `parameters`, one per uniform by name, and `set` takes the value as `ShaderMaterial.set_shader_parameter` takes it, a Godot Variant. `textToVariant` reads one from the text a `.tres` or `.tscn` file holds:

```js
const shader = transpileShadingLanguage('uniform vec4 tint : source_color;\nvec4 probe() { return tint; }');
shader.parameters.get('tint').set(textToVariant('Color(1, 0.5, 0, 1)'));
```

`set(undefined)` gives back Godot's own value. The transpiler fills each uniform as Godot's `update_uniform_buffer` does (`material_storage.cpp:741`): it converts the value to the uniform's type as `_fill_std140_variant_ubo_value` does, and a default as `_fill_std140_ubo_value` does. A uniform the material does not set reads the shader's default. With no default, a `source_color` `vec3` or `vec4` reads opaque black, a matrix reads the identity, and everything else reads zero. An array element the value has no whole element for reads zero, or the identity for a matrix.

Godot's `p_use_linear_color` decides whether a colour goes to linear. It is true for every material but a `canvas_item` one, which converts only in a viewport with `use_hdr_2d`. `TranspileOptions.useLinearColor` sets it for `transpileShadingLanguage`, and a sky always converts (`sky.cpp:193`). The probes run both ways.

An array reaches the shader as the bits of one `uvec4` per column, as std140 lays it out, and the shader reads each lane back from its bits. So a float array whose first value is NaN reaches the shader whole.

Godot 4.6.3-stable (official), probed on llvmpipe (LLVM 20.1.2). Each table shows at most 8 of a probe's rows, picked to show as many mixes of zero, subnormal, normal, infinite and NaN values as fit. The real-GL test (`pnpm test:shaders:gpu`) checks every row, bit for bit, NaN lanes compared as NaN. Generated by `pnpm godot:shader-language`: do not edit by hand.


## Declarations

`uniform type name;` declares a uniform of any value type, with an array size before the name, after it or both, and an optional `= constant` default, which Godot converts to the uniform's type. A precision word is allowed, but not on a bool. Godot refuses an interpolation qualifier, a struct, `void`, a default on an array, a name another uniform, function or built-in has, an assignment to a uniform and a uniform passed as an `out` argument. `global uniform` and `instance uniform` parse, and the transpiler refuses them at their row until they are bound.

The transpiler emits `a `uniform` node of the type, or a `uniformArray` of `uvec4``. Rows: `uniform`. Godot source: `servers/rendering/shader_language.cpp:335`.

Every row is native on WebGL 2. WebGPURenderer runs the same nodes and is untested (#1788).

## `group_uniforms`

`group_uniforms name;` or `group_uniforms name.sub;` puts the uniforms after it in a group of the inspector, and `group_uniforms;` closes it. A group changes no value.

The transpiler emits `none: a group is for the inspector`. Rows: `group_uniforms`. Godot source: `servers/rendering/shader_language.cpp:336`.

Every row is native on WebGL 2. WebGPURenderer runs the same nodes and is untested (#1788).

## Editor hints

`hint_range(min, max, step)` and `hint_enum("a", "b")` tell the inspector how to edit an int or a float. Godot does not clamp the value to the range. A range gets a step of 1 on an int and 0.001 on a float when the text gives none.

The transpiler emits `none: the hint is for the inspector`. Rows: `hint_range`, `hint_enum`. Godot source: `servers/rendering/shader_language.cpp:374`.

Every row is native on WebGL 2. WebGPURenderer runs the same nodes and is untested (#1788).

### Probe `uniform-hint-range-float`, no input

```glsl
uniform float u : hint_range(0, 10, 0.5) = 20.0;
uniform float w : hint_range(-1.0, 1.0);
vec2 probe() { return vec2(u, w); }
```
