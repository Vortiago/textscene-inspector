# Textures

A sampler uniform reads a texture the material gives it. `set` takes a three.js `Texture` where Godot's `set_shader_parameter` takes a `Texture2D`, `Texture3D`, `Texture2DArray` or `Cubemap`, a list of them for a sampler array, or null:

```js
const shader = transpileShadingLanguage('uniform sampler2D albedo : filter_nearest;\nvec4 probe(vec2 uv) { return texture(albedo, uv); }');
shader.parameters.get('albedo').set(texture);
```

The transpiler picks each texture as Godot's `update_textures` does (`material_storage.cpp:880`). A sampler the material leaves unset, or sets to null or NIL, reads Godot's 4 by 4 default texture of its hint and type: `set_shader_parameter` erases a null value. A Variant reads white. An array element the material's list does not reach, or a null element, reads the element before it, or white for the first. A `samplerExternalOES` has no default: while it has no texture, Godot builds no uniform set and does not draw the material. Then `isDrawable` of its parameter is false, and the sky's material is not `visible`.

Godot keeps the filter and repeat on the sampler, and three keeps them on the texture. So each sampler reads its own copy of the material's texture, which shares the texture's image and holds the sampler's filter, repeat and origin. A copy updates before each render after its texture updates. The binding disposes a copy that no element reads any more, or whose texture is disposed. A copy reads the image with Godot's top-left origin. A `source_color` sampler reads the texture through its sRGB view where the material converts colours, as `p_use_linear_color` decides.

Godot 4.6.3-stable (official), probed on llvmpipe (LLVM 20.1.2). Each table shows at most 8 of a probe's rows, picked to show as many mixes of zero, subnormal, normal, infinite and NaN values as fit. The real-GL test (`pnpm test:shaders:gpu`) checks every row, bit for bit, NaN lanes compared as NaN. Generated by `pnpm godot:shader-language`: do not edit by hand.


## Sampler types

A sampler reads a 2D texture, a 2D array, a 3D texture or a cube, of floats, ints (`isampler`) or uints (`usampler`). A sampler can be an argument of a function: the transpiler writes the function once for each set of textures its calls pass.

The transpiler emits a `texture`, `texture3D` or cube texture node per element. ## Default textures

A hint names the texture a sampler reads while the material sets none: `hint_default_black` reads opaque black, `hint_default_transparent` transparent black, `hint_normal` and `hint_roughness_normal` the flat normal (128, 128, 255), and `hint_anisotropy` (255, 128, 255). Every other sampler reads white. A cube and a 3D texture have black, transparent and white only. The roughness hints change nothing the shader reads.

The transpiler emits `a 4 by 4 texture of Godot's texel`. Rows: `hint_normal`, `hint_default_white`, `hint_default_black`, `hint_default_transparent`, `hint_anisotropy`, `hint_roughness_r`, `hint_roughness_normal`. Godot source: `servers/rendering/shader_language.cpp:380`.

Every row is native on WebGL 2. WebGPURenderer runs the same nodes and is untested (#1788).

## Filter and repeat

A filter word and a repeat word set the sampler. A sampler without one takes its shader type's default: `filter_linear_mipmap` and `repeat_enable` for spatial, sky and particles, `filter_linear_mipmap` and `repeat_disable` for fog, and `filter_linear` and `repeat_disable` for canvas_item. A filter without `_mipmap` reads level 0 only, at any level `textureLod` asks for. An anisotropic filter sets an anisotropy of 4, from the project's `anisotropic_filtering_level`. Vulkan and WebGL leave the anisotropic filter to the driver, so its texels can differ from Godot's.

The transpiler emits `the texture's filters, wrap and anisotropy`. Rows: `filter_nearest`, `filter_linear`, `filter_nearest_mipmap`, `filter_linear_mipmap`, `filter_nearest_mipmap_anisotropic`, `filter_linear_mipmap_anisotropic`, `repeat_enable`, `repeat_disable`. Every row is native on WebGL 2. WebGPURenderer runs the same nodes and is untested (#1788).

## Texture functions

`texture` samples at a coordinate, with an optional bias. `textureLod` samples a level, `textureGrad` samples with gradients and `texelFetch` reads one texel of a level. `textureSize` gives the size of a level, and `textureQueryLevels` the level count of the texture. `textureQueryLod` gives the level of detail from the derivatives of the coordinate in texels, as Vulkan defines it. `textureGather` reads one channel of the four texels around the coordinate. A cube gathers on the face the direction picks, and a texel past the edge of the face comes from the next face. A 2D array keeps the layer in the last lane of the coordinate.

The transpiler emits the `sample`, `bias`, `level`, `grad`, `load` and `gather` nodes and `textureSize` of a texture node, a uniform for the level count, and a composite for the level of detail and a cube gather.
