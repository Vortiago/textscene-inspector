# The shading language transpiler

`@textscene/three-godot-shaders` transpiles Godot 4.6.3's shading language to three.js TSL nodes, instruction by instruction. This guide explains each instruction the transpiler reads, with the values Godot gave for it. A text that uses an instruction not transpiled yet fails with an error that names the instruction and the issue that transpiles it.

One Godot version: the previewer draws every project as Godot 4.6.3 draws it. The transpiler reads every shader with the rules of Godot 4.6.3, not of the version a project's `project.godot` names.

768 of 1889 instructions transpiled. [INSTRUCTIONS.md](../INSTRUCTIONS.md) lists every row with its state. Generated by `pnpm godot:shader-language`: do not edit by hand.

A row is one typed form of an instruction, so a name has many rows: 588 operator signatures of 43 operators, 689 overloads of 128 built-in functions, 62 constructor overloads of 15 types, and 302 built-ins, one per shader type and stage that has it.

Godot draws the probes and showcases on Vulkan over lavapipe (`llvmpipe (LLVM 20.1.2)`). The transpilation draws in headless Chromium, WebGL 2 through ANGLE on Vulkan over the same lavapipe, and the run stops when the browser reports another renderer. "Bit-equal" is a claim about that pair. Every probe is bit-equal with Godot. The random programs are bit-equal with Godot except the listed driver and undefined-behaviour cases, each with its cause in [testing.md](testing.md).

## Chapters

- [Types and literals](types-and-literals.md): Value types, Precision words, Float literals, Integer literals, Boolean literals.
- [Arithmetic](arithmetic.md): `+` (OP_ADD), `-` (OP_SUB), `*` (OP_MUL), `/` (OP_DIV), `%` (OP_MOD), Negation `-a` (OP_NEGATE), Steps `++a`, `--a`, `a++`, `a--`.
- [Bit operators](bits.md): `&`, `|` and `^` (OP_BIT_AND, OP_BIT_OR, OP_BIT_XOR), `~a` (OP_BIT_INVERT), `<<` and `>>` (OP_SHIFT_LEFT, OP_SHIFT_RIGHT).
- [Comparison and logic](comparison-and-logic.md): `<`, `<=`, `>` and `>=`, `==` and `!=`, `&&`, `||` and `!`, The conditional operator `c ? a : b`.
- [Constructors and conversions](constructors.md): Vector constructors, Matrix constructors, Scalar conversions, The constructor operator.
- [Swizzles and indexes](swizzles-and-indexes.md): Swizzles, Indexes `a[i]`.
- [Assignments](assignments.md): `=` (OP_ASSIGN), Compound assignments.
- [Functions and statements](statements.md): `return`, Expression statements and `;`, Local variables and `const`, Blocks, `if` and `else`, Loops, `break` and `continue`, `switch`, `discard`, Arrays, Structs, Tree nodes.
- [Functions and calls](functions.md): Calls and overloads, `in`, `out` and `inout`, `void`.
- [How the tests check the transpiler against Godot](testing.md): every operator rule, random programs and a corpus of real shaders.
