# The shader head and the processor functions

A shader opens with `shader_type`, then holds render modes, stencil modes, uniforms, varyings, constants, structs and functions in any order. The processor functions are the functions Godot calls itself: `vertex()`, `fragment()` and `light()` of `spatial` and `canvas_item`, `start()` and `process()` of `particles`, `sky()` and `fog()`. Each one links into a slot of the type's template. A text with no head is read as Godot reads a `canvas_item`, which is how the probes run. The parser keeps Godot's rules and messages for every form below, and a set of whole shaders checks them against Godot's verdicts.

Godot 4.6.3-stable (official), probed on llvmpipe (LLVM 20.1.2). Each table shows at most 8 of a probe's rows, picked to show as many mixes of zero, subnormal, normal, infinite and NaN values as fit. The real-GL test (`pnpm test:shaders:gpu`) checks every row, bit for bit, NaN lanes compared as NaN. Generated by `pnpm godot:shader-language`: do not edit by hand.


## The shader type

`shader_type spatial;` names the type: `spatial`, `canvas_item`, `particles`, `sky` or `fog`. Godot refuses a second head and a head with no `;`, at the line of the type. The type decides which processor functions, built-ins, stage functions, render modes and stencil modes the shader has. Godot's rendering server compiles no shader of a type it does not know, so it shows no message for one. The transpiler refuses it with the message of Godot's shader editor.

The transpiler emits `the functions of the shader, which the template of the type links: the sky template now, and the others with their own slices`. Rows: `shader_type`, `NODE_TYPE_SHADER`, `shader_type spatial`, `shader_type canvas_item`, `shader_type particles`, `shader_type sky`, `shader_type fog`. Godot source: `servers/rendering/shader_language.cpp:340`.

Every row is native on WebGL 2. WebGPURenderer runs the same nodes and is untested (#1788).


## Processor functions

A processor function takes no arguments and returns `void`, and Godot refuses it once it is defined twice. No call reaches it, and its name is no value. Godot refuses `return` anywhere in it. `discard` stands only in `fragment()` and `light()` of `spatial` and `canvas_item`, and in the other functions of those two types. `vertex()` may not reach a derivative function, a stage function or `discard`, in its own body or in a function it calls. A varying that `vertex()` writes before such a use lets the use pass, as in Godot. `particles` and `fog` refuse the derivatives in every function. A stage function such as `texture_sdf` or `emit_subparticle` takes its exact argument types, with no conversion of a constant.

The transpiler emits a TSL `Fn` for each function, which the template calls in its stage. Rows: `NODE_TYPE_FUNCTION`. Godot source: `servers/rendering/shader_language.h:374`.

Every row is native on WebGL 2. WebGPURenderer runs the same nodes and is untested (#1788).


## Render modes

`render_mode unshaded, cull_disabled;` lists modes of the shader type, and a shader may have more than one `render_mode` line. Godot finds a mode by the start of its name, so `unshaded_extra` reads as `unshaded`. Godot refuses a mode of another type, a mode given twice, and two values of one mode such as `blend_mix` and `blend_add`. Each mode is a row of its own, with the template that reads it and the issue that binds it.

The transpiler emits `nothing in the functions: the template of the type reads the modes`. Rows: `render_mode`. Godot source: `servers/rendering/shader_language.cpp:341`.

Every row is native on WebGL 2. WebGPURenderer runs the same nodes and is untested (#1788).


## Stencil modes

`stencil_mode read, compare_less, 5;` lists the stencil modes of a `spatial` shader and one reference value, from 0 to 255. Godot refuses a second reference value, a value past 255, and a stencil mode in another type.

The transpiler emits `nothing in the functions: the template of the type reads the modes`. Rows: `stencil_mode`. Godot source: `servers/rendering/shader_language.cpp:342`.

Every row is native on WebGL 2. WebGPURenderer runs the same nodes and is untested (#1788).


## Global constants

`const float A = 1.5, B = A * 2.0;` outside a function declares constants that every function reads. Each value must be a constant expression, and Godot refuses a sampler, a missing value, a write, and the name of a built-in of the type. A global variable without `const` is refused. GLSL folds a global constant as it folds a local one, so the emitter writes each constant at the start of every function.

The transpiler emits a TSL `Var` at the start of each function, which starts at its value. Rows: `const`. Godot source: `servers/rendering/shader_language.cpp:338`.

Every row is native on WebGL 2. WebGPURenderer runs the same nodes and is untested (#1788).
