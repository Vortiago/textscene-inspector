# Functions and statements

The statements of a function body this slice reads, and the nodes of Godot's tree that its expressions use. Local variables, `if`, loops and the other statements come with the statements slice (#1824).

Godot 4.6.3-stable (official), probed on llvmpipe (LLVM 20.1.2, 256 bits). Each table shows at most 8 of a probe's rows, picked to show as many mixes of zero, subnormal, normal, infinite and NaN values as fit. The real-GL test (`pnpm test:shaders:gpu`) checks every row, bit for bit. Generated by `pnpm godot:shader-language`: do not edit by hand.


## `return`

`return a;` ends the function with the value `a`, of the function's return type. Godot refuses a non-void function with no `return`. A statement after the first `return` never runs.

The transpiler emits `the value of the first return`. Rows: `return`, `FLOW_OP_RETURN`. Godot source: `servers/rendering/shader_language.cpp:361`.

Every row is native on WebGL 2 and on WebGPURenderer.

## Expression statements and `;`
