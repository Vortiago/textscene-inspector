# Calls of constants

A call of a built-in function whose arguments are all constants, such as `sin(vec2(1.5))`, never reaches the GPU in Godot. glslang, the GLSL compiler of Godot, folds the call on the CPU in double precision and rounds the result to a float once (`Constant.cpp`). The transpiler folds the same calls with the same formulas (`glslangCalls.ts`) and writes the result as a TSL constant node. A call that reads a parameter or a variable is not folded on either side.

glslang has its own formulas, and the transpiler keeps them: `round(-2.5)` is -2, `sign(-0.0)` is +0, `sign` of NaN is 1, `min(NaN, 1.0)` is NaN, and `lessThanEqual` of NaN is true. A fold rounds once from double precision, where the GPU rounds after each step, so `length(vec3(0.1, 0.2, 0.3))` and `degrees(1.2345)` differ from the GPU in the last bit.

The browser's compiler folds some of these calls itself, to the same bits, so the probe of such a call is equal without the transpiler's fold too. The transpiler folds every call glslang folds, because another browser's compiler can fold it otherwise or not at all.

Godot 4.6.3-stable (official), probed on llvmpipe (LLVM 20.1.2). Each table shows at most 8 of a probe's rows, picked to show as many mixes of zero, subnormal, normal, infinite and NaN values as fit. The real-GL test (`pnpm test:shaders:gpu`) checks every row, bit for bit, NaN lanes compared as NaN. Generated by `pnpm godot:shader-language`: do not edit by hand.

## Calls glslang leaves to the GPU

glslang folds no call of the hyperbolic functions, `matrixCompMult`, `transpose`, `determinant` or `inverse`, so the GPU computes them. One side's compiler can fold such a call instead, and two kinds of difference follow. Inside the domain, the fold differs from the GPU in the last bits: Godot's driver folds `sinh` and `cosh`, the browser's compiler folds `tanh`, `acosh`, `atanh` and `inverse`, and both fold `asinh`, to other values. Outside the domain, or near the float range, the browser's compiler folds the call to a number where the GPU gives NaN or infinity: `atanh(92.167)`, `acosh(0.866)` and the inverse of a singular matrix to 0, and `cosh(89.152)` to a finite value. Each probe of a constant has a probe of the same value through the parameter, such as `sinh(a + 0.899)` on the input 0. No compiler can fold that one, so it gives the GPU's value on both sides and is bit-equal.

The transpiler emits `sinh(a)`. Rows: `sinh(float)`, `sinh(vec2)`, `sinh(vec3)`, `sinh(vec4)`, `cosh(float)`, `cosh(vec2)`, `cosh(vec3)`, `cosh(vec4)`, `tanh(float)`, `tanh(vec2)`, `tanh(vec3)`, `tanh(vec4)`, `asinh(float)`, `asinh(vec2)`, `asinh(vec3)`, `asinh(vec4)`, `acosh(float)`, `acosh(vec2)`, `acosh(vec3)`, `acosh(vec4)`, `atanh(float)`, `atanh(vec2)`, `atanh(vec3)`, `atanh(vec4)`, `matrixCompMult(mat2,mat2)`, `matrixCompMult(mat3,mat3)`, `matrixCompMult(mat4,mat4)`, `transpose(mat2)`, `transpose(mat3)`, `transpose(mat4)`, `determinant(mat2)`, `determinant(mat3)`, `determinant(mat4)`, `inverse(mat2)`, `inverse(mat3)`, `inverse(mat4)`. - `matrixCompMult(mat3,mat3)`: WebGL 2 lowered: column by column.
- `matrixCompMult(mat4,mat4)`: WebGL 2 lowered: column by column.

The other rows are native on WebGL 2. WebGPURenderer runs the same nodes and is untested (#1788).
