# WI-65: Height Mapping Enable Flag (StandardMaterial3D)

**Status**: Not Started
**Priority**: Medium
**Complexity**: Moderate
**Impact**: Parallax/displacement mapping for depth effects

## Overview

### Problem Statement

Height mapping (parallax mapping) adds depth perception to flat surfaces by offsetting texture coordinates based on a heightmap. Godot's `FEATURE_HEIGHT_MAPPING` requires an enable flag that is currently not implemented.

**Godot Feature**: `FEATURE_HEIGHT_MAPPING` → `heightmap_enabled` in TSCN

**TSCN Format**:
```tscn
[sub_resource type="StandardMaterial3D" id="Material_1"]
albedo_texture = ExtResource("1_albedo")
heightmap_enabled = true
heightmap_texture = ExtResource("2_height")
heightmap_scale = 5.0
heightmap_deep_parallax = false
heightmap_flip_tangent = false
heightmap_flip_binormal = false
heightmap_flip_texture = false
heightmap_min_layers = 8
heightmap_max_layers = 32
```

### Three.js Implementation Challenges

**Option 1: displacementMap** (Requires Geometry)
- Uses `MeshStandardMaterial.displacementMap`
- Requires actual geometry subdivision (not just texture offset)
- May not match Godot's shader-based parallax

**Option 2: Custom Shader** (More Accurate)
- Implements parallax occlusion mapping
- Matches Godot's behavior better
- Requires shader material extension

**Recommendation**: Start with `displacementMap`, document limitations, consider custom shader in future work item.

### 2. Update Parser

**File**: `packages/textscene-core/src/resources/materials/standardmaterial3d/parser.ts`

```typescript
if (properties.heightmap_enabled !== undefined) {
  result.heightmap_enabled = properties.heightmap_enabled === 'true';
}

// Parse heightmap texture
if (registry && properties.heightmap_texture) {
  const heightmapTexRef = ResourceRegistry.parseReference(properties.heightmap_texture);
  if (heightmapTexRef) {
    const texture = await registry.loadTexture(heightmapTexRef);
    if (texture) {
      result.heightmap_texture = texture;
    }
  }
}

// Parse heightmap scale
if (properties.heightmap_scale !== undefined) {
  const scale = parseFloat(properties.heightmap_scale);
  if (!isNaN(scale)) {
    result.heightmap_scale = scale;
  }
}

// Optional: Parse deep parallax flag
if (properties.heightmap_deep_parallax !== undefined) {
  result.heightmap_deep_parallax = properties.heightmap_deep_parallax === 'true';
}
```

### 3. Update Renderer

**File**: `packages/textscene-core/src/resources/materials/standardmaterial3d/renderer.ts`

```typescript
if (properties.heightmap_enabled && properties.heightmap_texture) {
  materialOptions.displacementMap = properties.heightmap_texture;

  // Apply scale if specified, default to Godot's default (5.0)
  if (properties.heightmap_scale !== undefined) {
    materialOptions.displacementScale = properties.heightmap_scale;
  } else {
    materialOptions.displacementScale = 5.0;  // Godot default
  }

  // Note: heightmap_deep_parallax and other flags require custom shader
  // Current implementation uses basic displacement mapping
}
```
