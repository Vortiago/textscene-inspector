# WI-10: Implement SpotLight3D Node

## Overview
Implement parser and renderer for Godot's SpotLight3D node type in the TSCN renderer. SpotLight3D represents cone-shaped lights commonly used for sunrise lighting, focused beams, and dramatic lighting effects.

## Implementation Requirements
- Create parser and renderer in `packages/textscene-renderer/src/nodes/spotlight3d/`
- Parse light_color, light_energy, spot_range, spot_angle, shadow_enabled
- Generate THREE.SpotLight with shadows
- **Frequency**: 15+ instances in hallway scene (sunrise lighting)

## Godot Documentation

### SpotLight3D Properties

**Shadow Mapping Configuration**
```gdscript
# Example of enabling shadows on a SpotLight3D node
var light_node = $SpotLight3D
light_node.shadow_enabled = true

# Shadow settings (tune these for quality vs performance)
light_node.shadow_bias = 0.05 # Adjust to prevent self-shadowing artifacts
light_node.shadow_contact_clean_offset = 0.05 # Further bias for contact points

# Shadow filter can improve quality but costs performance
# Options: SHADOW_FILTER_NONE, SHADOW_FILTER_PCF3, SHADOW_FILTER_PCF5
light_node.shadow_filter = SpotLight3D.SHADOW_FILTER_PCF5
```

**Key Shadow Properties:**
- `shadow_enabled` (bool) - Enable/disable shadow casting
- `shadow_bias` (float) - Prevents self-shadowing artifacts (typical: 0.05-0.1)
- `shadow_contact_clean_offset` (float) - Additional bias for contact points
- `shadow_filter` - Quality vs performance trade-off (NONE, PCF3, PCF5)

**Light Properties:**
- `light_color` (Color) - The color of the light
- `light_energy` (float) - Light intensity/brightness
- `spot_range` (float) - Maximum distance the light reaches
- `spot_angle` (float) - Cone angle in degrees
- `light_attenuation` (float) - How light intensity falls off with distance

## Three.js Documentation

### THREE.SpotLight API

**Constructor and Basic Setup**
```javascript
const color = 0xFFFFFF;
const intensity = 100;
const light = new THREE.SpotLight(color, intensity);
light.castShadow = true;
light.position.set(0, 10, 0);
light.target.position.set(-4, 0, -4);
scene.add(light);
scene.add(light.target);
```

**Key Properties:**
- `color` (Color) - Light color
- `intensity` (float) - Light intensity (in three.js r155+, this is in lumens)
- `distance` (float) - Maximum range of the light (0 = infinite)
- `angle` (float) - Maximum angle of light dispersion in radians
- `penumbra` (float) - Percent of spotlight cone attenuated (0-1)
- `decay` (float) - Amount the light dims along distance (default: 2)

**Shadow Configuration**
```javascript
// Shadow camera configuration
light.shadow.camera.near = 8;
light.shadow.camera.far = 200;
light.shadow.mapSize.width = 256;
light.shadow.mapSize.height = 256;
light.shadow.bias = -0.002;
light.shadow.radius = 4;
```

**Shadow Properties:**
- `light.shadow.camera.near` - Shadow camera near plane
- `light.shadow.camera.far` - Shadow camera far plane
- `light.shadow.mapSize` - Shadow map resolution (width x height)
- `light.shadow.bias` - Shadow bias to prevent artifacts
- `light.shadow.radius` - Shadow blur radius

**Target System:**
SpotLight uses a `target` object to define direction:
```javascript
light.target.position.set(x, y, z);
light.target.updateMatrixWorld();
scene.add(light.target); // Must be added to scene
```

## Implementation Notes

### Property Mapping: Godot → Three.js

| Godot Property | Three.js Property | Conversion |
|---|---|---|
| `light_color` | `color` | Parse Color → hex |
| `light_energy` | `intensity` | Direct mapping (consider three.js units) |
| `spot_range` | `distance` | Direct mapping |
| `spot_angle` | `angle` | Degrees → Radians (angle * π / 180) |
| `shadow_enabled` | `castShadow` | Direct boolean |
| `shadow_bias` | `shadow.bias` | May need sign flip (Godot uses positive, three.js often negative) |

### Key Considerations

1. **Angle Conversion**: Godot uses degrees, three.js uses radians
   ```typescript
   const angleRadians = (godotAngle * Math.PI) / 180;
   ```

2. **Intensity Scaling**: Godot's `light_energy` may need scaling for three.js
   - Consider the scene scale and units
   - three.js r155+ uses physically-based units (lumens for SpotLight)

3. **Target Object**:
   - SpotLight requires a target object to define direction
   - Extract direction from Godot's transform or explicit target
   - Target must be added to scene separately

4. **Shadow Bias**:
   - Godot typically uses positive bias values
   - three.js often uses negative bias
   - Test and adjust for artifact-free shadows

5. **Penumbra**:
   - Godot doesn't have direct equivalent
   - Could derive from spot_angle or leave as default (0.0)
   - Consider making configurable

## Code Examples

### Complete Implementation Pattern
```typescript
// parser.ts
export function isSpotLight3D(node: TscnNode): boolean {
  return node.type === 'SpotLight3D';
}

export function parseSpotLight3D(node: TscnNode): SpotLight3DProperties {
  return {
    light_color: node.properties.light_color || 'Color(1, 1, 1, 1)',
    light_energy: parseFloat(node.properties.light_energy) || 1.0,
    spot_range: parseFloat(node.properties.spot_range) || 5.0,
    spot_angle: parseFloat(node.properties.spot_angle) || 45.0,
    shadow_enabled: node.properties.shadow_enabled === 'true',
    shadow_bias: node.properties.shadow_bias ? parseFloat(node.properties.shadow_bias) : undefined,
  };
}

// renderer.ts
export function createSpotLight3D(
  properties: SpotLight3DProperties,
  transform: Transform3D
): THREE.Group {
  // Parse color
  const color = parseGodotColor(properties.light_color);

  // Create light
  const light = new THREE.SpotLight(color, properties.light_energy);
  light.distance = properties.spot_range;
  light.angle = (properties.spot_angle * Math.PI) / 180;
  light.penumbra = 0.1; // Default, could be configurable

  // Apply transform
  light.position.copy(transform.position);

  // Configure shadows
  if (properties.shadow_enabled) {
    light.castShadow = true;
    light.shadow.camera.near = 0.5;
    light.shadow.camera.far = properties.spot_range;
    light.shadow.mapSize.width = 512;
    light.shadow.mapSize.height = 512;
    if (properties.shadow_bias !== undefined) {
      light.shadow.bias = -properties.shadow_bias; // Note sign flip
    }
  }

  // Create target (calculate from transform rotation)
  const target = new THREE.Object3D();
  const direction = new THREE.Vector3(0, 0, -1);
  direction.applyQuaternion(transform.rotation);
  target.position.copy(light.position).add(direction);

  // Group light and target
  const group = new THREE.Group();
  group.add(light);
  group.add(target);
  light.target = target;

  return group;
}
```
