# WI-59: Normal Map Support (StandardMaterial3D)

**Status**: Not Started
**Priority**: High
**Estimated Effort**: Small Complexity
**Impact**: 2 instances in ld-58 (HallwayGeometry walls/ceiling) - Significant visual quality improvement

## Overview

### Current State

StandardMaterial3D supports albedo textures and PBR properties, but **normal maps are not implemented**:
- ✅ Albedo textures render correctly
- ✅ External texture loading works (WI-52)
- ❌ `normal_enabled` property is ignored
- ❌ `normal_texture` ExtResource is ignored
- ❌ Surfaces lack depth detail that normal maps provide

### Evidence from ld-58

**Example: HallwayGeometry.tscn (lines 18-22)** - Ceiling material with normal map:
```tscn
[ext_resource type="Texture2D" uid="uid://dg1a7d86kdjag" path="res://assets/textures/WhiteRaised_S.jpg" id="3_tljqy"]
[ext_resource type="Texture2D" uid="uid://di1ju6xum75pe" path="res://assets/textures/WhiteRaised_N.jpg" id="4_lehkh"]

[sub_resource type="StandardMaterial3D" id="StandardMaterial3D_tljqy"]
albedo_texture = ExtResource("3_tljqy")
normal_enabled = true
normal_texture = ExtResource("4_lehkh")
uv1_scale = Vector3(0.5, 0.5, 0.5)
```

**Analysis**:
- `normal_enabled = true` activates normal mapping
- `normal_texture` references external normal map file (`WhiteRaised_N.jpg`)
- Albedo and normal textures are separate ExtResources

**Impact**: Only 2 instances in ld-58, but **critical for visual quality**. Ceilings and walls look flat without normal maps.

## Implementation Overview

### Parser Changes

Add normal map properties to StandardMaterial3D:

```typescript
export interface StandardMaterial3DProperties {
  // Existing properties...
  albedo_color?: THREE.Color;
  albedo_texture?: string;

  // NEW: Normal map properties
  normal_enabled?: boolean;
  normal_texture?: string;
}
```

### Renderer Changes

Apply normal map to material:

```typescript
// NEW: Normal map application
if (props.normal_enabled && props.normal_texture) {
  const normalMap = await resolveTextureResource(props.normal_texture, context);
  if (normalMap) {
    material.normalMap = normalMap;
    material.normalMapType = THREE.TangentSpaceNormalMap; // Default in three.js
    logger.info(
      `[StandardMaterial3D] Applied normal map: ${props.normal_texture}`
    );
  } else {
    logger.warn(
      `[StandardMaterial3D] Normal texture not found: ${props.normal_texture}`
    );
  }
} else if (props.normal_enabled && !props.normal_texture) {
  logger.warn('[StandardMaterial3D] normal_enabled=true but no normal_texture specified');
}
```

## Linter Requirements

**Validation Rules**:
1. Warn if `normal_enabled=true` but no `normal_texture` specified
2. Error if `normal_texture` reference doesn't exist
3. Warn if `normal_texture` specified but `normal_enabled=false`

```typescript
const normalMapValidationRule: LintRule = {
  meta: {
    name: 'valid-normal-map',
    description: 'Validates normal map properties on StandardMaterial3D',
  },
  check: (context: LintContext) => {
    const normalEnabled = subResource.properties.normal_enabled === 'true';
    const normalTexture = subResource.properties.normal_texture;

    // Warn if normal_enabled=true but no texture
    if (normalEnabled && !normalTexture) {
      diagnostics.push({
        severity: 'warning',
        message: 'normal_enabled is true but normal_texture is not specified',
      });
    }

    // Validate texture reference exists
    if (normalTexture) {
      const exists = context.resourceExists(normalTexture);
      if (!exists) {
        diagnostics.push({
          severity: 'error',
          message: `Normal texture reference not found: ${normalTexture}`,
        });
      }
    }
  },
};
```
