# WI-64: Label3D Node Support

**Status**: Not Started
**Priority**: Medium
**Estimated Effort**: Medium Complexity
**Impact**: Quality of life - enables text annotations in test fixtures and examples

## Overview

### Current State

Label3D nodes are not implemented:
- ❌ Label3D nodes are parsed but not rendered
- ❌ No text appears in 3D space
- ❌ Cannot annotate fixtures with descriptive labels
- ✅ Generic node parsing handles Label3D without errors (WI-55)

### Use Case

Label3D would be extremely useful for:
- **Annotating test fixtures**: Label each sphere in material-features.tscn with its properties
- **Example scenes**: Add labels explaining what each object demonstrates
- **Debugging aids**: Show node names, positions, or property values directly in the scene
- **Visual documentation**: Self-documenting scenes that explain their own structure

**Example use in material-features.tscn**:
```tscn
[node name="Label_AlbedoOnly" type="Label3D" parent="Row1_Basic/Sphere_AlbedoOnly"]
transform = Transform3D(1, 0, 0, 0, 1, 0, 0, 0, 1, 0, -1.5, 0)
text = "Albedo Only"
pixel_size = 0.01
billboard = 1
modulate = Color(1, 1, 1, 1)
```

## Implementation Overview

### Key Properties

**Essential properties** (minimum viable implementation):
```typescript
export interface Label3DProperties {
  text?: string;                    // The text to display
  pixel_size?: number;               // Size of text in world units (default: 0.01)
  billboard?: number;                // Billboard mode: 0=disabled, 1=enabled, 2=y-axis only
  modulate?: Color;                  // Text color/tint (default: white)
  outline_size?: number;             // Outline thickness (default: 0)
  outline_modulate?: Color;          // Outline color (default: black)
}
```

**Billboard modes**:
- 0: Disabled - text faces forward
- 1: Enabled - text always faces camera
- 2: Y-axis only - rotates around Y to face camera

### Renderer Implementation

Use THREE.Mesh with PlaneGeometry and canvas-rendered text for full billboard mode control:

```typescript
export function createLabel3D(properties: Label3DProperties): THREE.Mesh {
  const text = properties.text || '';
  const pixelSize = properties.pixel_size ?? 0.01;
  const billboardMode = properties.billboard ?? 1; // Default: enabled
  const modulate = properties.modulate || { r: 1, g: 1, b: 1, a: 1 };

  // Create canvas with text
  const canvas = document.createElement('canvas');
  const context = canvas.getContext('2d')!;

  // Set canvas size based on text length
  const fontSize = 128; // High resolution for quality
  context.font = `${fontSize}px Arial`;
  const metrics = context.measureText(text);
  canvas.width = Math.ceil(metrics.width) + 20;
  canvas.height = fontSize + 20;

  // Draw outline if specified
  if (properties.outline_size && properties.outline_size > 0) {
    context.strokeStyle = colorToHex(properties.outline_modulate || { r: 0, g: 0, b: 0, a: 1 });
    context.lineWidth = properties.outline_size * 10;
    context.strokeText(text, 10, fontSize);
  }

  // Draw text
  context.fillStyle = colorToHex(modulate);
  context.font = `${fontSize}px Arial`;
  context.fillText(text, 10, fontSize);

  // Create texture from canvas
  const texture = new THREE.CanvasTexture(canvas);
  texture.needsUpdate = true;

  // Calculate plane dimensions based on pixel_size
  const aspect = canvas.width / canvas.height;
  const width = pixelSize * aspect * 100;
  const height = pixelSize * 100;

  // Create plane geometry and material
  const geometry = new THREE.PlaneGeometry(width, height);
  const material = new THREE.MeshBasicMaterial({
    map: texture,
    transparent: true,
    opacity: modulate.a,
    side: THREE.DoubleSide,  // Visible from both sides
    depthWrite: false,       // Prevent z-fighting with other labels
  });

  const mesh = new THREE.Mesh(geometry, material);

  // Store billboard mode in userData for update loop
  mesh.userData.isLabel3D = true;
  mesh.userData.billboardMode = billboardMode;

  return mesh;
}
```

### Billboard Mode Update System

Billboard behavior is handled in the render loop by updating label rotations each frame:

```typescript
// In SceneRenderer class
class SceneRenderer {
  // ... existing methods ...

  /**
   * Updates all Label3D nodes to face the camera based on their billboard mode.
   * Should be called in the render loop before rendering.
   */
  updateLabels(camera: THREE.Camera): void {
    this.scene.traverse((object) => {
      if (object.userData.isLabel3D) {
        const mode = object.userData.billboardMode as number;

        if (mode === 1) {
          // Full billboard: always face camera
          object.quaternion.copy(camera.quaternion);
        } else if (mode === 2) {
          // Y-axis only billboard: rotate around Y to face camera
          this.updateYAxisBillboard(object as THREE.Mesh, camera);
        }
        // mode === 0: disabled, no rotation applied
      }
    });
  }

  private updateYAxisBillboard(mesh: THREE.Mesh, camera: THREE.Camera): void {
    // Get positions
    const meshPos = mesh.position;
    const camPos = camera.position;

    // Calculate horizontal direction to camera (ignore Y)
    const dx = camPos.x - meshPos.x;
    const dz = camPos.z - meshPos.z;

    // Calculate rotation angle in XZ plane only
    const angle = Math.atan2(dx, dz);

    // Apply only Y-axis rotation
    mesh.rotation.set(0, angle, 0);
  }
}
```

### Integration in Render Loop

Both web previewer and VS Code extension need to call `updateLabels()` in their animation loop:

```typescript
// In apps/textscene-web/src/main.ts and apps/textscene-vscode/src/PreviewPanel.ts
function animate() {
  requestAnimationFrame(animate);
  controls.update();

  sceneRenderer.updateLabels(camera);  // ← Add this line

```

**Benefits of Mesh approach**:
- ✅ Full control over all three billboard modes (0, 1, 2)
- ✅ Same high-quality canvas text rendering
- ✅ Consistent with other node types (everything is a Mesh)
- ✅ Better transform handling with parent nodes
- ✅ More flexible for future enhancements (shadows, lighting)

### Parser Implementation

Extract Label3D properties from TSCN:

```typescript
export function parseLabel3D(properties: Record<string, string>): Label3DProperties {
  const result: Label3DProperties = {};

  if (properties.text) {
    result.text = properties.text.replace(/^"(.*)"$/, '$1'); // Remove quotes
  }

  if (properties.pixel_size) {
    result.pixel_size = parseFloat(properties.pixel_size);
  }

  if (properties.billboard !== undefined) {
    result.billboard = parseInt(properties.billboard, 10);
  }

  if (properties.modulate) {
    result.modulate = parseColor(properties.modulate);
  }

  if (properties.outline_size) {
    result.outline_size = parseFloat(properties.outline_size);
  }

  if (properties.outline_modulate) {
    result.outline_modulate = parseColor(properties.outline_modulate);
  }

  return result;
}
```

## Linter Requirements

**Validation Rules**:
1. Warn if `text` property is empty or missing
2. Warn if `pixel_size` is extremely large (> 1.0) or negative
3. Error if `billboard` value is not 0, 1, or 2

```typescript
const label3DValidationRule: LintRule = {
  meta: {
    name: 'valid-label3d',
    description: 'Validates Label3D node properties',
  },
  check: (context: LintContext) => {
    const text = node.properties.text;
    const pixelSize = parseFloat(node.properties.pixel_size || '0.01');
    const billboard = parseInt(node.properties.billboard || '1', 10);

    // Warn if no text
    if (!text || text === '""') {
      diagnostics.push({
        severity: 'warning',
        message: 'Label3D has no text property',
      });
    }

    // Warn if pixel_size is unusual
    if (pixelSize < 0) {
      diagnostics.push({
        severity: 'warning',
        message: 'Label3D pixel_size is negative',
      });
    } else if (pixelSize > 1.0) {
      diagnostics.push({
        severity: 'warning',
        message: 'Label3D pixel_size is very large (> 1.0)',
      });
    }

    // Error if billboard mode is invalid
    if (![0, 1, 2].includes(billboard)) {
      diagnostics.push({
        severity: 'error',
        message: `Invalid billboard mode: ${billboard} (must be 0, 1, or 2)`,
      });
    }
  },
};
```
