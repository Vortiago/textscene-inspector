# WI-16: ShaderMaterial SubResource

## Overview

Implement support for parsing and rendering Godot's ShaderMaterial as a SubResource type. ShaderMaterial allows custom shader code written in Godot Shading Language (GSL) to be applied to meshes. This work item focuses on parsing shader parameters (uniforms) and mapping them to three.js ShaderMaterial, with initial support for basic uniform types and future extensibility for full shader code conversion.

## Implementation Requirements

From TODO.md Phase 4: Advanced Features:

- Parse ShaderMaterial SubResource from TSCN `[sub_resource]` sections
- Extract shader reference (ExtResource or inline shader code)
- Parse shader parameters (uniforms: colors, floats, vectors, textures)
- Map Godot shader uniforms to three.js ShaderMaterial uniforms
- Support basic uniform types: float, vec2, vec3, vec4, color, sampler2D
- Create three.js ShaderMaterial with appropriate uniforms
- Handle shader parameter hints (source_color, hint_range, etc.)
- Provide fallback materials for unsupported shader features
- Register with ResourceRegistry for material resolution

## Godot Documentation

### ShaderMaterial and Shader Resources

From Context7 research on `websites/godotengine_en_stable`:

ShaderMaterial is a Material subclass that uses custom shader code written in Godot Shading Language (GSL). It provides complete control over how an object is rendered by defining custom vertex, fragment, and light processing functions.

**ShaderMaterial Structure:**

```gdscript
# Create ShaderMaterial in code
var shader_material = ShaderMaterial.new()
shader_material.shader = preload("res://shaders/my_shader.gdshader")

# Set shader parameters (uniforms)
shader_material.set_shader_parameter("tint_color", Color(1.0, 0.5, 0.0))
shader_material.set_shader_parameter("intensity", 2.0)
shader_material.set_shader_parameter("texture_albedo", texture)
```

**TSCN Format for ShaderMaterial:**

```ini
[ext_resource type="Shader" path="res://shaders/custom.gdshader" id="1_abcde"]

[sub_resource type="ShaderMaterial" id="ShaderMaterial_xyz"]
shader = ExtResource("1_abcde")
shader_parameter/tint_color = Color(1, 0.5, 0, 1)
shader_parameter/intensity = 2.0
shader_parameter/metallic = 0.8
shader_parameter/texture_albedo = ExtResource("2_tex")
```

**Godot Shading Language (GSL) - Uniforms:**

Uniforms are variables passed from the CPU (engine) to the GPU (shader). They remain constant across all shader invocations but can be changed per-material.

```glsl
shader_type spatial;

// Color uniform with hint
uniform vec4 tint_color : source_color = vec4(1.0);

// Float uniform with range hint
uniform float intensity : hint_range(0.0, 10.0) = 1.0;

// Texture uniform
uniform sampler2D texture_albedo : source_color;

// Vector uniforms
uniform vec2 uv_scale = vec2(1.0, 1.0);
uniform vec3 offset = vec3(0.0);

void fragment() {
    // Use uniforms in shader
    vec4 albedo_tex = texture(texture_albedo, UV * uv_scale);
    ALBEDO = albedo_tex.rgb * tint_color.rgb * intensity;
}
```

**Uniform Types and Hints:**

| Type | GSL Declaration | Default Value | Notes |
|------|-----------------|---------------|-------|
| Float | `uniform float name` | `0.0` | Single floating-point value |
| Vec2 | `uniform vec2 name` | `vec2(0.0)` | 2D vector |
| Vec3 | `uniform vec3 name` | `vec3(0.0)` | 3D vector |
| Vec4 | `uniform vec4 name` | `vec4(0.0)` | 4D vector or color |
| Color | `uniform vec4 name : source_color` | `vec4(1.0)` | Color with hint |
| Texture | `uniform sampler2D name` | `null` | 2D texture sampler |
| Bool | `uniform bool name` | `false` | Boolean value |
| Int | `uniform int name` | `0` | Integer value |

**Parameter Hints:**

- `:source_color` - Indicates the vec4 represents a color
- `:hint_range(min, max, step)` - Provides UI range for floats
- `:hint_albedo` - Texture is used for albedo
- `:hint_normal` - Texture contains normal map data

**Shader Types:**

```glsl
shader_type spatial;   // 3D shaders for MeshInstance3D
shader_type canvas_item; // 2D shaders for CanvasItem nodes
shader_type particles;   // Particle system shaders
shader_type sky;        // Sky shaders
shader_type fog;        // Volumetric fog shaders
```

For this work item, we focus on `shader_type spatial` for 3D rendering.

## Three.js Documentation

### ShaderMaterial and Custom Shaders

From Context7 research on `/mrdoob/three.js`:

Three.js ShaderMaterial allows complete control over the rendering pipeline by providing custom GLSL vertex and fragment shaders.

**ShaderMaterial Creation:**

```javascript
const material = new THREE.ShaderMaterial({
  uniforms: {
    tint_color: { value: new THREE.Color(1.0, 0.5, 0.0) },
    intensity: { value: 2.0 },
    texture_albedo: { value: textureLoader.load('texture.png') },
    uv_scale: { value: new THREE.Vector2(1.0, 1.0) },
    time: { value: 0.0 }
  },
  vertexShader: vertexShaderCode,
  fragmentShader: fragmentShaderCode,
  lights: true,  // Enable lighting calculations
  transparent: false,
  side: THREE.FrontSide
});

// Update uniforms at runtime
material.uniforms.intensity.value = 3.0;
material.uniforms.time.value = performance.now() * 0.001;
```

**Uniform Types in three.js:**

| Type | three.js Value | Example |
|------|----------------|---------|
| Float | `{ value: number }` | `{ value: 1.5 }` |
| Vec2 | `{ value: THREE.Vector2 }` | `{ value: new THREE.Vector2(1, 2) }` |
| Vec3 | `{ value: THREE.Vector3 }` | `{ value: new THREE.Vector3(1, 2, 3) }` |
| Vec4 | `{ value: THREE.Vector4 }` | `{ value: new THREE.Vector4(1, 2, 3, 4) }` |
| Color | `{ value: THREE.Color }` | `{ value: new THREE.Color(0xff0000) }` |
| Texture | `{ value: THREE.Texture }` | `{ value: texture }` |
| Bool | `{ value: boolean }` | `{ value: true }` |
| Int | `{ value: number }` | `{ value: 5 }` |

**GLSL Shader Example:**

```glsl
// Vertex Shader
uniform vec2 uv_scale;

varying vec2 vUv;

void main() {
    vUv = uv * uv_scale;
    gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0);
}
```

```glsl
// Fragment Shader
uniform vec4 tint_color;
uniform float intensity;
uniform sampler2D texture_albedo;

varying vec2 vUv;

void main() {
    vec4 texColor = texture2D(texture_albedo, vUv);
    gl_FragColor = texColor * tint_color * intensity;
}
```

**Updating Shaders:**

When fundamental material properties change (like adding uniforms or changing shader code), you must force recompilation:

```javascript
material.needsUpdate = true;  // Forces shader recompilation
```

**Material Properties:**

```javascript

material.transparent = true;  // Enable transparency
material.side = THREE.DoubleSide;  // Render both sides
material.depthWrite = false;  // Disable depth writing
```

## Implementation Notes

### Property Mapping

**ShaderMaterial Properties:**

| Godot Property | three.js Property | Conversion | Notes |
|----------------|-------------------|------------|-------|
| `shader` | Reference to shader | ExtResource lookup | Load shader code or use fallback |
| `shader_parameter/*` | `uniforms.*` | Type-specific conversion | Map each parameter |
| `render_priority` | `renderOrder` | Direct copy | Rendering order |

**Shader Parameter Mapping:**

| Godot Type | Godot Example | three.js Type | Conversion |
|------------|---------------|---------------|------------|
| `Color(r,g,b,a)` | `Color(1, 0.5, 0, 1)` | `THREE.Color` | Parse RGBA, create Color |
| `float` | `2.5` | `number` | `parseFloat()` |
| `vec2` | `Vector2(1, 2)` | `THREE.Vector2` | Parse x, y |
| `vec3` | `Vector3(1, 2, 3)` | `THREE.Vector3` | Parse x, y, z |
| `vec4` | `Vector4(1, 2, 3, 4)` | `THREE.Vector4` | Parse x, y, z, w |
| `sampler2D` | `ExtResource("2")` | `THREE.Texture` | Load via ResourceRegistry |
| `bool` | `true` | `boolean` | Parse boolean |
| `int` | `5` | `number` | `parseInt()` |

### Key Considerations

**1. Shader Code Handling**

For initial implementation:
- **Phase 1 (This WI)**: Parse shader parameters only, use fallback three.js material
- **Phase 2 (WI-17)**: Convert Godot Shading Language to GLSL
- Fallback strategy: Use MeshStandardMaterial with parameters where possible

**2. Shader Parameter Naming**

Godot TSCN format:
```ini
shader_parameter/tint_color = Color(1, 0, 0, 1)
shader_parameter/intensity = 2.0
```

Strip `shader_parameter/` prefix to get uniform name:
```typescript
const paramName = key.replace('shader_parameter/', '');
// "tint_color", "intensity"
```

**3. Type Detection**

Godot TSCN doesn't explicitly declare parameter types. Infer from value:
```typescript
function inferUniformType(value: string): UniformType {
  if (value.startsWith('Color(')) return 'color';
  if (value.startsWith('Vector2(')) return 'vec2';
  if (value.startsWith('Vector3(')) return 'vec3';
  if (value.startsWith('Vector4(')) return 'vec4';
  if (value.startsWith('ExtResource(')) return 'texture';
  if (value === 'true' || value === 'false') return 'bool';
  if (value.includes('.')) return 'float';
  return 'int';
}
```

**4. Resource Dependencies**

ShaderMaterial may reference:
- Shader ExtResource (`.gdshader` files)
- Texture ExtResources for sampler2D uniforms
- Must resolve via ResourceRegistry

**5. Fallback Material Strategy**

When full shader conversion isn't available:
```typescript
// Option 1: MeshStandardMaterial with uniforms applied
const fallback = new THREE.MeshStandardMaterial({
  color: uniforms.tint_color?.value || 0xffffff,
  metallic: uniforms.metallic?.value || 0.0,
  roughness: uniforms.roughness?.value || 0.5,
  map: uniforms.texture_albedo?.value || null,
});

// Option 2: Basic ShaderMaterial with passthrough shaders
const fallback = new THREE.ShaderMaterial({
  uniforms: parsedUniforms,
  vertexShader: defaultVertexShader,
  fragmentShader: defaultFragmentShader,
});
```

**6. Uniform Updates**

Support runtime uniform updates:
```typescript
export function updateShaderParameter(
  material: THREE.ShaderMaterial,
  paramName: string,
  value: any
): void {
  if (material.uniforms[paramName]) {
    material.uniforms[paramName].value = value;
  }
}
```

### Uniform Parser

```typescript
// packages/textscene-renderer/src/resources/shadermaterial/uniformParser.ts
import * as THREE from 'three';
import type { ResourceRegistry } from '../../core/ResourceRegistry';

export type UniformType = 'float' | 'vec2' | 'vec3' | 'vec4' | 'color' | 'texture' | 'bool' | 'int';

export interface ShaderParameter {
  name: string;
  type: UniformType;
  value: any;  // Parsed value
  rawValue: string;  // Original TSCN value
}

export interface ParsedUniforms {
  [key: string]: { value: any };
}

export function parseShaderParameters(
  properties: Record<string, string>,
  resourceRegistry?: ResourceRegistry
): ShaderParameter[] {
  const parameters: ShaderParameter[] = [];

  for (const [key, value] of Object.entries(properties)) {
    if (key.startsWith('shader_parameter/')) {
      const paramName = key.replace('shader_parameter/', '');
      const type = inferUniformType(value);
      const parsedValue = parseUniformValue(value, type, resourceRegistry);

      parameters.push({
        name: paramName,
        type,
        value: parsedValue,
        rawValue: value,
      });
    }
  }

  return parameters;
}

export function inferUniformType(value: string): UniformType {
  const trimmed = value.trim();

  if (trimmed.startsWith('Color(')) return 'color';
  if (trimmed.startsWith('Vector2(')) return 'vec2';
  if (trimmed.startsWith('Vector3(')) return 'vec3';
  if (trimmed.startsWith('Vector4(')) return 'vec4';
  if (trimmed.startsWith('ExtResource(')) return 'texture';
  if (trimmed === 'true' || trimmed === 'false') return 'bool';
  if (trimmed.includes('.') || trimmed.includes('e')) return 'float';

  return 'int';
}

export function parseUniformValue(
  value: string,
  type: UniformType,
  resourceRegistry?: ResourceRegistry
): any {
  const trimmed = value.trim();

  switch (type) {
    case 'color':
      return parseColorValue(trimmed);

    case 'vec2':
      return parseVector2Value(trimmed);

    case 'vec3':
      return parseVector3Value(trimmed);

    case 'vec4':
      return parseVector4Value(trimmed);

    case 'texture':
      // Return ExtResource ID for later resolution
      return parseExtResourceId(trimmed);

    case 'bool':
      return trimmed === 'true';

    case 'float':
      return parseFloat(trimmed);

    case 'int':
      return parseInt(trimmed, 10);

    default:
      return trimmed;
  }
}

function parseColorValue(value: string): THREE.Color {
  // Parse Color(r, g, b, a) format
  const match = value.match(/Color\(\s*([\d.]+)\s*,\s*([\d.]+)\s*,\s*([\d.]+)\s*(?:,\s*([\d.]+))?\s*\)/);

  if (match) {
    const r = parseFloat(match[1]);
    const g = parseFloat(match[2]);
    const b = parseFloat(match[3]);
    // Note: three.js Color doesn't store alpha, handle separately if needed
    return new THREE.Color(r, g, b);
  }

  return new THREE.Color(1, 1, 1);
}

function parseVector2Value(value: string): THREE.Vector2 {
  const match = value.match(/Vector2\(\s*([-\d.]+)\s*,\s*([-\d.]+)\s*\)/);

  if (match) {
    return new THREE.Vector2(
      parseFloat(match[1]),
      parseFloat(match[2])
    );
  }

  return new THREE.Vector2(0, 0);
}

function parseVector3Value(value: string): THREE.Vector3 {
  const match = value.match(/Vector3\(\s*([-\d.]+)\s*,\s*([-\d.]+)\s*,\s*([-\d.]+)\s*\)/);

  if (match) {
    return new THREE.Vector3(
      parseFloat(match[1]),
      parseFloat(match[2]),
      parseFloat(match[3])
    );
  }

  return new THREE.Vector3(0, 0, 0);
}

function parseVector4Value(value: string): THREE.Vector4 {
  const match = value.match(/Vector4\(\s*([-\d.]+)\s*,\s*([-\d.]+)\s*,\s*([-\d.]+)\s*,\s*([-\d.]+)\s*\)/);

  if (match) {
    return new THREE.Vector4(
      parseFloat(match[1]),
      parseFloat(match[2]),
      parseFloat(match[3]),
      parseFloat(match[4])
    );
  }

  return new THREE.Vector4(0, 0, 0, 0);
}

function parseExtResourceId(value: string): string | null {
  const match = value.match(/ExtResource\(\s*"([^"]+)"\s*\)/);
  return match ? match[1] : null;
}

export async function resolveTextureUniforms(
  parameters: ShaderParameter[],
  resourceRegistry: ResourceRegistry
): Promise<ParsedUniforms> {
  const uniforms: ParsedUniforms = {};

  for (const param of parameters) {
    if (param.type === 'texture' && param.value) {
      // Resolve texture ExtResource
      try {
        const texture = await resourceRegistry.loadResource(param.value);
        uniforms[param.name] = { value: texture };
      } catch (error) {
        console.warn(`Failed to load texture for uniform ${param.name}:`, error);
        uniforms[param.name] = { value: null };
      }
    } else {
      uniforms[param.name] = { value: param.value };
    }
  }

  return uniforms;
}
```

```typescript
export const defaultVertexShader = `
varying vec2 vUv;
varying vec3 vNormal;
varying vec3 vPosition;

void main() {
    vUv = uv;
    vNormal = normalize(normalMatrix * normal);
    vPosition = (modelViewMatrix * vec4(position, 1.0)).xyz;
    gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0);
}
`;

export const defaultFragmentShader = `
uniform vec3 diffuse;
uniform float opacity;

varying vec2 vUv;
varying vec3 vNormal;
varying vec3 vPosition;

void main() {
    // Simple lighting
    vec3 lightDir = normalize(vec3(1.0, 1.0, 1.0));
    float lightIntensity = max(dot(vNormal, lightDir), 0.0) * 0.8 + 0.2;

    vec3 color = diffuse * lightIntensity;
    gl_FragColor = vec4(color, opacity);
}
`;

export const textureVertexShader = `
varying vec2 vUv;
varying vec3 vNormal;

void main() {
    vUv = uv;
    vNormal = normalize(normalMatrix * normal);
    gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0);
}
`;

export const textureFragmentShader = `
uniform sampler2D map;
uniform vec3 tint_color;
uniform float intensity;

varying vec2 vUv;
varying vec3 vNormal;

void main() {
    vec4 texColor = texture2D(map, vUv);
    vec3 lightDir = normalize(vec3(1.0, 1.0, 1.0));
    float lightIntensity = max(dot(vNormal, lightDir), 0.0) * 0.8 + 0.2;

    vec3 color = texColor.rgb * tint_color * intensity * lightIntensity;
    gl_FragColor = vec4(color, texColor.a);
}
`;
```

### Parser Implementation

```typescript
// packages/textscene-renderer/src/resources/shadermaterial/parser.ts
import type { TscnSubResource } from '../../types';
import type { ShaderParameter } from './uniformParser';
import { parseShaderParameters } from './uniformParser';

export interface ShaderMaterialProperties {
  shader: string | null;  // ExtResource ID or inline shader
  parameters: ShaderParameter[];
  renderPriority: number;
}

export function isShaderMaterial(resource: TscnSubResource): boolean {
  return resource.type === 'ShaderMaterial';
}

export function parseShaderMaterial(resource: TscnSubResource): ShaderMaterialProperties {
  const props = resource.properties;

  return {
    shader: parseShaderReference(props.shader),
    parameters: parseShaderParameters(props),
    renderPriority: parseInt(props.render_priority ?? '0', 10),
  };
}

function parseShaderReference(value: string | undefined): string | null {
  if (!value) return null;

  // Parse ExtResource("id") format
  const match = value.match(/ExtResource\(\s*"([^"]+)"\s*\)/);
  return match ? match[1] : null;
}
```

### Renderer Implementation

```typescript
// packages/textscene-renderer/src/resources/shadermaterial/renderer.ts
import * as THREE from 'three';
import type { ShaderMaterialProperties } from './parser';
import type { ResourceRegistry } from '../../core/ResourceRegistry';
import { resolveTextureUniforms } from './uniformParser';
import {
  defaultVertexShader,
  defaultFragmentShader,
  textureFragmentShader,
  textureVertexShader,
} from './fallbackShaders';

export async function createShaderMaterial(
  properties: ShaderMaterialProperties,
  resourceRegistry: ResourceRegistry
): Promise<THREE.Material> {
  // Resolve texture uniforms
  const uniforms = await resolveTextureUniforms(properties.parameters, resourceRegistry);

  // Check if shader resource exists
  let shaderCode: string | null = null;
  if (properties.shader) {
    try {
      // Try to load shader code (will be implemented in WI-17)
      // For now, we use fallback shaders
      shaderCode = null;
    } catch (error) {
      console.warn('Shader resource not found, using fallback material:', error);
    }
  }

  // Determine which fallback shader to use
  const hasTexture = Object.values(uniforms).some(
    u => u.value instanceof THREE.Texture
  );

  // Create ShaderMaterial with fallback shaders
  const material = new THREE.ShaderMaterial({
    uniforms: {
      ...createDefaultUniforms(),
      ...uniforms,
    },
    vertexShader: hasTexture ? textureVertexShader : defaultVertexShader,
    fragmentShader: hasTexture ? textureFragmentShader : defaultFragmentShader,
    lights: false,  // Custom shaders don't use three.js lighting by default
    transparent: hasAlphaUniforms(uniforms),
    side: THREE.FrontSide,
  });

  material.renderOrder = properties.renderPriority;

  return material;
}

function createDefaultUniforms(): { [key: string]: { value: any } } {
  return {
    diffuse: { value: new THREE.Color(0xffffff) },
    opacity: { value: 1.0 },
    tint_color: { value: new THREE.Vector3(1, 1, 1) },
    intensity: { value: 1.0 },
  };
}

function hasAlphaUniforms(uniforms: { [key: string]: { value: any } }): boolean {
  // Check if any uniform suggests transparency
  return (
    uniforms.opacity?.value < 1.0 ||
    uniforms.alpha?.value < 1.0 ||
    uniforms.transparent?.value === true
  );
}

export function updateShaderParameter(
  material: THREE.ShaderMaterial,
  paramName: string,
  value: any
): void {
  if (material.uniforms[paramName]) {
    material.uniforms[paramName].value = value;
  } else {
    console.warn(`Uniform ${paramName} not found in material`);
  }
}
```
