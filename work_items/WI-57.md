# WI-57: WorldEnvironment + Environment SubResource

**Status**: Not Started
**Priority**: High
**Estimated Effort**: High Complexity
**Impact**: 2 instances in ld-58 (main.tscn, Hallway.tscn) - Critical for scene atmosphere

## Overview

### Current State

Scene environment settings control lighting, fog, color grading, and atmospheric effects, but **WorldEnvironment and Environment are not implemented**:
- ❌ `WorldEnvironment` node is not parsed or rendered
- ❌ `Environment` sub-resource is not parsed
- ❌ Background mode, color, fog, and color adjustments are ignored
- ❌ Scenes default to basic black background with no atmospheric effects

### Evidence from ld-58

**Example: main.tscn (lines 12-27)** - Environment with background, fog, and color adjustments:
```tscn
[sub_resource type="Environment" id="Environment_sunrise"]
background_mode = 1
background_color = Color(0.15, 0.12, 0.1, 1)
ssr_enabled = true
volumetric_fog_enabled = true
volumetric_fog_density = 0.0003
adjustment_enabled = true
adjustment_brightness = 1.05
adjustment_contrast = 1.05
adjustment_saturation = 1.1

[node name="WorldEnvironment" type="WorldEnvironment" parent="."]
environment = SubResource("Environment_sunrise")
```

**Impact**: Only 2 instances in ld-58, but **critical for visual atmosphere**. Without this, scenes look flat and lifeless.

## Implementation Overview

1. **Environment SubResource Parser** - Parse background, fog, and adjustment properties
2. **WorldEnvironment Node Parser** - Parse node with environment reference
3. **Environment Renderer** - Apply settings to THREE.js scene
4. **Linter Rules** - Validate environment references and property ranges

### Minimum v1 Features

- ✅ Background color/mode
- ✅ Basic fog (THREE.Fog approximation)
- ⚠️ Color adjustments (log warning - requires post-processing)
- ❌ Screen-space reflections (defer to v2 - complex)
