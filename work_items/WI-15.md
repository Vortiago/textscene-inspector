# WI-15: Camera3D Node

## Overview

Implement support for parsing and rendering Godot's Camera3D node, enabling viewport control with both perspective and orthographic projection modes. Camera3D is essential for controlling how the 3D scene is viewed, supporting features like field of view adjustment, near/far clipping planes, and different projection types.

## Implementation Requirements

From TODO.md Phase 4: Advanced Features:

- Parse Camera3D TSCN properties (FOV, projection mode, near/far planes, keep_aspect)
- Create three.js PerspectiveCamera or OrthographicCamera based on projection mode
- Support switching between perspective and orthographic projection
- Handle viewport sizing and aspect ratio calculations
- Implement camera frustum visualization
- Support camera properties: near, far, fov, size (for orthographic)
- Handle keep_aspect modes (KEEP_WIDTH, KEEP_HEIGHT)

## Godot Documentation

### Camera3D Node Properties

From Context7 research on `websites/godotengine_en_stable`:

Camera3D is a specialized Node3D that defines the viewpoint from which a scene is observed. It inherits all transformation properties from Node3D (position, rotation, scale) and adds camera-specific projection properties.

**Key Camera3D Properties:**

```gdscript
# Projection Type
projection = 0  # 0 = PROJECTION_PERSPECTIVE, 1 = PROJECTION_ORTHOGONAL

# Perspective Properties
fov = 75.0              # Field of view in degrees (vertical)
near = 0.05             # Near clipping plane distance
far = 4000.0            # Far clipping plane distance

# Orthographic Properties
size = 1.0              # Half-height of the orthographic view

# Aspect Ratio Handling
keep_aspect = 1         # 0 = KEEP_WIDTH, 1 = KEEP_HEIGHT

# Additional Properties
h_offset = 0.0          # Horizontal offset
v_offset = 0.0          # Vertical offset
frustum_offset = Vector2(0, 0)  # Frustum offset for advanced use
```

**Projection Modes:**

1. **PROJECTION_PERSPECTIVE (0)**: Standard 3D perspective with vanishing points
   - Uses `fov` for vertical field of view
   - Objects appear smaller with distance
   - Default mode for most 3D games

2. **PROJECTION_ORTHOGONAL (1)**: Parallel projection without perspective
   - Uses `size` for orthographic view height
   - Objects maintain size regardless of distance
   - Useful for isometric views, editors, UI

**Keep Aspect Modes:**

- **KEEP_WIDTH (0)**: Adjust height to maintain aspect ratio
- **KEEP_HEIGHT (1)**: Adjust width to maintain aspect ratio (default)

**Inherited Node3D Properties:**

```gdscript
# Transform properties (from Node3D)
position = Vector3(0, 0, 0)
rotation = Vector3(0, 0, 0)       # In radians
rotation_degrees = Vector3(0, 0, 0)
scale = Vector3(1, 1, 1)
transform = Transform3D.IDENTITY
global_transform = Transform3D.IDENTITY

# Visibility
visible = true
```

**Example TSCN Format:**

```ini
[node name="Camera3D" type="Camera3D" parent="."]
transform = Transform3D(1, 0, 0, 0, 0.866025, 0.5, 0, -0.5, 0.866025, 0, 5, 10)
projection = 0
fov = 60.0
near = 0.1
far = 1000.0
```

## Three.js Documentation

### PerspectiveCamera and OrthographicCamera

From Context7 research on `/mrdoob/three.js`:

Three.js provides two main camera types that map to Godot's projection modes:

**PerspectiveCamera (for PROJECTION_PERSPECTIVE):**

```javascript
const camera = new THREE.PerspectiveCamera(fov, aspect, near, far);

// Parameters
// fov: Vertical field of view in degrees (0-180)
// aspect: Aspect ratio (width / height)
// near: Near clipping plane distance (> 0)
// far: Far clipping plane distance (> near)

// Key properties
camera.fov = 75;                    // Vertical FOV in degrees
camera.aspect = window.innerWidth / window.innerHeight;
camera.near = 0.1;
camera.far = 1000;

// IMPORTANT: Must call after changing properties
camera.updateProjectionMatrix();

// Position and rotation (inherited from Object3D)
camera.position.set(0, 0, 5);
camera.rotation.set(0, 0, 0);
camera.lookAt(new THREE.Vector3(0, 0, 0));
```

**OrthographicCamera (for PROJECTION_ORTHOGONAL):**

```javascript
const camera = new THREE.OrthographicCamera(left, right, top, bottom, near, far);

// Parameters define frustum boundaries
// left: Left boundary of frustum
// right: Right boundary of frustum
// top: Top boundary of frustum
// bottom: Bottom boundary of frustum
// near: Near clipping plane distance
// far: Far clipping plane distance

// Key properties
camera.left = -width / 2;
camera.right = width / 2;
camera.top = height / 2;
camera.bottom = -height / 2;
camera.near = 0.1;
camera.far = 1000;

// IMPORTANT: Must call after changing properties
camera.updateProjectionMatrix();
```

**Handling Window Resize:**

```javascript
function onWindowResize() {
  // Update aspect ratio for perspective camera
  camera.aspect = window.innerWidth / window.innerHeight;
  camera.updateProjectionMatrix();

  // Update renderer size
  renderer.setSize(window.innerWidth, window.innerHeight);
}

window.addEventListener('resize', onWindowResize);
```

**Camera Helpers for Debugging:**

```javascript
// Visualize camera frustum
const cameraHelper = new THREE.CameraHelper(camera);
scene.add(cameraHelper);

// Update helper when camera changes
function updateCamera() {
  camera.updateProjectionMatrix();
  cameraHelper.update();
}
```

## Implementation Notes

### Property Mapping

**Perspective Camera Properties (projection = 0):**

| Godot Property | three.js Property | Conversion | Notes |
|----------------|-------------------|------------|-------|
| `projection` | Camera type | 0 → PerspectiveCamera | Determines camera class |
| `fov` | `fov` | Direct copy | Both in degrees |
| `near` | `near` | Direct copy | Min distance > 0 |
| `far` | `far` | Direct copy | Max distance > near |
| `keep_aspect` | `aspect` calculation | Mode-dependent | Affects aspect ratio |
| `position` | `position` | Vector3 conversion | From transform |
| `rotation` | `rotation` | Radians conversion | Extract from transform |

**Orthographic Camera Properties (projection = 1):**

| Godot Property | three.js Property | Conversion | Notes |
|----------------|-------------------|------------|-------|
| `projection` | Camera type | 1 → OrthographicCamera | Determines camera class |
| `size` | `top`/`bottom` | ±size | Half-height of view |
| `size` + aspect | `left`/`right` | ±size * aspect | Width from aspect ratio |
| `near` | `near` | Direct copy | Min distance |
| `far` | `far` | Direct copy | Max distance |
| `keep_aspect` | Frustum calculation | Mode-dependent | Affects frustum bounds |

### Key Considerations

**1. Projection Mode Switching**
- Godot supports runtime projection mode changes
- Implementation should handle switching between camera types
- Preserve common properties (position, rotation, near, far) when switching

**2. Aspect Ratio Calculation**
- Godot's `keep_aspect` affects how the viewport is sized
- KEEP_WIDTH (0): Maintains horizontal FOV, adjusts vertical
- KEEP_HEIGHT (1): Maintains vertical FOV, adjusts horizontal (default)
- Three.js always uses aspect ratio (width/height)
- Need to calculate appropriate aspect based on viewport size and keep_aspect mode

**3. FOV Conversion**
- Godot FOV is vertical field of view in degrees
- three.js PerspectiveCamera also uses vertical FOV in degrees
- Direct mapping: `threeFOV = godotFOV`

**4. Orthographic Size**
- Godot's `size` property represents half-height of the orthographic view
- three.js uses explicit frustum boundaries (left, right, top, bottom)
- Conversion:
  ```typescript
  top = size
  bottom = -size
  right = size * aspect
  left = -size * aspect
  ```

**5. Transform Extraction**
- Camera inherits Node3D transform properties
- Extract position and rotation from transform matrix
- Apply to three.js camera position and rotation

**6. Clipping Planes**
- Ensure near > 0 (three.js requirement)
- Ensure far > near
- Default Godot values: near=0.05, far=4000.0
- Consider reasonable defaults if invalid values encountered

**7. Frustum Offset**
- Godot supports `frustum_offset` for advanced rendering (VR, portals)
- three.js doesn't have direct equivalent
- Can implement using custom projection matrix if needed
- Initially skip for basic implementation

## Code Examples

### Parser Implementation

```typescript
// packages/textscene-renderer/src/nodes/camera3d/parser.ts
import type { TscnNode, Transform3D } from '../../types';

export enum ProjectionMode {
  PROJECTION_PERSPECTIVE = 0,
  PROJECTION_ORTHOGONAL = 1,
}

export enum KeepAspectMode {
  KEEP_WIDTH = 0,
  KEEP_HEIGHT = 1,
}

export interface Camera3DProperties {
  // Projection
  projection: ProjectionMode;

  // Perspective properties
  fov: number;

  // Orthographic properties
  size: number;

  // Common properties
  near: number;
  far: number;
  keep_aspect: KeepAspectMode;

  // Offsets (advanced)
  h_offset: number;
  v_offset: number;
  frustum_offset: { x: number; y: number };
}

export function isCamera3D(node: TscnNode): boolean {
  return node.type === 'Camera3D';
}

export function parseCamera3D(node: TscnNode): Camera3DProperties {
  const props = node.properties;

  return {
    projection: parseProjectionMode(props.projection),
    fov: parseFloat(props.fov ?? '75.0'),
    size: parseFloat(props.size ?? '1.0'),
    near: parseFloat(props.near ?? '0.05'),
    far: parseFloat(props.far ?? '4000.0'),
    keep_aspect: parseKeepAspectMode(props.keep_aspect),
    h_offset: parseFloat(props.h_offset ?? '0.0'),
    v_offset: parseFloat(props.v_offset ?? '0.0'),
    frustum_offset: parseFrustumOffset(props.frustum_offset),
  };
}

function parseProjectionMode(value: string | undefined): ProjectionMode {
  if (value === undefined) return ProjectionMode.PROJECTION_PERSPECTIVE;
  const num = parseInt(value, 10);
  return num === 1 ? ProjectionMode.PROJECTION_ORTHOGONAL : ProjectionMode.PROJECTION_PERSPECTIVE;
}

function parseKeepAspectMode(value: string | undefined): KeepAspectMode {
  if (value === undefined) return KeepAspectMode.KEEP_HEIGHT;
  const num = parseInt(value, 10);
  return num === 0 ? KeepAspectMode.KEEP_WIDTH : KeepAspectMode.KEEP_HEIGHT;
}

function parseFrustumOffset(value: string | undefined): { x: number; y: number } {
  if (!value) return { x: 0, y: 0 };

  // Parse Vector2(x, y) format
  const match = value.match(/Vector2\(\s*([-\d.]+)\s*,\s*([-\d.]+)\s*\)/);
  if (match) {
    return {
      x: parseFloat(match[1]),
      y: parseFloat(match[2]),
    };
  }

  return { x: 0, y: 0 };
}
```

### Renderer Implementation

```typescript
// packages/textscene-renderer/src/nodes/camera3d/renderer.ts
import * as THREE from 'three';
import type { Transform3D } from '../../types';
import type { Camera3DProperties } from './parser';
import { ProjectionMode, KeepAspectMode } from './parser';
import { applyTransform3D } from '../../utils/transformUtils';

export interface CameraConfig {
  aspect: number;  // Viewport aspect ratio (width/height)
  width: number;   // Viewport width in pixels
  height: number;  // Viewport height in pixels
}

export function createCamera3D(
  properties: Camera3DProperties,
  transform: Transform3D,
  config: CameraConfig = { aspect: 16/9, width: 1920, height: 1080 }
): THREE.Camera {
  let camera: THREE.Camera;

  if (properties.projection === ProjectionMode.PROJECTION_PERSPECTIVE) {
    camera = createPerspectiveCamera(properties, config);
  } else {
    camera = createOrthographicCamera(properties, config);
  }

  // Apply transform (position and rotation)
  applyTransform3D(camera, transform);

  // Apply offsets if present
  if (properties.h_offset !== 0 || properties.v_offset !== 0) {
    camera.position.x += properties.h_offset;
    camera.position.y += properties.v_offset;
  }

  return camera;
}

function createPerspectiveCamera(
  properties: Camera3DProperties,
  config: CameraConfig
): THREE.PerspectiveCamera {
  // Calculate aspect ratio based on keep_aspect mode
  const aspect = calculateAspect(properties.keep_aspect, config);

  const camera = new THREE.PerspectiveCamera(
    properties.fov,
    aspect,
    Math.max(0.001, properties.near), // Ensure near > 0
    Math.max(properties.near + 0.1, properties.far) // Ensure far > near
  );

  camera.updateProjectionMatrix();

  return camera;
}

function createOrthographicCamera(
  properties: Camera3DProperties,
  config: CameraConfig
): THREE.OrthographicCamera {
  // Calculate frustum based on size and aspect ratio
  const aspect = calculateAspect(properties.keep_aspect, config);

  const halfHeight = properties.size;
  const halfWidth = properties.size * aspect;

  const camera = new THREE.OrthographicCamera(
    -halfWidth,   // left
    halfWidth,    // right
    halfHeight,   // top
    -halfHeight,  // bottom
    Math.max(0.001, properties.near),
    Math.max(properties.near + 0.1, properties.far)
  );

  camera.updateProjectionMatrix();

  return camera;
}

function calculateAspect(keepAspect: KeepAspectMode, config: CameraConfig): number {
  // In three.js, aspect is always width/height
  // KEEP_HEIGHT is the default behavior for three.js
  // KEEP_WIDTH would require adjusting the FOV or frustum differently

  // For now, use viewport aspect ratio
  // TODO: Implement KEEP_WIDTH mode with adjusted FOV calculations
  return config.aspect;
}

export function updateCameraAspect(
  camera: THREE.Camera,
  properties: Camera3DProperties,
  config: CameraConfig
): void {
  const aspect = calculateAspect(properties.keep_aspect, config);

  if (camera instanceof THREE.PerspectiveCamera) {
    camera.aspect = aspect;
    camera.updateProjectionMatrix();
  } else if (camera instanceof THREE.OrthographicCamera) {
    const halfHeight = properties.size;
    const halfWidth = properties.size * aspect;

    camera.left = -halfWidth;
    camera.right = halfWidth;
    camera.top = halfHeight;
    camera.bottom = -halfHeight;
    camera.updateProjectionMatrix();
  }
}

export function switchProjectionMode(
  currentCamera: THREE.Camera,
  newMode: ProjectionMode,
  properties: Camera3DProperties,
  config: CameraConfig
): THREE.Camera {
  // Create new camera with the same position and rotation
  const newCamera = createCamera3D(
    { ...properties, projection: newMode },
    extractTransform(currentCamera),
    config
  );

  return newCamera;
}

function extractTransform(object: THREE.Object3D): Transform3D {
  // Extract position and rotation from three.js object
  const position = object.position.clone();
  const rotation = object.rotation.clone();
  const scale = object.scale.clone();

  // Convert to Transform3D format
  const matrix = new THREE.Matrix4();
  matrix.compose(position, new THREE.Quaternion().setFromEuler(rotation), scale);

  const elements = matrix.elements;
  return {
    basis: {
      x: { x: elements[0], y: elements[1], z: elements[2] },
      y: { x: elements[4], y: elements[5], z: elements[6] },
      z: { x: elements[8], y: elements[9], z: elements[10] },
    },
    origin: { x: elements[12], y: elements[13], z: elements[14] },
  };
}
```

### Usage in Application

```typescript
// Example: Using Camera3D in web-previewer or vscode-extension
import { parseCamera3D, createCamera3D, updateCameraAspect } from '@tscn-renderer/nodes/camera3d';

// Parse camera from TSCN
const cameraNode = scene.nodes.find(n => n.type === 'Camera3D');
if (cameraNode) {
  const properties = parseCamera3D(cameraNode);

  // Create camera with viewport config
  const config = {
    aspect: window.innerWidth / window.innerHeight,
    width: window.innerWidth,
    height: window.innerHeight,
  };

  const camera = createCamera3D(properties, cameraNode.transform, config);

  // Use camera for rendering
  renderer.render(scene, camera);

  // Handle window resize
  window.addEventListener('resize', () => {
    const newConfig = {
      aspect: window.innerWidth / window.innerHeight,
      width: window.innerWidth,
      height: window.innerHeight,
    };

    updateCameraAspect(camera, properties, newConfig);
    renderer.setSize(window.innerWidth, window.innerHeight);
  });
}
```
