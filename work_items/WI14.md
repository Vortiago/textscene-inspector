# WI-14: Implement Scene Instancing

## Overview
Implement the ability to handle scene instances within TSCN files. This enables Godot's scene composition pattern where scenes can contain instances of other scenes, creating reusable components and modular scene hierarchies.

## Implementation Requirements
- Handle `instance=ExtResource("id")` in node headings
- Load and instantiate sub-scenes
- Maintain parent-child relationships across instances
- **Critical**: Enables scene reuse and composition
- **Frequency**: 20+ external scene instances in typical scenes

## Godot Documentation

### PackedScene and Scene Instancing

**What is a PackedScene?**
A PackedScene is a resource that contains a complete scene stored in a file (.tscn or .scn). It can be instantiated multiple times to create copies of the scene in your game.

**Instantiating Scenes in GDScript:**
```gdscript
extends Node

# Preload scene at compile-time (efficient)
const BulletScene = preload("res://scenes/Bullet.tscn")

func spawn_bullet():
    # Create an instance of the scene
    var bullet_instance = BulletScene.instantiate()

    # Add it to the scene tree
    add_child(bullet_instance)

    # Set properties
    bullet_instance.position = Vector2(100, 100)
```

**Dynamic Loading:**
```gdscript
func load_enemy_scene():
    # Load scene at runtime
    var enemy_scene = load("res://scenes/Enemy.tscn")

    if enemy_scene:
        var enemy_instance = enemy_scene.instantiate()
        add_child(enemy_instance)
        enemy_instance.position = Vector2(300, 150)
```

**Multiple Instances:**
```gdscript
var enemy_scene: PackedScene = preload("res://enemies/goblin.tscn")

func _ready():
    # Spawn multiple enemies
    for i in range(5):
        spawn_enemy(Vector2(randf_range(0, 800), randf_range(0, 600)))

func spawn_enemy(spawn_position: Vector2) -> void:
    var enemy = enemy_scene.instantiate()
    add_child(enemy)
    enemy.position = spawn_position

    # Connect signals after instantiation
    if enemy.has_signal("died"):
        enemy.died.connect(_on_enemy_died)
```

**Scene Management with Signals:**
```gdscript
func _ready():
    var bullet_scene = preload("res://scenes/bullet.tscn")
    var bullet_instance = bullet_scene.instantiate()
    add_child(bullet_instance)

    # Connect to signals from instanced scene
    bullet_instance.connect("hit_target", self, "_on_bullet_hit_target")

func _on_bullet_hit_target():
    print("Bullet hit something!")
```

### TSCN Instance Format

**In TSCN Files:**
```text
[gd_scene load_steps=3 format=3]

[ext_resource type="PackedScene" path="res://scenes/Player.tscn" id="1_player"]
[ext_resource type="PackedScene" path="res://scenes/Enemy.tscn" id="2_enemy"]

[node name="Level" type="Node2D"]

[node name="Player" type="Node2D" parent="." instance=ExtResource("1_player")]
position = Vector2(100, 100)

[node name="Enemy1" type="Node2D" parent="." instance=ExtResource("2_enemy")]
position = Vector2(300, 200)

[node name="Enemy2" type="Node2D" parent="." instance=ExtResource("2_enemy")]
position = Vector2(500, 200)
```

**Key Points:**
- `instance=ExtResource("id")` indicates this node is an instance of an external scene
- The node type in the heading matches the root node type of the instanced scene
- Properties can override the instanced scene's default values
- Each instance maintains its own transform and properties

### Scene Hierarchy and Parent-Child Relationships

**Hierarchy Preservation:**
When a scene is instantiated:
1. The entire scene tree structure is copied
2. Child nodes maintain their relative positions
3. Signals and scripts are preserved
4. Properties can be overridden at the instance level

**Example Hierarchy:**
```
Level (Node2D)
├── Player (instance of Player.tscn)
│   ├── Sprite2D (from Player.tscn)
│   ├── CollisionShape2D (from Player.tscn)
│   └── AnimationPlayer (from Player.tscn)
├── Enemy1 (instance of Enemy.tscn)
│   ├── Sprite2D (from Enemy.tscn)
│   └── AI (from Enemy.tscn)
└── Enemy2 (instance of Enemy.tscn)
    ├── Sprite2D (from Enemy.tscn)
    └── AI (from Enemy.tscn)
```

### Property Overrides

Instanced scenes can override properties:
```text
[node name="Player" parent="." instance=ExtResource("1_player")]
position = Vector2(100, 100)  # Overrides default position
scale = Vector2(1.5, 1.5)     # Overrides default scale
```

The override properties are applied after the scene is instantiated.

## Implementation Notes

### Detecting Instanced Nodes

```typescript
interface TscnNode {
  name: string;
  type: string;
  parent: string;
  instance?: string;  // e.g., "ExtResource('1_player')"
  properties: Record<string, any>;
  children: TscnNode[];
}

function isInstancedNode(node: TscnNode): boolean {
  return node.instance !== undefined;
}

function getInstanceResourceId(instance: string): string {
  // Parse: instance=ExtResource("1_player") → "1_player"
  const match = instance.match(/ExtResource\("([^"]+)"\)/);
  return match ? match[1] : '';
}
```

### Scene Instantiation Flow

```typescript
async function buildSceneGraph(
  scene: TscnScene,
  resourceRegistry: ResourceRegistry
): Promise<THREE.Group> {
  const root = new THREE.Group();
  root.name = scene.rootNode.name;

  await buildNodeRecursive(scene.rootNode, root, resourceRegistry);

  return root;
}

async function buildNodeRecursive(
  node: TscnNode,
  parent: THREE.Object3D,
  resourceRegistry: ResourceRegistry
): Promise<void> {
  let nodeObject: THREE.Object3D;

  if (isInstancedNode(node)) {
    // This node is an instance of an external scene
    nodeObject = await instantiateScene(node, resourceRegistry);
  } else {
    // Regular node - create using node type renderer
    nodeObject = createNodeObject(node);
  }

  // Apply transform and properties
  applyTransform(nodeObject, node.properties.transform);
  applyProperties(nodeObject, node.properties);

  // Add to parent
  parent.add(nodeObject);

  // Process children (if not instanced, or if instance has child overrides)
  for (const child of node.children) {
    await buildNodeRecursive(child, nodeObject, resourceRegistry);
  }
}

async function instantiateScene(
  instanceNode: TscnNode,
  resourceRegistry: ResourceRegistry
): Promise<THREE.Object3D> {
  // Get the resource ID from instance property
  const resourceId = getInstanceResourceId(instanceNode.instance!);

  // Load the external scene
  const externalScene = await resourceRegistry.loadResource(resourceId);

  if (!externalScene) {
    console.error(`Failed to load instanced scene: ${resourceId}`);
    return new THREE.Group(); // Return empty group as fallback
  }

  // Build the instanced scene's object graph
  const instancedObject = await buildSceneGraph(
    externalScene,
    resourceRegistry
  );

  // Apply overrides from the instance definition
  instancedObject.name = instanceNode.name;

  return instancedObject;
}
```

### Circular Dependency Detection

```typescript
class InstanceTracker {
  private loadingStack: Set<string> = new Set();

  async loadScene(
    scenePath: string,
    resourceRegistry: ResourceRegistry
  ): Promise<TscnScene> {
    if (this.loadingStack.has(scenePath)) {
      throw new Error(
        `Circular dependency detected: ${scenePath} ` +
        `is already being loaded. Stack: ${Array.from(this.loadingStack).join(' → ')}`
      );
    }

    this.loadingStack.add(scenePath);

    try {
      const scene = await resourceRegistry.loadResource(scenePath);
      this.loadingStack.delete(scenePath);
      return scene;
    } catch (error) {
      this.loadingStack.delete(scenePath);
      throw error;
    }
  }
}
```

### Key Considerations

1. **Transform Inheritance**:
   - Instanced scenes maintain their internal transform hierarchy
   - The instance node's transform is applied to the root of the instanced scene
   - Child transforms are relative to their parents

2. **Property Override Strategy**:
   - Instance-level overrides apply to the root node of the instanced scene
   - Deep property overrides (affecting children) are more complex
   - Godot supports both root and child overrides

3. **Resource Caching**:
   - Cache loaded PackedScenes to avoid reloading
   - Multiple instances of the same scene share the scene data
   - Each instance gets its own Object3D hierarchy

4. **Circular Dependencies**:
   - Scene A instances Scene B which instances Scene A → infinite loop
   - Detect using loading stack
   - Show clear error message with dependency chain

5. **Scene Update Strategy**:
   - When instanced scene file changes, should instances update?
   - For preview: Reload instanced scenes when files change
   - Track file watchers for instanced resources

### Complete Scene Instantiation System

```typescript
// packages/textscene-renderer/src/core/SceneInstantiator.ts
import * as THREE from 'three';
import type { TscnScene, TscnNode } from '../parser/types';
import type { ResourceRegistry } from '../resources/ResourceRegistry';

export class SceneInstantiator {
  private instanceTracker = new InstanceTracker();

  async buildSceneGraph(
    scene: TscnScene,
    resourceRegistry: ResourceRegistry
  ): Promise<THREE.Group> {
    const root = new THREE.Group();
    root.name = scene.rootNode.name;

    // Apply root node transform
    if (scene.rootNode.properties.transform) {
      this.applyTransform(root, scene.rootNode.properties.transform);
    }

    // Build children
    for (const child of scene.rootNode.children) {
      const childObject = await this.buildNode(child, resourceRegistry);
      if (childObject) {
        root.add(childObject);
      }
    }

    return root;
  }

  private async buildNode(
    node: TscnNode,
    resourceRegistry: ResourceRegistry
  ): Promise<THREE.Object3D | null> {
    let nodeObject: THREE.Object3D;

    if (node.instance) {
      // Instantiate external scene
      nodeObject = await this.instantiateScene(node, resourceRegistry);
    } else {
      // Create regular node
      nodeObject = await this.createNodeObject(node, resourceRegistry);
    }

    // Apply transform
    if (node.properties.transform) {
      this.applyTransform(nodeObject, node.properties.transform);
    }

    // Build children (may have child overrides even for instances)
    for (const child of node.children) {
      const childObject = await this.buildNode(child, resourceRegistry);
      if (childObject) {
        nodeObject.add(childObject);
      }
    }

    return nodeObject;
  }

  private async instantiateScene(
    instanceNode: TscnNode,
    resourceRegistry: ResourceRegistry
  ): Promise<THREE.Object3D> {
    // Extract resource ID
    const resourceId = this.parseExtResourceRef(instanceNode.instance!);
    if (!resourceId) {
      console.error('Invalid instance reference:', instanceNode.instance);
      return new THREE.Group();
    }

    // Get resource info
    const resource = resourceRegistry.get(resourceId);
    if (!resource || resource.type !== 'PackedScene') {
      console.error('Invalid PackedScene resource:', resourceId);
      return new THREE.Group();
    }

    // Check for circular dependencies
    const scenePath = resource.path;
    if (this.instanceTracker.isLoading(scenePath)) {
      console.error(
        `Circular dependency detected: ${scenePath}\n` +
        `Loading stack: ${this.instanceTracker.getStack().join(' → ')}`
      );
      return new THREE.Group();
    }

    // Load the scene
    this.instanceTracker.push(scenePath);

    try {
      const externalScene = await resourceRegistry.loadResource(resourceId);

      if (!externalScene) {
        throw new Error(`Failed to load scene: ${scenePath}`);
      }

      // Build the instanced scene
      const instancedObject = await this.buildSceneGraph(
        externalScene,
        resourceRegistry
      );

      // Override name from instance definition
      instancedObject.name = instanceNode.name;

      // Apply property overrides
      this.applyPropertyOverrides(instancedObject, instanceNode.properties);

      this.instanceTracker.pop();

      return instancedObject;
    } catch (error) {
      this.instanceTracker.pop();
      console.error('Failed to instantiate scene:', error);
      return new THREE.Group();
    }
  }

  private async createNodeObject(
    node: TscnNode,
    resourceRegistry: ResourceRegistry
  ): Promise<THREE.Object3D> {
    // Use node registry to create appropriate three.js object
    const nodeType = nodeRegistry.get(node.type);

    if (!nodeType) {
      console.warn(`Unknown node type: ${node.type}`);
      return new THREE.Group();
    }

    // Parse node properties
    const properties = nodeType.parser(node);

    // Create three.js object
    const object = nodeType.renderer(properties, node.properties.transform);

    object.name = node.name;

    return object;
  }

  private applyTransform(object: THREE.Object3D, transform: any): void {
    if (transform.position) {
      object.position.copy(transform.position);
    }
    if (transform.rotation) {
      object.quaternion.copy(transform.rotation);
    }
    if (transform.scale) {
      object.scale.copy(transform.scale);
    }
  }

  private applyPropertyOverrides(
    object: THREE.Object3D,
    properties: Record<string, any>
  ): void {
    // Apply overrides from instance definition
    for (const [key, value] of Object.entries(properties)) {
      // Skip transform (already applied)
      if (key === 'transform') continue;

      // Apply other overridable properties
      // This is scene-specific and depends on node type
      // For now, we focus on transform overrides
    }
  }

  private parseExtResourceRef(ref: string): string | null {
    const match = ref.match(/ExtResource\("([^"]+)"\)/);
    return match ? match[1] : null;
  }
}

class InstanceTracker {
  private stack: string[] = [];

  push(scenePath: string): void {
    this.stack.push(scenePath);
  }

  pop(): void {
    this.stack.pop();
  }

  isLoading(scenePath: string): boolean {
    return this.stack.includes(scenePath);
  }

  getStack(): string[] {
    return [...this.stack];
  }
}
```

### Parser Extension for Instances

```typescript
// packages/textscene-renderer/src/parser/TscnParser.ts (extension)
export function parseNodeHeading(line: string): Partial<TscnNode> {
  const node: Partial<TscnNode> = {};

  // Parse name
  const nameMatch = line.match(/name="([^"]+)"/);
  if (nameMatch) node.name = nameMatch[1];

  // Parse type
  const typeMatch = line.match(/type="([^"]+)"/);
  if (typeMatch) node.type = typeMatch[1];

  // Parse parent
  const parentMatch = line.match(/parent="([^"]+)"/);
  if (parentMatch) node.parent = parentMatch[1];

  // Parse instance (NEW!)
  const instanceMatch = line.match(/instance=ExtResource\("([^"]+)"\)/);
  if (instanceMatch) {
    node.instance = `ExtResource("${instanceMatch[1]}")`;
  }

  return node;
}
```

export class TscnRenderer {
  private instantiator = new SceneInstantiator();

  async render(scene: TscnScene): Promise<void> {
    // Clear previous scene
    this.clear();

    // Build scene graph with instancing support
    const sceneGraph = await this.instantiator.buildSceneGraph(
      scene,
      scene.resourceRegistry!
    );

    // Add to three.js scene
    this.scene.add(sceneGraph);

    // Render
    this.renderer.render(this.scene, this.camera);
  }
}

## Performance Considerations

1. **Scene Caching**: Cache loaded PackedScenes to avoid re-parsing
2. **Instance Pooling**: For frequently instantiated scenes (bullets, particles), consider object pooling
3. **Lazy Loading**: Load instanced scenes only when needed
4. **Memory Management**: Track and dispose of unused scene instances
