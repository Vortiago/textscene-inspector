# WI-62: Emission Enable Flag Support (StandardMaterial3D)

**Status**: Not Started
**Priority**: High
**Complexity**: Simple
**Impact**: Existing fixture `unit-material-emissive.tscn` uses `emission_enabled = true` but flag is ignored

## Overview

### Problem Statement

StandardMaterial3D emission textures are applied **unconditionally** when present, violating Godot's feature flag pattern:

- ✅ `normal_enabled` flag correctly controls normal map application (WI-59)
- ❌ `emission_enabled` flag is **NOT parsed or checked** in renderer
- ❌ Emission texture applied even when `emission_enabled = false`
- ❌ **Inconsistent behavior** compared to normal maps

**Evidence**: Fixture `scenes/fixtures/unit-material-emissive.tscn:13` uses `emission_enabled = true` but our code ignores it.

### Current Implementation Gap

**Parser** (`standardmaterial3d/parser.ts:131-138`):
```typescript
// Emission texture - WRONG: No flag check
if (properties.emission_texture) {
  const emissionTexRef = ResourceRegistry.parseReference(properties.emission_texture);
  if (emissionTexRef) {
    const texture = await registry.loadTexture(emissionTexRef);
    if (texture) {
      result.emission_texture = texture;  // Applied unconditionally!
    }
  }
}
```

**Renderer** (`standardmaterial3d/renderer.ts:58-60`):
```typescript
// Emission texture - WRONG: No flag check
if (properties.emission_texture) {
  materialOptions.emissiveMap = properties.emission_texture;  // Applied unconditionally!
}
```

**Correct behavior** (from normal maps WI-59):
```typescript
if (properties.normal_enabled && properties.normal_texture) {
  materialOptions.normalMap = properties.normal_texture;  // ✅ Checks both flag and texture
}
```

### Godot's Feature Flag System

Godot's BaseMaterial3D uses a `Feature` enum system:
- `FEATURE_EMISSION` → saved as `emission_enabled` in TSCN
- `FEATURE_NORMAL_MAPPING` → saved as `normal_enabled` in TSCN
- `FEATURE_AMBIENT_OCCLUSION` → saved as `ao_enabled` in TSCN

**Source**: `godot/scene/resources/material.h` - `set_feature(Feature p_feature, bool p_enabled)` method

**TSCN Format**:
```tscn
[sub_resource type="StandardMaterial3D" id="Material_emissive"]
albedo_color = Color(0.2, 0.4, 0.9, 1)
emission_enabled = true              # ← Feature flag (IGNORED by our code!)
emission = Color(0.3, 0.6, 1.0, 1)   # ← Emission color
emission_energy_multiplier = 2.0     # ← Emission strength
```
