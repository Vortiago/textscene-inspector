# WI-54: External Audio Loading

## Overview
Implement loading and visualization of external audio resources referenced in TSCN files. While audio playback is not the primary goal for a 3D scene previewer, representing audio sources spatially and showing their properties is valuable for scene understanding and debugging.

## Current State

**What Exists:**
- ✅ `ResourceRegistry` parses and registers `[ext_resource type="AudioStream*"]` headings
- ✅ `ResourceProvider` interface supports loading binary resources (returns `ArrayBuffer`)
- ⚠️ AudioStreamPlayer3D and AudioStreamPlayer2D nodes exist but lack linter support

**What's Missing:**
- ❌ No actual audio file loading
- ❌ No audio stream application to AudioStreamPlayer nodes
- ❌ No THREE.js Audio/PositionalAudio integration
- ❌ No visual representation of audio sources in 3D viewport

## Implementation Requirements

### 1. Audio Loading in ResourceRegistry

Extend `ResourceRegistry` to load audio as THREE.js audio objects:

```typescript
// packages/textscene-core/src/resources/ResourceRegistry.ts

/**
 * Load audio resource and return THREE.js Audio/PositionalAudio
 */
async loadAudio(idOrPath: string, spatial: boolean = false): Promise<THREE.Audio | THREE.PositionalAudio> {
  // 1. Get resource metadata
  const resource = this.getMetadata(idOrPath);
  if (!resource || !resource.type.includes('AudioStream')) {
    throw new Error(`Not an audio resource: ${idOrPath}`);
  }

  // 2. Load raw content via provider (returns ArrayBuffer)
  const content = await this.loadByPath(resource.path);
  if (!(content instanceof ArrayBuffer)) {
    throw new Error(`Audio must be binary data: ${resource.path}`);
  }

  // 3. Create AudioContext if needed (singleton)
  if (!this.audioListener) {
    this.audioListener = new THREE.AudioListener();
    // Note: AudioListener should be added to camera in renderer
  }

  // 4. Create Audio or PositionalAudio
  const audio = spatial
    ? new THREE.PositionalAudio(this.audioListener)
    : new THREE.Audio(this.audioListener);

  // 5. Decode audio data
  const audioContext = this.audioListener.context;
  const audioBuffer = await audioContext.decodeAudioData(content.slice(0)); // Clone buffer

  audio.setBuffer(audioBuffer);

  return audio;
}
```

### 2. AudioStreamPlayer3D Renderer

Create renderer for spatial audio sources:

```typescript
// packages/textscene-core/src/nodes/audio/audiostreamplayer3d/renderer.ts

import * as THREE from 'three';
import type { AudioStreamPlayer3DProperties } from './types';

export function createAudioStreamPlayer3D(
  props: AudioStreamPlayer3DProperties,
  transform?: Transform3D
): THREE.Group {
  const group = new THREE.Group();

  // Visual representation: speaker icon
  const iconGeometry = new THREE.SphereGeometry(0.2, 8, 8);
  const iconMaterial = new THREE.MeshBasicMaterial({
    color: 0x4444ff,
    transparent: true,
    opacity: 0.5
  });
  const icon = new THREE.Mesh(iconGeometry, iconMaterial);
  group.add(icon);

  // Add visual indicator for audio range (max_distance)
  if (props.maxDistance > 0) {
    const rangeGeometry = new THREE.SphereGeometry(props.maxDistance, 16, 16);
    const rangeMaterial = new THREE.MeshBasicMaterial({
      color: 0x4444ff,
      transparent: true,
      opacity: 0.1,
      wireframe: true
    });
    const range = new THREE.Mesh(rangeGeometry, rangeMaterial);
    group.add(range);
  }

  // Attach audio if available
  if (props.audio) {
    group.add(props.audio);

    // Configure spatial audio properties
    if (props.audio instanceof THREE.PositionalAudio) {
      props.audio.setRefDistance(props.unitSize);
      props.audio.setMaxDistance(props.maxDistance);
      props.audio.setDistanceModel(props.attenuationModel);
      props.audio.setVolume(props.volumeDb / 24.0); // Convert dB to 0-1 range
    }
  }

  // Apply transform
  if (transform) {
    group.position.copy(transform.position);
    group.quaternion.copy(transform.rotation);
    group.scale.copy(transform.scale);
  }

  return group;
}
```

### 3. AudioStreamPlayer3D Parser

Parse audio node properties and load external audio:

```typescript
// packages/textscene-core/src/nodes/audio/audiostreamplayer3d/parser.ts

import type { TscnNode, TscnScene } from '../../../parser/types';
import type { AudioStreamPlayer3DProperties } from './types';
import { ResourceRegistry } from '../../../resources/ResourceRegistry';

export async function parseAudioStreamPlayer3D(
  node: TscnNode,
  scene: TscnScene
): Promise<AudioStreamPlayer3DProperties> {
  const props: AudioStreamPlayer3DProperties = {
    stream: null,
    audio: null,
    volumeDb: 0.0,
    unitSize: 10.0,
    maxDistance: 0.0,
    attenuationModel: 'inverse',
    playing: false,
    autoplay: false,
  };

  // Parse properties
  if (node.properties.volume_db !== undefined) {
    props.volumeDb = Number(node.properties.volume_db);
  }

  if (node.properties.unit_size !== undefined) {
    props.unitSize = Number(node.properties.unit_size);
  }

  if (node.properties.max_distance !== undefined) {
    props.maxDistance = Number(node.properties.max_distance);
  }

  if (node.properties.attenuation_model !== undefined) {
    // Map Godot attenuation models to THREE.js distance models
    const modelMap: Record<number, DistanceModelType> = {
      0: 'inverse',      // ATTENUATION_INVERSE_DISTANCE
      1: 'inverse',      // ATTENUATION_INVERSE_SQUARE_DISTANCE (approximate)
      2: 'linear',       // ATTENUATION_LOGARITHMIC (approximate)
      3: 'exponential',  // ATTENUATION_DISABLED (use exponential with large distance)
    };
    props.attenuationModel = modelMap[Number(node.properties.attenuation_model)] || 'inverse';
  }

  if (node.properties.autoplay !== undefined) {
    props.autoplay = Boolean(node.properties.autoplay);
  }

  if (node.properties.playing !== undefined) {
    props.playing = Boolean(node.properties.playing);
  }

  // Load external audio stream if referenced
  const registry = scene.resourceRegistry;
  if (registry && node.properties.stream) {
    const streamRef = ResourceRegistry.parseReference(node.properties.stream as string);
    if (streamRef) {
      try {
        props.audio = await registry.loadAudio(streamRef, true); // spatial=true
        props.stream = streamRef;
      } catch (error) {
        console.warn(`Failed to load audio stream: ${streamRef}`, error);
      }
    }
  }

  return props;
}
```

### 4. Audio Types

Define types for audio properties:

```typescript
// packages/textscene-core/src/nodes/audio/audiostreamplayer3d/types.ts

import type * as THREE from 'three';

export interface AudioStreamPlayer3DProperties {
  /** External audio stream reference */
  stream: string | null;

  /** THREE.js PositionalAudio object (if loaded) */
  audio: THREE.PositionalAudio | null;

  /** Volume in decibels (-80 to 24 dB) */
  volumeDb: number;

  /** Unit size for attenuation (ref distance) */
  unitSize: number;

  /** Maximum distance for attenuation (0 = infinite) */
  maxDistance: number;

  /** Attenuation model */
  attenuationModel: 'linear' | 'inverse' | 'exponential';

  /** Is the audio currently playing? */
  playing: boolean;

  /** Should audio start automatically? */
  autoplay: boolean;
}
```

### 5. Godot AudioStream Types

Godot supports various audio formats:

| Godot Type | File Extension | Description |
|------------|----------------|-------------|
| `AudioStreamWAV` | .wav | Uncompressed PCM audio |
| `AudioStreamOggVorbis` | .ogg | Ogg Vorbis compressed audio |
| `AudioStreamMP3` | .mp3 | MP3 compressed audio |
| `AudioStreamPolyphonic` | - | Layered audio (complex) |

For preview purposes, we'll focus on the common formats: WAV, OGG, MP3.

### 6. TSCN Usage Pattern

```tscn
[gd_scene format=3]

[ext_resource type="AudioStreamWAV" path="res://sounds/footstep.wav" id="1_sound"]

[node name="FootstepSound" type="AudioStreamPlayer3D"]

unit_size = 10.0

attenuation_model = 0
autoplay = false
```

## Architecture Considerations

### Audio Playback Control

For preview purposes, audio should **NOT autoplay** by default:
- Visual representation is more important than playback
- Autoplay can be annoying during development
- Option: Add UI button to toggle audio playback

### AudioListener Management

THREE.js requires a single `AudioListener` attached to the camera:

```typescript
// In TscnRenderer initialization
const audioListener = new THREE.AudioListener();
camera.add(audioListener);

// Pass to ResourceRegistry
resourceRegistry.setAudioListener(audioListener);
```

### Performance Considerations

- **Lazy loading**: Load audio files only when node is visible or selected
- **Audio buffer caching**: Share AudioBuffer across multiple player instances
- **Memory management**: Dispose audio buffers when clearing scene

### Visual Representation

Audio sources should be visible in the 3D viewport:
1. **Icon**: Small sphere/speaker icon at audio source position
2. **Range indicator**: Wireframe sphere showing max_distance
3. **Color coding**: Blue for 3D audio, green for 2D audio
4. **Selected state**: Highlight when audio node is selected

### Error Handling

When audio loading fails:
1. Log warning with audio path
2. Show icon without audio attached
3. Continue rendering scene
4. Optionally call `onResourceNeeded` callback
