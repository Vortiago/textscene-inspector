# WI-18: Additional Mesh Types (PlaneMesh, CapsuleMesh, TorusMesh, PrismMesh)

## Overview

Implement support for additional Godot mesh primitive types: PlaneMesh, CapsuleMesh, TorusMesh, and PrismMesh. This extends the mesh primitive support beyond the already-implemented BoxMesh, SphereMesh, and CylinderMesh, enabling rendering of a wider variety of procedural geometry from Godot scenes.

## Implementation Requirements

From TODO.md Phase 5: Mesh Primitives:

- Parse PlaneMesh SubResource (size, subdivisions, orientation)
- Parse CapsuleMesh SubResource (radius, height, rings, radial_segments)
- Parse TorusMesh SubResource (inner_radius, outer_radius, rings, ring_segments)
- Parse PrismMesh SubResource (left_to_right, size, subdivisions)
- Create three.js equivalents: PlaneGeometry, CapsuleGeometry, TorusGeometry
- Handle PrismMesh conversion (no direct three.js equivalent - use custom geometry or CylinderGeometry approximation)
- Support mesh subdivision parameters
- Apply materials correctly
- Register with ResourceRegistry
- Follow vertical slicing pattern

## Godot Documentation

### Godot Mesh Primitives

From Context7 research on `websites/godotengine_en_stable`:

Godot provides several primitive mesh types as SubResources. These are procedurally generated meshes defined by parameters rather than vertex data.

**General Mesh Structure:**

All mesh primitives inherit from PrimitiveMesh and share common properties:
- `material` - Material applied to the mesh
- Custom parameters specific to each primitive type

**PlaneMesh:**

A flat rectangular plane, useful for floors, walls, or quad surfaces.

```gdscript
# Creating PlaneMesh in code
var plane = PlaneMesh.new()
plane.size = Vector2(10.0, 5.0)  # Width x Height
plane.subdivide_width = 10       # Horizontal subdivisions
plane.subdivide_depth = 5        # Vertical subdivisions
plane.orientation = PlaneMesh.FACE_Y  # FACE_X, FACE_Y, FACE_Z
plane.material = material
```

**TSCN Format:**
```ini
[sub_resource type="PlaneMesh" id="PlaneMesh_abc"]
size = Vector2(10, 5)
subdivide_width = 10
subdivide_depth = 5
orientation = 1  # 0=FACE_X, 1=FACE_Y, 2=FACE_Z
```

**Properties:**
- `size: Vector2` - Dimensions (width, depth), default: Vector2(2, 2)
- `subdivide_width: int` - Number of horizontal subdivisions, default: 0
- `subdivide_depth: int` - Number of vertical subdivisions, default: 0
- `orientation: int` - Which axis the plane faces (0=X, 1=Y, 2=Z), default: 1

**CapsuleMesh:**

A capsule shape (cylinder with hemispherical caps), commonly used for character collision shapes.

```gdscript
# Creating CapsuleMesh in code
var capsule = CapsuleMesh.new()
capsule.radius = 0.5
capsule.height = 2.0
capsule.radial_segments = 32
capsule.rings = 8
capsule.material = material
```

**TSCN Format:**
```ini
[sub_resource type="CapsuleMesh" id="CapsuleMesh_xyz"]
radius = 0.5
height = 2.0
radial_segments = 32
rings = 8
```

**Properties:**
- `radius: float` - Radius of the capsule, default: 0.5
- `height: float` - Total height (including hemisphere caps), default: 2.0
- `radial_segments: int` - Number of segments around circumference, default: 64
- `rings: int` - Number of horizontal rings, default: 8

**TorusMesh:**

A torus (donut) shape.

```gdscript
# Creating TorusMesh in code
var torus = TorusMesh.new()
torus.inner_radius = 0.5
torus.outer_radius = 1.0
torus.rings = 32
torus.ring_segments = 16
torus.material = material
```

**TSCN Format:**
```ini
[sub_resource type="TorusMesh" id="TorusMesh_xyz"]
inner_radius = 0.5
outer_radius = 1.0
rings = 32
ring_segments = 16
```

**Properties:**
- `inner_radius: float` - Inner radius (hole size), default: 0.5
- `outer_radius: float` - Outer radius (total radius), default: 1.0
- `rings: int` - Number of rings (around the donut), default: 32
- `ring_segments: int` - Number of segments per ring (tube detail), default: 16

**PrismMesh:**

A triangular prism shape. Note: This is less common and has limited documentation.

```gdscript
# Creating PrismMesh in code
var prism = PrismMesh.new()
prism.left_to_right = 0.5
prism.size = Vector3(1.0, 2.0, 1.0)
prism.subdivide_width = 0
prism.subdivide_height = 0
prism.subdivide_depth = 0
prism.material = material
```

**TSCN Format:**
```ini
[sub_resource type="PrismMesh" id="PrismMesh_xyz"]
left_to_right = 0.5
size = Vector3(1, 2, 1)
subdivide_width = 0
subdivide_height = 0
subdivide_depth = 0
```

**Properties:**
- `left_to_right: float` - Offset of the top vertices, default: 0.5
- `size: Vector3` - Dimensions of the prism, default: Vector3(2, 2, 2)
- `subdivide_width: int` - Width subdivisions, default: 0
- `subdivide_height: int` - Height subdivisions, default: 0
- `subdivide_depth: int` - Depth subdivisions, default: 0

## Three.js Documentation

### Three.js Geometry Classes

From Context7 research on `/mrdoob/three.js`:

Three.js provides equivalent geometry classes for most Godot primitives.

**PlaneGeometry:**

```javascript
const geometry = new THREE.PlaneGeometry(
  width,   // Width along X axis
  height,  // Height along Y axis
  widthSegments,   // Number of horizontal subdivisions
  heightSegments   // Number of vertical subdivisions
);

// Example
const plane = new THREE.PlaneGeometry(10, 5, 10, 5);
const material = new THREE.MeshStandardMaterial({ color: 0xffffff, side: THREE.DoubleSide });
const mesh = new THREE.Mesh(plane, material);
```

**Parameters:**
- `width: number` - Width of the plane (default: 1)
- `height: number` - Height of the plane (default: 1)
- `widthSegments: number` - Horizontal segments (default: 1)
- `heightSegments: number` - Vertical segments (default: 1)

**Orientation:** PlaneGeometry faces the +Z direction by default. Rotate to match Godot orientation.

**CapsuleGeometry:**

```javascript
const geometry = new THREE.CapsuleGeometry(
  radius,          // Radius of capsule
  length,          // Length of middle section (excludes caps)
  capSegments,     // Number of segments for hemisphere caps
  radialSegments   // Number of segments around circumference
);

// Example
const capsule = new THREE.CapsuleGeometry(0.5, 1.0, 4, 32);
const material = new THREE.MeshStandardMaterial({ color: 0x0000ff });
const mesh = new THREE.Mesh(capsule, material);
```

**Parameters:**
- `radius: number` - Radius of the capsule (default: 1)
- `length: number` - Length of the cylindrical section (default: 1)
- `capSegments: number` - Segments in hemisphere caps (default: 4)
- `radialSegments: number` - Segments around circumference (default: 8)

**Important:** three.js `length` parameter is the middle section only, while Godot's `height` includes the caps. Conversion: `threeLength = godotHeight - 2 * radius`

**TorusGeometry:**

```javascript
const geometry = new THREE.TorusGeometry(
  radius,          // Radius from center to tube center
  tube,            // Radius of the tube
  radialSegments,  // Number of segments around the torus
  tubularSegments, // Number of segments around the tube
  arc              // Central angle (default: 2π for full torus)
);

// Example
const torus = new THREE.TorusGeometry(1.0, 0.4, 16, 32);
const material = new THREE.MeshStandardMaterial({ color: 0xff0000 });
const mesh = new THREE.Mesh(torus, material);
```

**Parameters:**
- `radius: number` - Main radius (default: 1)
- `tube: number` - Tube radius (default: 0.4)
- `radialSegments: number` - Radial segments (default: 12)
- `tubularSegments: number` - Tubular segments (default: 48)
- `arc: number` - Central angle in radians (default: Math.PI * 2)

**Mapping:**
- Godot `outer_radius` → three.js `radius`
- Godot `inner_radius` → three.js `tube` = (outer_radius - inner_radius) / 2
- Adjust center: `radius = (outer_radius + inner_radius) / 2`

**PrismMesh (No Direct Equivalent):**

Three.js doesn't have a built-in PrismGeometry. Options:
1. **Use CylinderGeometry** with 3 radial segments (triangle cross-section)
2. **Create custom BufferGeometry** with manually defined vertices

```javascript
// Option 1: CylinderGeometry approximation
const geometry = new THREE.CylinderGeometry(
  radiusTop,    // Top radius
  radiusBottom, // Bottom radius
  height,       // Height
  3,            // 3 radial segments = triangular
  heightSegments
);

// Option 2: Custom BufferGeometry (more accurate)
// Define vertices for triangular prism manually
```

## Implementation Notes

### Property Mapping

**PlaneMesh:**

| Godot Property | three.js Property | Conversion | Notes |
|----------------|-------------------|------------|-------|
| `size.x` | `width` | Direct copy | Width along X |
| `size.y` | `height` | Direct copy | Height along Y/Z |
| `subdivide_width` | `widthSegments` | Direct copy | Horizontal subdivisions |
| `subdivide_depth` | `heightSegments` | Direct copy | Vertical subdivisions |
| `orientation` | Rotation | Apply rotation | See orientation mapping |

**Orientation Mapping:**
- `FACE_X (0)`: Rotate plane to face X axis: `rotation.y = Math.PI / 2`
- `FACE_Y (1)`: Rotate plane to face Y axis (up): `rotation.x = -Math.PI / 2`
- `FACE_Z (2)`: Default orientation (no rotation)

**CapsuleMesh:**

| Godot Property | three.js Property | Conversion | Notes |
|----------------|-------------------|------------|-------|
| `radius` | `radius` | Direct copy | Capsule radius |
| `height` | `length` | `height - 2 * radius` | Subtract hemisphere heights |
| `radial_segments` | `radialSegments` | Direct copy | Circumference segments |
| `rings` | `capSegments` | Direct copy | Hemisphere rings |

**TorusMesh:**

| Godot Property | three.js Property | Conversion | Notes |
|----------------|-------------------|------------|-------|
| `outer_radius` | `radius` | `(outer + inner) / 2` | Distance to tube center |
| `inner_radius` | `tube` | `(outer - inner) / 2` | Tube radius |
| `rings` | `tubularSegments` | Direct copy | Around the donut |
| `ring_segments` | `radialSegments` | Direct copy | Around the tube |

**PrismMesh:**

| Godot Property | three.js Approximation | Conversion | Notes |
|----------------|------------------------|------------|-------|
| `size.x` | Custom geometry width | Scale factor | Base width |
| `size.y` | `height` | Direct copy | Prism height |
| `size.z` | Custom geometry depth | Scale factor | Base depth |
| `left_to_right` | Top vertex offset | Manual calculation | Skew factor |

### Key Considerations

**1. Plane Orientation**

Godot's `orientation` property determines which axis the plane faces. three.js PlaneGeometry always faces +Z, requiring rotation:

```typescript
function applyPlaneOrientation(mesh: THREE.Mesh, orientation: number): void {
  switch (orientation) {
    case 0: // FACE_X
      mesh.rotation.y = Math.PI / 2;
      break;
    case 1: // FACE_Y (default, facing up)
      mesh.rotation.x = -Math.PI / 2;
      break;
    case 2: // FACE_Z
      // No rotation needed
      break;
  }
}
```

**2. Capsule Height Conversion**

Godot's capsule `height` includes the hemisphere caps, while three.js `length` is only the cylindrical middle section:

```typescript
function calculateCapsuleLength(godotHeight: number, radius: number): number {
  // Godot height = cylinder length + 2 * radius (two hemisphere caps)
  // three.js length = cylinder length only
  return Math.max(0.01, godotHeight - 2 * radius);
}
```

**3. Torus Radius Calculation**

Godot uses inner and outer radii, while three.js uses center radius and tube radius:

```typescript
function calculateTorusParams(innerRadius: number, outerRadius: number) {
  const radius = (outerRadius + innerRadius) / 2;  // Distance to tube center
  const tube = (outerRadius - innerRadius) / 2;     // Tube thickness
  return { radius, tube };
}
```

**4. Prism Mesh Strategy**

Since three.js lacks PrismGeometry, use CylinderGeometry with 3 radial segments:

```typescript
function createPrismGeometry(size: Vector3, leftToRight: number): THREE.CylinderGeometry {
  // Use CylinderGeometry with 3 sides for triangular cross-section
  const geometry = new THREE.CylinderGeometry(
    size.x / 2,  // Top radius
    size.x / 2,  // Bottom radius
    size.y,      // Height
    3,           // 3 radial segments = triangle
    1            // Height segments
  );

  // Note: leftToRight parameter would require custom geometry for accurate representation
  // For now, ignore or approximate with asymmetric scaling

  return geometry;
}
```

**5. Subdivision Support**

All mesh types support subdivision parameters. Higher subdivisions create smoother geometry but increase vertex count.

## Code Examples

### PlaneMesh Implementation

```typescript
// packages/textscene-renderer/src/resources/primitives/planemesh/parser.ts
import type { TscnSubResource } from '../../../types';

export interface PlaneMeshProperties {
  size: { x: number; y: number };
  subdivideWidth: number;
  subdivideDepth: number;
  orientation: number;  // 0=FACE_X, 1=FACE_Y, 2=FACE_Z
}

export function isPlaneMesh(resource: TscnSubResource): boolean {
  return resource.type === 'PlaneMesh';
}

export function parsePlaneMesh(resource: TscnSubResource): PlaneMeshProperties {
  const props = resource.properties;

  return {
    size: parseVector2(props.size ?? 'Vector2(2, 2)'),
    subdivideWidth: parseInt(props.subdivide_width ?? '0', 10),
    subdivideDepth: parseInt(props.subdivide_depth ?? '0', 10),
    orientation: parseInt(props.orientation ?? '1', 10),
  };
}

function parseVector2(value: string): { x: number; y: number } {
  const match = value.match(/Vector2\(\s*([-\d.]+)\s*,\s*([-\d.]+)\s*\)/);
  if (match) {
    return { x: parseFloat(match[1]), y: parseFloat(match[2]) };
  }
  return { x: 2, y: 2 };
}
```

```typescript
// packages/textscene-renderer/src/resources/primitives/planemesh/renderer.ts
import * as THREE from 'three';
import type { PlaneMeshProperties } from './parser';

export function createPlaneMesh(properties: PlaneMeshProperties): THREE.PlaneGeometry {
  const geometry = new THREE.PlaneGeometry(
    properties.size.x,
    properties.size.y,
    Math.max(1, properties.subdivideWidth),
    Math.max(1, properties.subdivideDepth)
  );

  return geometry;
}

export function applyPlaneOrientation(mesh: THREE.Mesh, orientation: number): void {
  // Reset rotation
  mesh.rotation.set(0, 0, 0);

  switch (orientation) {
    case 0: // FACE_X
      mesh.rotation.y = Math.PI / 2;
      break;
    case 1: // FACE_Y (default - facing up)
      mesh.rotation.x = -Math.PI / 2;
      break;
    case 2: // FACE_Z
      // No rotation needed (default three.js orientation)
      break;
  }
}
```

```typescript
// packages/textscene-renderer/src/resources/primitives/prismmesh/renderer.ts
import * as THREE from 'three';
import type { PrismMeshProperties } from './parser';

export function createPrismMesh(properties: PrismMeshProperties): THREE.CylinderGeometry {
  // Approximate prism using CylinderGeometry with 3 radial segments
  // Note: This is a simplified approximation and doesn't fully represent
  // Godot's PrismMesh, especially the left_to_right parameter

  const geometry = new THREE.CylinderGeometry(
    properties.size.x / 2,                    // Top radius (approximate)
    properties.size.x / 2,                    // Bottom radius
    properties.size.y,                        // Height
    3,                                        // 3 radial segments = triangular
    Math.max(1, properties.subdivideHeight), // Height segments
    false                                     // Open ended = false
  );

  // Rotate to match Godot's default orientation
  geometry.rotateY(Math.PI / 6); // Align triangle

  return geometry;
}

// For more accurate representation, implement custom BufferGeometry:
export function createAccuratePrismGeometry(properties: PrismMeshProperties): THREE.BufferGeometry {
  const { size, leftToRight } = properties;
  const geometry = new THREE.BufferGeometry();

  // Define vertices for triangular prism
  const halfWidth = size.x / 2;
  const halfHeight = size.y / 2;
  const halfDepth = size.z / 2;
  const offset = leftToRight * size.x;

  // Bottom triangle vertices
  const v0 = [-halfWidth, -halfHeight, -halfDepth];
  const v1 = [halfWidth, -halfHeight, -halfDepth];
  const v2 = [0, -halfHeight, halfDepth];

  // Top triangle vertices (with offset)
  const v3 = [-halfWidth + offset, halfHeight, -halfDepth];
  const v4 = [halfWidth + offset, halfHeight, -halfDepth];
  const v5 = [offset, halfHeight, halfDepth];

  // Define faces (two triangles per face)
  const vertices = new Float32Array([
    // Bottom face
    ...v0, ...v2, ...v1,
    // Top face
    ...v3, ...v4, ...v5,
    // Side faces...
    // (Complete implementation would add all 5 faces)
  ]);

  geometry.setAttribute('position', new THREE.BufferAttribute(vertices, 3));
  geometry.computeVertexNormals();

  return geometry;
}
```
