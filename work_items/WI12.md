# WI-12: Implement OmniLight3D Node

## Overview
Implement parser and renderer for Godot's OmniLight3D node type in the TSCN renderer. OmniLight3D represents omnidirectional point lights that emit light in all directions, commonly used for lamps, candles, and local light sources.

## Implementation Requirements
- Create parser and renderer in `packages/textscene-renderer/src/nodes/omnilight3d/`
- Generate THREE.PointLight
- **Common**: Lamps, candles, point light sources

## Godot Documentation

### OmniLight3D Properties

Based on Godot's Light3D hierarchy, OmniLight3D shares common properties with other lights:

**Basic Light Properties:**
- `light_color` (Color) - The color of the light
- `light_energy` (float) - Light intensity/brightness
- `shadow_enabled` (bool) - Enable/disable shadow casting
- `shadow_bias` (float) - Prevents self-shadowing artifacts
- `shadow_normal_bias` (float) - Additional bias based on surface normal
- `shadow_filter` (enum) - Shadow quality filter (PCF3, PCF5, PCF13)

**OmniLight3D Specific Properties:**
- `omni_range` (float) - Maximum distance the light reaches
- `omni_attenuation` (float) - Attenuation curve (how light falls off with distance)
- `omni_shadow_mode` (enum) - Shadow rendering mode (DUAL_PARABOLOID or CUBE)

**Shadow Configuration Pattern:**
```gdscript
# Shadow mapping is configured on Light nodes (DirectionalLight3D, SpotLight3D, OmniLight3D)
var omni_light = OmniLight3D.new()
add_child(omni_light)

# Enable shadows
omni_light.shadow_enabled = true

# Shadow settings
omni_light.shadow_bias = 0.05
omni_light.shadow_contact_clean_offset = 0.05

# Shadow filter options
# SHADOW_FILTER_NONE, SHADOW_FILTER_PCF3, SHADOW_FILTER_PCF5
omni_light.shadow_filter = OmniLight3D.SHADOW_FILTER_PCF5

# Omni-specific: Shadow mode
# SHADOW_DUAL_PARABOLOID or SHADOW_CUBE
omni_light.omni_shadow_mode = OmniLight3D.SHADOW_CUBE
```

**Omni Shadow Modes:**
- `SHADOW_DUAL_PARABOLOID` - Faster, two shadow maps (front/back hemispheres)
- `SHADOW_CUBE` - Higher quality, six shadow maps (cubemap), more expensive

**Attenuation:**
Godot uses attenuation value to control light falloff:
- 1.0 = Linear falloff
- 2.0 = Quadratic falloff (physically accurate)
- Values between affect the curve

## Three.js Documentation

### THREE.PointLight API

**Constructor and Basic Setup:**
```javascript
const color = 0xFFFFFF;
const intensity = 100;
const distance = 10; // Maximum range
const decay = 2; // Light falloff
const light = new THREE.PointLight(color, intensity, distance, decay);
light.castShadow = true;
light.position.set(0, 5, 0);
scene.add(light);
```

**Key Properties:**
- `color` (Color) - Light color
- `intensity` (float) - Light intensity (lumens in r155+)
- `distance` (float) - Maximum range (0 = infinite)
- `decay` (float) - Light attenuation (2 = physically accurate quadratic falloff)
- `castShadow` (bool) - Whether light casts shadows
- `power` (float) - Luminous power in lumens (alternative to intensity)

**Shadow Configuration (Perspective Camera):**
PointLight uses a perspective camera for each shadow face (cubemap):
```javascript
// Shadow camera configuration
light.shadow.camera.near = 0.5;
light.shadow.camera.far = 50;
light.shadow.mapSize.width = 512;
light.shadow.mapSize.height = 512;
light.shadow.bias = -0.001;
light.shadow.radius = 4;
```

**Shadow Properties:**
- `shadow.camera.near` - Shadow camera near plane
- `shadow.camera.far` - Shadow camera far plane (should match light.distance)
- `shadow.mapSize` - Shadow map resolution per face
- `shadow.bias` - Shadow bias to prevent artifacts
- `shadow.radius` - Shadow blur radius

**Helper Visualization:**
```javascript
// Add helper for debugging
const helper = new THREE.PointLightHelper(light, 0.5);
scene.add(helper);
```

## Implementation Notes

### Property Mapping: Godot → Three.js

| Godot Property | Three.js Property | Conversion |
|---|---|---|
| `light_color` | `color` | Parse Color → hex |
| `light_energy` | `intensity` | Direct mapping (may need scaling) |
| `omni_range` | `distance` | Direct mapping |
| `omni_attenuation` | `decay` | Direct mapping (typically 2.0) |
| `shadow_enabled` | `castShadow` | Direct boolean |
| `shadow_bias` | `shadow.bias` | May need sign flip |
| `omni_shadow_mode` | N/A | three.js always uses cubemap shadows |

### Key Considerations

1. **Light Falloff**:
   - Godot: `omni_attenuation` controls falloff curve
   - three.js: `decay` parameter (typically 2 for physical accuracy)
   - Direct mapping works well

2. **Range Limit**:
   - Godot: `omni_range` defines maximum distance
   - three.js: `distance` parameter (0 = infinite)
   - Match Godot's range value

3. **Shadow Modes**:
   - Godot: DUAL_PARABOLOID (2 maps) or CUBE (6 maps)
   - three.js: Always uses cubemap (6 perspective cameras)
   - Ignore Godot's shadow mode, always use cubemap in three.js

4. **Shadow Performance**:
   - PointLight shadows are expensive (6 render passes for cubemap)
   - Consider limiting shadow map size (256 or 512)
   - Only enable shadows when necessary

5. **Intensity Scaling**:
   - May need to scale `light_energy` for three.js
   - Test with typical Godot values (0.5-2.0 range)

6. **Position Only**:
   - PointLight only needs position, not rotation
   - Extract position from Transform3D
   - Rotation is ignored

### Parser Structure
```typescript
// packages/textscene-renderer/src/nodes/omnilight3d/parser.ts
export interface OmniLight3DProperties {
  light_color: string;
  light_energy: number;
  omni_range: number;
  omni_attenuation: number;
  shadow_enabled: boolean;
  shadow_bias?: number;
  shadow_normal_bias?: number;
  shadow_filter?: number;
  omni_shadow_mode?: number;
}

export function isOmniLight3D(node: TscnNode): boolean {
  return node.type === 'OmniLight3D';
}

export function parseOmniLight3D(node: TscnNode): OmniLight3DProperties {
  return {
    light_color: node.properties.light_color || 'Color(1, 1, 1, 1)',
    light_energy: parseFloat(node.properties.light_energy) || 1.0,
    omni_range: parseFloat(node.properties.omni_range) || 5.0,
    omni_attenuation: parseFloat(node.properties.omni_attenuation) || 1.0,
    shadow_enabled: node.properties.shadow_enabled === 'true',
    shadow_bias: node.properties.shadow_bias ? parseFloat(node.properties.shadow_bias) : undefined,
    shadow_normal_bias: node.properties.shadow_normal_bias ? parseFloat(node.properties.shadow_normal_bias) : undefined,
    shadow_filter: node.properties.shadow_filter ? parseInt(node.properties.shadow_filter) : undefined,
    omni_shadow_mode: node.properties.omni_shadow_mode ? parseInt(node.properties.omni_shadow_mode) : undefined,
  };
}
```

### Renderer Structure
```typescript
// packages/textscene-renderer/src/nodes/omnilight3d/renderer.ts
import * as THREE from 'three';

export function createOmniLight3D(
  properties: OmniLight3DProperties,
  transform: Transform3D
): THREE.PointLight {
  // Parse color
  const color = parseGodotColor(properties.light_color);

  // Create light with scaled intensity
  const light = new THREE.PointLight(
    color,
    properties.light_energy * 2, // May need intensity scaling
    properties.omni_range,
    properties.omni_attenuation
  );

  // Apply transform position (rotation not needed)
  light.position.copy(transform.position);

  // Configure shadows
  if (properties.shadow_enabled) {
    light.castShadow = true;

    // Shadow camera settings
    light.shadow.camera.near = 0.5;
    light.shadow.camera.far = properties.omni_range;

    // Shadow map size based on filter quality
    const mapSize = getShadowMapSize(properties.shadow_filter);
    light.shadow.mapSize.width = mapSize;
    light.shadow.mapSize.height = mapSize;

    // Shadow bias
    if (properties.shadow_bias !== undefined) {
      light.shadow.bias = -properties.shadow_bias * 0.01; // Sign flip and scale
    } else {
      light.shadow.bias = -0.001; // Default
    }

    light.shadow.radius = 4; // Soft shadows
  }

  return light;
}

function getShadowMapSize(filter?: number): number {
  // Map Godot shadow filter to shadow map size
  // Note: PointLight uses 6 faces, so total memory is 6x this value
  switch (filter) {
    case 0: return 256;  // SHADOW_FILTER_NONE - use lower res
    case 1: return 512;  // SHADOW_FILTER_PCF3
    case 2: return 1024; // SHADOW_FILTER_PCF5
    case 3: return 1024; // SHADOW_FILTER_PCF13 - cap at 1024 for performance
    default: return 512; // Default to PCF3 equivalent
  }
}
```

```typescript
// Full renderer with all features
export function createOmniLight3D(
  properties: OmniLight3DProperties,
  transform: Transform3D
): THREE.PointLight {
  const color = parseGodotColor(properties.light_color);

  // Create PointLight
  const light = new THREE.PointLight(
    color,
    properties.light_energy * 2,
    properties.omni_range,
    properties.omni_attenuation
  );

  // Position only (rotation not needed for omnidirectional)
  light.position.copy(transform.position);

  // Configure shadows if enabled
  if (properties.shadow_enabled) {
    light.castShadow = true;

    // Shadow camera (perspective, 90° FOV for each cubemap face)
    light.shadow.camera.near = 0.5;
    light.shadow.camera.far = properties.omni_range;

    // Shadow map resolution (per face)
    const mapSize = getShadowMapSize(properties.shadow_filter);
    light.shadow.mapSize.width = mapSize;
    light.shadow.mapSize.height = mapSize;

    // Bias
    light.shadow.bias = properties.shadow_bias !== undefined
      ? -properties.shadow_bias * 0.01
      : -0.001;

    // Soft shadows
    light.shadow.radius = 4;

    // Optional: Log shadow mode for debugging
    if (properties.omni_shadow_mode !== undefined) {
      console.debug(
        `OmniLight3D shadow mode ${properties.omni_shadow_mode} ` +
        `(three.js always uses cubemap)`
      );
    }
  }

  return light;
}
```

## Performance Considerations

### Shadow Performance Impact
- PointLight shadows require 6 render passes (cubemap)
- Each face is a perspective render from light's position
- Total shadow map memory = mapSize² × 6 faces
- Example: 512×512 per face = ~1.5MB total per light

### Optimization Strategies
1. **Limit Shadow Map Size**:
   - Use 256 or 512 for most lights
   - Reserve 1024+ for key lights only

2. **Selective Shadows**:
   - Only enable shadows on important lights
   - Consider shadow distance culling

3. **Shadow Update Frequency**:
   - Static scenes: Update shadows once
   - Dynamic scenes: Update per frame (expensive)

4. **Alternative Techniques**:
   - Use fake shadows (contact shadows, AO) for small lights
   - Limit number of shadow-casting point lights to 2-3 max
