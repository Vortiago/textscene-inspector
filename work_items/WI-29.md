# WI-29: Scene-to-C# Code Generation

## Overview

Implement automatic C# code generation from TSCN scene files to reduce boilerplate when writing Godot C# scripts. This feature analyzes the scene tree structure and generates correctly-typed GetNode<T>() calls, field declarations, and optional initialization code, saving developers time and preventing typing errors.

## Implementation Requirements

From TODO.md Phase 7: C# Integration:

- Generate GetNode<T>() calls for all nodes in scene
- Create private readonly fields for node references
- Support different code generation templates (fields only, with initialization, with comments)
- Handle node naming conventions (PascalCase conversion)
- Generate code with proper indentation and formatting
- VS Code command to trigger generation
- Support inserting at cursor or replacing selection
- Handle nested node paths correctly
- Generate type-safe code using actual node types from scene
- Optional: Generate property declarations instead of fields

## Code Generation Templates

### Template 1: Field Declarations with _Ready() Initialization

```csharp
// Generated from scene: player_scene.tscn
public partial class Player : CharacterBody3D
{
    private Camera3D _camera;
    private MeshInstance3D _playerMesh;
    private CollisionShape3D _collisionShape;
    private Label _healthLabel;
    private AnimationPlayer _animationPlayer;

    public override void _Ready()
    {
        _camera = GetNode<Camera3D>("Camera3D");
        _playerMesh = GetNode<MeshInstance3D>("Mesh");
        _collisionShape = GetNode<CollisionShape3D>("CollisionShape3D");
        _healthLabel = GetNode<Label>("UI/HealthLabel");
        _animationPlayer = GetNode<AnimationPlayer>("AnimationPlayer");
    }
}
```

### Template 2: Immediate Initialization (Recommended)

```csharp
// Generated from scene: player_scene.tscn
public partial class Player : CharacterBody3D
{
    private Camera3D _camera = GetNode<Camera3D>("Camera3D");
    private MeshInstance3D _playerMesh = GetNode<MeshInstance3D>("Mesh");
    private CollisionShape3D _collisionShape = GetNode<CollisionShape3D>("CollisionShape3D");
    private Label _healthLabel = GetNode<Label>("UI/HealthLabel");
    private AnimationPlayer _animationPlayer = GetNode<AnimationPlayer>("AnimationPlayer");
}
```

**Note**: Immediate initialization is not valid in C# for instance methods. The correct approach is Template 1.

### Template 3: Property Declarations

```csharp
// Generated from scene: player_scene.tscn
public partial class Player : CharacterBody3D
{
    private Camera3D Camera => GetNode<Camera3D>("Camera3D");
    private MeshInstance3D PlayerMesh => GetNode<MeshInstance3D>("Mesh");
    private CollisionShape3D CollisionShape => GetNode<CollisionShape3D>("CollisionShape3D");
    private Label HealthLabel => GetNode<Label>("UI/HealthLabel");
    private AnimationPlayer AnimationPlayer => GetNode<AnimationPlayer>("AnimationPlayer");
}
```

**Trade-offs**:
- **Properties**: Simpler code, call GetNode on every access (performance overhead)
- **Fields + _Ready()**: Best performance, cached references, requires initialization method

### GetNode in C#

```csharp
using Godot;

public partial class MyNode : Node
{
    public override void _Ready()
    {
        // Get child node by name
        var childNode = GetNode<Node>("ChildNodeName");

        // Get node with relative path
        var siblingNode = GetNode<Node>("../SiblingNode/ChildNode");

        // Get node from UI hierarchy
        var label = GetNode<Label>("UI/HealthBar/Label");
    }
}
```

### Node Paths

- **Relative paths**: `"ChildNode"`, `"Child/GrandChild"`
- **Parent access**: `"../Sibling"`, `"../../AnotherBranch/Node"`
- **Absolute paths**: `"/root/MainScene/Player"` (rarely used in GetNode)

### C# Naming Conventions

**Godot C# follows .NET conventions**:
- Private fields: `_camelCase` with underscore prefix
- Public properties: `PascalCase`
- Methods: `PascalCase`

**Node name conversion**:
- Node name: `"player_mesh"` → Field: `_playerMesh`
- Node name: `"Camera3D"` → Field: `_camera3D` or `_camera`
- Node name: `"UI/HealthBar"` → Field: `_healthBar` (remove path)

## Implementation Notes

### Code Generator Class

```typescript
// codeGenerator.ts
import * as vscode from 'vscode';
import type { TscnNode } from '@tscn-renderer/core';

export interface CodeGenerationOptions {
  template: 'fields-with-ready' | 'properties';
  includeComments: boolean;
  fieldPrefix: string;  // Default: '_'
  nodePathStyle: 'relative' | 'absolute';
  indentation: string;  // Default: '    ' (4 spaces)
}

export class CSharpCodeGenerator {
  constructor(private options: CodeGenerationOptions) {}

  generateFromScene(
    rootNode: TscnNode,
    className: string,
    baseType: string
  ): string {
    if (this.options.template === 'properties') {
      return this.generatePropertyTemplate(rootNode, className, baseType);
    } else {
      return this.generateFieldTemplate(rootNode, className, baseType);
    }
  }

  private generateFieldTemplate(
    rootNode: TscnNode,
    className: string,
    baseType: string
  ): string {
    const nodes = this.collectChildNodes(rootNode);
    const fields = this.generateFields(nodes);
    const readyMethod = this.generateReadyMethod(nodes);

    return `// Generated from scene: ${rootNode.name || 'scene'}.tscn
public partial class ${className} : ${baseType}
{
${fields}

${readyMethod}
}`;
  }

  private generatePropertyTemplate(
    rootNode: TscnNode,
    className: string,
    baseType: string
  ): string {
    const nodes = this.collectChildNodes(rootNode);
    const properties = this.generateProperties(nodes);

    return `// Generated from scene: ${rootNode.name || 'scene'}.tscn
public partial class ${className} : ${baseType}
{
${properties}
}`;
  }

  private collectChildNodes(rootNode: TscnNode): NodeInfo[] {
    const nodes: NodeInfo[] = [];
    this.traverseNodes(rootNode, '', nodes);
    return nodes;
  }

  private traverseNodes(
    node: TscnNode,
    parentPath: string,
    result: NodeInfo[]
  ): void {
    for (const child of node.children) {
      const nodePath = parentPath ? `${parentPath}/${child.name}` : child.name;

      result.push({
        name: child.name,
        type: this.resolveNodeType(child),
        path: nodePath,
        fieldName: this.generateFieldName(child.name),
      });

      // Recursively traverse children
      if (child.children.length > 0) {
        this.traverseNodes(child, nodePath, result);
      }
    }
  }

  private resolveNodeType(node: TscnNode): string {
    // Check for attached script (custom type)
    if (node.properties.script) {
      const scriptType = this.extractScriptTypeName(node.properties.script);
      if (scriptType) {
        return scriptType;
      }
    }

    // Use Godot built-in type
    return node.type;
  }

  private extractScriptTypeName(scriptProperty: string): string | null {
    // Parse: ExtResource("1_abc123")
    // Would need to resolve through resource registry
    // For now, simplified
    return null;
  }

  private generateFieldName(nodeName: string): string {
    // Convert "player_mesh" → "_playerMesh"
    // Convert "Camera3D" → "_camera3D"
    const camelCase = this.toCamelCase(nodeName);
    return `${this.options.fieldPrefix}${camelCase}`;
  }

  private toCamelCase(str: string): string {
    // Remove special characters, split by underscore/space
    const words = str.replace(/[^a-zA-Z0-9]/g, '_').split('_');

    // First word lowercase, rest capitalized
    return words
      .map((word, index) => {
        if (index === 0) {
          return word.charAt(0).toLowerCase() + word.slice(1);
        }
        return word.charAt(0).toUpperCase() + word.slice(1);
      })
      .join('');
  }

  private generateFields(nodes: NodeInfo[]): string {
    const indent = this.options.indentation;
    return nodes
      .map(node => {
        const comment = this.options.includeComments
          ? `${indent}// ${node.path}\n`
          : '';
        return `${comment}${indent}private ${node.type} ${node.fieldName};`;
      })
      .join('\n');
  }

  private generateReadyMethod(nodes: NodeInfo[]): string {
    const indent = this.options.indentation;
    const assignments = nodes
      .map(node => {
        return `${indent}${indent}${node.fieldName} = GetNode<${node.type}>("${node.path}");`;
      })
      .join('\n');

    return `${indent}public override void _Ready()
${indent}{
${assignments}
${indent}}`;
  }

  private generateProperties(nodes: NodeInfo[]): string {
    const indent = this.options.indentation;
    return nodes
      .map(node => {
        const comment = this.options.includeComments
          ? `${indent}// ${node.path}\n`
          : '';
        const propName = this.toPascalCase(node.fieldName.substring(1)); // Remove '_' prefix
        return `${comment}${indent}private ${node.type} ${propName} => GetNode<${node.type}>("${node.path}");`;
      })
      .join('\n');
  }

  private toPascalCase(str: string): string {
    return str.charAt(0).toUpperCase() + str.slice(1);
  }
}

interface NodeInfo {
  name: string;
  type: string;
  path: string;
  fieldName: string;
}
```

### VS Code Command Registration

```typescript
// extension.ts
import * as vscode from 'vscode';
import { CSharpCodeGenerator, CodeGenerationOptions } from './codeGenerator';
import { TscnParser } from '@tscn-renderer/core';

export function activate(context: vscode.ExtensionContext) {
  // Command: Generate GetNode code
  const generateCommand = vscode.commands.registerTextEditorCommand(
    'tscn.generateGetNodeCode',
    async (textEditor: vscode.TextEditor, edit: vscode.TextEditorEdit) => {
      await generateGetNodeCode(textEditor, edit);
    }
  );

  context.subscriptions.push(generateCommand);
}

async function generateGetNodeCode(
  textEditor: vscode.TextEditor,
  edit: vscode.TextEditorEdit
): Promise<void> {
  // Find associated scene file
  const sceneUri = await findSceneForScript(textEditor.document.uri);
  if (!sceneUri) {
    vscode.window.showErrorMessage('No associated .tscn scene file found.');
    return;
  }

  // Parse scene
  const sceneDocument = await vscode.workspace.openTextDocument(sceneUri);
  const sceneText = sceneDocument.getText();

  const parser = new TscnParser();
  const scene = parser.parse(sceneText);

  // Prompt user for generation options
  const template = await vscode.window.showQuickPick(
    [
      { label: 'Fields with _Ready()', value: 'fields-with-ready' },
      { label: 'Properties (GetNode on access)', value: 'properties' },
    ],
    { placeHolder: 'Select code generation template' }
  );

  if (!template) {
    return; // User cancelled
  }

  const includeComments = await vscode.window.showQuickPick(
    [
      { label: 'Yes', value: true },
      { label: 'No', value: false },
    ],
    { placeHolder: 'Include node path comments?' }
  );

  if (includeComments === undefined) {
    return; // User cancelled
  }

  // Generate code
  const options: CodeGenerationOptions = {
    template: template.value as 'fields-with-ready' | 'properties',
    includeComments: includeComments.value,
    fieldPrefix: '_',
    nodePathStyle: 'relative',
    indentation: '    ',
  };

  const generator = new CSharpCodeGenerator(options);

  // Extract class name and base type from current C# file
  const { className, baseType } = extractClassInfo(textEditor.document);

  const generatedCode = generator.generateFromScene(
    scene.rootNode,
    className || 'GeneratedClass',
    baseType || 'Node'
  );

  // Insert at cursor position
  const position = textEditor.selection.active;
  edit.insert(position, generatedCode);

  vscode.window.showInformationMessage('GetNode code generated successfully!');
}

function extractClassInfo(document: vscode.TextDocument): {
  className: string | null;
  baseType: string | null;
} {
  const text = document.getText();

  // Match: public partial class ClassName : BaseType
  const classRegex = /public\s+partial\s+class\s+(\w+)\s*:\s*(\w+)/;
  const match = classRegex.exec(text);

  if (match) {
    return {
      className: match[1],
      baseType: match[2],
    };
  }

  return {
    className: null,
    baseType: null,
  };
}

async function findSceneForScript(
  scriptUri: vscode.Uri
): Promise<vscode.Uri | undefined> {
  // Search for .tscn files that reference this script
  const workspaceFolder = vscode.workspace.getWorkspaceFolder(scriptUri);
  if (!workspaceFolder) {
    return undefined;
  }

  const scriptPath = vscode.workspace.asRelativePath(scriptUri);

  // Find all .tscn files
  const tscnFiles = await vscode.workspace.findFiles('**/*.tscn', '**/node_modules/**');

  for (const tscnUri of tscnFiles) {
    const document = await vscode.workspace.openTextDocument(tscnUri);
    const text = document.getText();

    // Check if this scene references the script
    if (text.includes(scriptPath) || text.includes(scriptUri.fsPath)) {
      return tscnUri;
    }
  }

  return undefined;
}
```

### Advanced: Multi-Scene Code Generation

```typescript
// multiSceneGenerator.ts
export class MultiSceneCodeGenerator {
  async generateForAllScenes(
    workspaceFolder: vscode.WorkspaceFolder
  ): Promise<GenerationResult[]> {
    const results: GenerationResult[] = [];

    // Find all .tscn files
    const tscnFiles = await vscode.workspace.findFiles(
      new vscode.RelativePattern(workspaceFolder, '**/*.tscn'),
      '**/node_modules/**'
    );

    for (const tscnUri of tscnFiles) {
      // Check if C# script exists for this scene
      const scriptUri = await this.findScriptForScene(tscnUri);

      if (scriptUri) {
        // Parse scene
        const scene = await this.parseScene(tscnUri);

        // Generate code
        const generator = new CSharpCodeGenerator(this.defaultOptions);
        const code = generator.generateFromScene(
          scene.rootNode,
          path.basename(scriptUri.fsPath, '.cs'),
          scene.rootNode.type
        );

        results.push({
          sceneUri: tscnUri,
          scriptUri: scriptUri,
          generatedCode: code,
        });
      }
    }

    return results;
  }

  private async findScriptForScene(
    sceneUri: vscode.Uri
  ): Promise<vscode.Uri | undefined> {
    // Look for .cs file with same name
    const sceneName = path.basename(sceneUri.fsPath, '.tscn');
    const scriptPath = path.join(
      path.dirname(sceneUri.fsPath),
      `${sceneName}.cs`
    );

    try {
      await vscode.workspace.fs.stat(vscode.Uri.file(scriptPath));
      return vscode.Uri.file(scriptPath);
    } catch {
      return undefined;
    }
  }
}

interface GenerationResult {
  sceneUri: vscode.Uri;
  scriptUri: vscode.Uri;
  generatedCode: string;
}
```

## User Experience

### Command Execution Flow

1. **User opens C# script** (e.g., `Player.cs`)
2. **User triggers command**:
   - Right-click → "Generate GetNode Code from Scene"
   - Command Palette → "TSCN: Generate GetNode Code from Scene"
   - Keyboard shortcut: `Ctrl+Shift+G` (Windows/Linux) or `Cmd+Shift+G` (Mac)
3. **Extension finds associated .tscn file**:
   - Searches for scenes that reference this script
   - If multiple found, prompts user to select one
4. **User selects code template**:
   - Quick pick: "Fields with _Ready()" or "Properties"
5. **User chooses whether to include comments**:
   - Quick pick: "Yes" or "No"
6. **Code is generated and inserted** at cursor position
7. **Success notification** appears
