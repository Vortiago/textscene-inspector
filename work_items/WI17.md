# WI-17: Custom Shader Support

## Overview

Implement conversion from Godot Shading Language (GSL) to GLSL for three.js ShaderMaterial. This work item enables full custom shader support by translating Godot's `.gdshader` files to three.js-compatible vertex and fragment shaders. It builds on WI-16's ShaderMaterial parameter parsing by adding shader code conversion capabilities.

From TODO.md Phase 4: Advanced Features:

- Map Godot built-in variables to three.js equivalents

- Handle shader preprocessor directives
- Support common shader patterns (texture sampling, lighting, transformations)
- Provide comprehensive built-in variable mapping

- Handle unsupported features with graceful fallbacks
- Support shader hints and annotations

## Godot Documentation

### Godot Shading Language Structure

From Context7 research on `websites/godotengine_en_stable`:

Godot Shading Language is a high-level shading language similar to GLSL but with Godot-specific built-in variables and functions. Shaders are divided into processor functions: `vertex()`, `fragment()`, and `light()`.

**Shader File Structure (`.gdshader`):**

```glsl
shader_type spatial;  // Type: spatial, canvas_item, particles, sky, fog

// Render modes (optional)
render_mode blend_mix, depth_draw_opaque, cull_back;

// Uniforms (shader parameters)
uniform vec4 tint_color : source_color = vec4(1.0);
uniform float intensity : hint_range(0.0, 10.0) = 1.0;
uniform sampler2D texture_albedo : source_color;

// Global variables (shared across functions)
varying vec3 custom_data;

// Vertex processor
void vertex() {
    // Built-in inputs: VERTEX, NORMAL, TANGENT, BINORMAL, UV, UV2, COLOR
    // Built-in outputs: VERTEX, NORMAL, TANGENT, BINORMAL, POSITION

    VERTEX.y += sin(TIME + VERTEX.x) * 0.1;
    custom_data = NORMAL;
}

// Fragment processor
void fragment() {
    // Built-in inputs: FRAGCOORD, NORMAL, TANGENT, BINORMAL, UV, UV2, COLOR
    // Built-in outputs: ALBEDO, ALPHA, METALLIC, ROUGHNESS, EMISSION, NORMAL_MAP, etc.

    vec4 tex = texture(texture_albedo, UV);
    ALBEDO = tex.rgb * tint_color.rgb * intensity;
    ALPHA = tex.a;
}

// Light processor (optional)
void light() {
    // Built-in inputs: LIGHT_COLOR, LIGHT_DIRECTION, ATTENUATION
    // Built-in outputs: DIFFUSE_LIGHT, SPECULAR_LIGHT

    DIFFUSE_LIGHT += LIGHT_COLOR * ATTENUATION;
}
```

**Spatial Shader Built-in Variables:**

**Global Built-ins:**
- `TIME` - Elapsed time in seconds
- `WORLD_MATRIX` - Object's world transformation matrix
- `PROJECTION_MATRIX` - Camera projection matrix
- `VIEW_MATRIX` - Camera view matrix
- `INV_VIEW_MATRIX` - Inverse view matrix

**Vertex Built-ins:**

Inputs:
- `VERTEX` - Vertex position in model space (vec3)
- `NORMAL` - Vertex normal in model space (vec3)
- `TANGENT` - Vertex tangent in model space (vec3)
- `BINORMAL` - Vertex binormal in model space (vec3)
- `UV` - First UV coordinate (vec2)
- `UV2` - Second UV coordinate (vec2)
- `COLOR` - Vertex color (vec4)

Outputs:
- `VERTEX` - Modified vertex position
- `NORMAL` - Modified normal
- `POSITION` - Clip space position (auto-calculated if not set)

**Fragment Built-ins:**

Inputs:
- `FRAGCOORD` - Fragment coordinate in screen space (vec4)
- `NORMAL` - Interpolated normal (vec3)
- `UV` - Interpolated UV coordinates (vec2)
- `UV2` - Second UV coordinates (vec2)
- `COLOR` - Interpolated vertex color (vec4)

Outputs:
- `ALBEDO` - Base color (vec3)
- `ALPHA` - Transparency (float, 0-1)
- `METALLIC` - Metallic property (float, 0-1)
- `ROUGHNESS` - Roughness property (float, 0-1)
- `EMISSION` - Emissive color (vec3)
- `NORMAL_MAP` - Normal map value (vec3)
- `AO` - Ambient occlusion (float)
- `SPECULAR` - Specular intensity (float)

**Shader Types:**

| Type | Usage | Key Features |
|------|-------|--------------|
| `spatial` | 3D materials | vertex(), fragment(), light() functions |
| `canvas_item` | 2D materials | vertex(), fragment(), light() functions |
| `particles` | Particle systems | start(), process() functions |
| `sky` | Sky shaders | sky(), fragment() functions |
| `fog` | Volumetric fog | fog() function |

For this work item, we focus on `shader_type spatial`.

## Three.js Documentation

### GLSL Shader Structure in three.js

From Context7 research on `/mrdoob/three.js`:

Three.js uses standard GLSL ES shaders with automatic injection of common uniforms and attributes.

**ShaderMaterial GLSL Structure:**

```javascript
const material = new THREE.ShaderMaterial({
  uniforms: {
    tint_color: { value: new THREE.Color(1, 1, 1) },
    intensity: { value: 1.0 },
    texture_albedo: { value: texture },
    time: { value: 0.0 }
  },
  vertexShader: `
    // Automatic uniforms from three.js
    uniform mat4 modelMatrix;
    uniform mat4 modelViewMatrix;
    uniform mat4 projectionMatrix;
    uniform mat4 viewMatrix;
    uniform mat3 normalMatrix;
    uniform vec3 cameraPosition;

    // Automatic attributes
    attribute vec3 position;
    attribute vec3 normal;
    attribute vec2 uv;
    attribute vec4 color;

    // Custom uniforms
    uniform float time;

    // Varyings to fragment shader
    varying vec2 vUv;
    varying vec3 vNormal;
    varying vec3 vPosition;

    void main() {
      vUv = uv;
      vNormal = normalize(normalMatrix * normal);

      vec3 transformed = position;
      transformed.y += sin(time + position.x) * 0.1;

      vPosition = (modelViewMatrix * vec4(transformed, 1.0)).xyz;
      gl_Position = projectionMatrix * modelViewMatrix * vec4(transformed, 1.0);
    }
  `,
  fragmentShader: `
    precision highp float;

    // Custom uniforms
    uniform vec3 tint_color;
    uniform float intensity;
    uniform sampler2D texture_albedo;

    // Varyings from vertex shader
    varying vec2 vUv;
    varying vec3 vNormal;
    varying vec3 vPosition;

    void main() {
      vec4 texColor = texture2D(texture_albedo, vUv);

      // Simple lighting
      vec3 lightDir = normalize(vec3(1.0, 1.0, 1.0));
      float lightIntensity = max(dot(vNormal, lightDir), 0.0) * 0.8 + 0.2;

      vec3 color = texColor.rgb * tint_color * intensity * lightIntensity;
      gl_FragColor = vec4(color, texColor.a);
    }
  `
});
```

**Three.js Automatic Uniforms:**

These are automatically available in shaders:

```glsl
// Matrices
uniform mat4 modelMatrix;
uniform mat4 modelViewMatrix;
uniform mat4 projectionMatrix;
uniform mat4 viewMatrix;
uniform mat3 normalMatrix;

// Camera
uniform vec3 cameraPosition;
uniform float cameraNear;
uniform float cameraFar;

// Time (not automatic, usually added manually)
uniform float time;
```

**Three.js Automatic Attributes:**

```glsl
attribute vec3 position;   // Vertex position
attribute vec3 normal;     // Vertex normal
attribute vec2 uv;         // UV coordinates
attribute vec2 uv2;        // Second UV set
attribute vec4 color;      // Vertex color
attribute vec3 tangent;    // Tangent vector
```

### Key Considerations

**1. Shader Type Declaration**

Godot:
```glsl
shader_type spatial;
```

three.js: Implicit - separate vertex and fragment shaders

**2. Processor Functions**

Godot has three processor functions in one file:
```glsl
void vertex() { ... }
void fragment() { ... }
void light() { ... }
```

three.js requires two separate shaders:
- Convert `vertex()` → vertexShader
- Convert `fragment()` → fragmentShader
- Convert `light()` → integrate into fragmentShader with lighting calculations

**3. Varying Variables**

Godot:
```glsl
varying vec3 custom_data;

void vertex() {
    custom_data = NORMAL;
}

void fragment() {
    ALBEDO = custom_data;
}
```

three.js:
```glsl
// Vertex shader
varying vec3 custom_data;
void main() {
    custom_data = normal;
    ...
}

// Fragment shader
varying vec3 custom_data;
void main() {
    gl_FragColor = vec4(custom_data, 1.0);
}
```

**4. Output Variables**

Godot uses named outputs:
```glsl
ALBEDO = vec3(1.0);
ALPHA = 0.5;
```

three.js uses `gl_FragColor`:
```glsl
gl_FragColor = vec4(ALBEDO, ALPHA);
```

**5. Texture Sampling**

Godot:
```glsl
vec4 color = texture(texture_albedo, UV);
```

three.js (GLSL ES 1.0):
```glsl
vec4 color = texture2D(texture_albedo, vUv);
```

**6. Material Properties (PBR)**

Godot's `METALLIC`, `ROUGHNESS`, etc., are part of the PBR lighting model. In three.js ShaderMaterial without built-in lighting, you must implement lighting manually or use MeshStandardMaterial as a base.

For custom shaders, simplified approach:
- Ignore PBR outputs initially
- Focus on ALBEDO and ALPHA
- Future: Implement custom PBR lighting in fragment shader

**7. Render Modes**

Godot:
```glsl
render_mode blend_mix, depth_draw_opaque, cull_back;
```

three.js (material properties):
```javascript
material.blending = THREE.NormalBlending;
material.depthWrite = true;
material.side = THREE.FrontSide;
```

Parse render modes and set material properties accordingly.

### Conversion Strategy

**Phase 1: Basic Conversion (This WI)**

1. Parse `.gdshader` file structure
2. Extract uniform declarations
3. Extract varying declarations
4. Extract vertex() function body
5. Extract fragment() function body
6. Map built-in variables
7. Convert function calls (texture → texture2D)
8. Generate three.js vertex and fragment shaders
9. Handle output variable consolidation (ALBEDO/ALPHA → gl_FragColor)

**Phase 2: Advanced Features (Future)**

- Light function conversion
- Custom lighting models
- Advanced render modes
- Shader includes and libraries

### Shader Parser

```typescript
// packages/textscene-renderer/src/resources/shader/parser.ts
import type { ExtResource } from '../../types';

export interface ParsedShader {
  shaderType: 'spatial' | 'canvas_item' | 'particles' | 'sky' | 'fog';
  renderModes: string[];
  uniforms: UniformDeclaration[];
  varyings: VaryingDeclaration[];
  globalCode: string;
  vertexCode: string;
  fragmentCode: string;
  lightCode: string;
}

export interface UniformDeclaration {
  name: string;
  type: string;  // 'float', 'vec2', 'vec3', 'vec4', 'sampler2D', etc.
  hint?: string;  // 'source_color', 'hint_range', etc.
  defaultValue?: string;
}

export interface VaryingDeclaration {
  name: string;
  type: string;
}

export function parseGodotShader(shaderCode: string): ParsedShader {
  const lines = shaderCode.split('\n');

  const result: ParsedShader = {
    shaderType: 'spatial',
    renderModes: [],
    uniforms: [],
    varyings: [],
    globalCode: '',
    vertexCode: '',
    fragmentCode: '',
    lightCode: '',
  };

  // Parse shader_type
  const shaderTypeMatch = shaderCode.match(/shader_type\s+(\w+)/);
  if (shaderTypeMatch) {
    result.shaderType = shaderTypeMatch[1] as any;
  }

  // Parse render_mode
  const renderModeMatch = shaderCode.match(/render_mode\s+([^;]+);/);
  if (renderModeMatch) {
    result.renderModes = renderModeMatch[1].split(',').map(m => m.trim());
  }

  // Parse uniforms
  const uniformRegex = /uniform\s+(\w+)\s+(\w+)(?:\s*:\s*([^=;]+))?(?:\s*=\s*([^;]+))?;/g;
  let match;
  while ((match = uniformRegex.exec(shaderCode)) !== null) {
    result.uniforms.push({
      name: match[2],
      type: match[1],
      hint: match[3]?.trim(),
      defaultValue: match[4]?.trim(),
    });
  }

  // Parse varyings
  const varyingRegex = /varying\s+(\w+)\s+(\w+);/g;
  while ((match = varyingRegex.exec(shaderCode)) !== null) {
    result.varyings.push({
      name: match[2],
      type: match[1],
    });
  }

  // Extract function bodies
  result.vertexCode = extractFunctionBody(shaderCode, 'vertex');
  result.fragmentCode = extractFunctionBody(shaderCode, 'fragment');
  result.lightCode = extractFunctionBody(shaderCode, 'light');

  // Extract global code (outside of functions)
  result.globalCode = extractGlobalCode(shaderCode);

  return result;
}

function extractFunctionBody(code: string, functionName: string): string {
  const regex = new RegExp(`void\\s+${functionName}\\s*\\(\\)\\s*\\{([^}]*)\\}`, 's');
  const match = code.match(regex);
  return match ? match[1].trim() : '';
}

function extractGlobalCode(code: string): string {
  // Remove shader_type, render_mode, uniforms, varyings, and functions
  let global = code;
  global = global.replace(/shader_type\s+\w+;/g, '');
  global = global.replace(/render_mode\s+[^;]+;/g, '');
  global = global.replace(/uniform\s+[^;]+;/g, '');
  global = global.replace(/varying\s+[^;]+;/g, '');
  global = global.replace(/void\s+\w+\s*\([^)]*\)\s*\{[^}]*\}/gs, '');
  return global.trim();
}
```

```typescript
// packages/textscene-renderer/src/resources/shader/builtinMapper.ts

export interface BuiltinMapping {
  godotName: string;
  glslName: string;
  isAttribute?: boolean;
  isUniform?: boolean;
  isVarying?: boolean;
  requiresDeclaration?: boolean;
}

export const vertexBuiltins: BuiltinMapping[] = [
  // Attributes (inputs)
  { godotName: 'VERTEX', glslName: 'position', isAttribute: true },
  { godotName: 'NORMAL', glslName: 'normal', isAttribute: true },
  { godotName: 'TANGENT', glslName: 'tangent', isAttribute: true },
  { godotName: 'UV', glslName: 'uv', isAttribute: true },
  { godotName: 'UV2', glslName: 'uv2', isAttribute: true },
  { godotName: 'COLOR', glslName: 'color', isAttribute: true },

  // Uniforms
  { godotName: 'TIME', glslName: 'time', isUniform: true },
  { godotName: 'WORLD_MATRIX', glslName: 'modelMatrix', isUniform: true },
  { godotName: 'PROJECTION_MATRIX', glslName: 'projectionMatrix', isUniform: true },
  { godotName: 'VIEW_MATRIX', glslName: 'viewMatrix', isUniform: true },
  { godotName: 'MODEL_MATRIX', glslName: 'modelMatrix', isUniform: true },
  { godotName: 'MODELVIEW_MATRIX', glslName: 'modelViewMatrix', isUniform: true },

  // Output
  { godotName: 'POSITION', glslName: 'gl_Position' },
];

export const fragmentBuiltins: BuiltinMapping[] = [
  // Inputs (varyings from vertex shader)
  { godotName: 'NORMAL', glslName: 'vNormal', isVarying: true, requiresDeclaration: true },
  { godotName: 'UV', glslName: 'vUv', isVarying: true, requiresDeclaration: true },
  { godotName: 'UV2', glslName: 'vUv2', isVarying: true, requiresDeclaration: true },
  { godotName: 'COLOR', glslName: 'vColor', isVarying: true, requiresDeclaration: true },

  // Built-ins
  { godotName: 'FRAGCOORD', glslName: 'gl_FragCoord' },

  // Outputs (handled specially - converted to gl_FragColor)
  { godotName: 'ALBEDO', glslName: '_albedo', requiresDeclaration: true },
  { godotName: 'ALPHA', glslName: '_alpha', requiresDeclaration: true },
  { godotName: 'EMISSION', glslName: '_emission', requiresDeclaration: true },
  { godotName: 'METALLIC', glslName: '_metallic', requiresDeclaration: true },
  { godotName: 'ROUGHNESS', glslName: '_roughness', requiresDeclaration: true },
];

export function mapBuiltinVariables(
  code: string,
  builtins: BuiltinMapping[]
): string {
  let result = code;

  for (const builtin of builtins) {
    // Use word boundary to avoid partial replacements
    const regex = new RegExp(`\\b${builtin.godotName}\\b`, 'g');
    result = result.replace(regex, builtin.glslName);
  }

  return result;
}

export function generateVaryingDeclarations(
  usedBuiltins: string[],
  builtins: BuiltinMapping[]
): string {
  const declarations: string[] = [];

  for (const builtin of builtins) {
    if (builtin.requiresDeclaration && usedBuiltins.includes(builtin.godotName)) {
      const type = inferVaryingType(builtin.godotName);
      declarations.push(`varying ${type} ${builtin.glslName};`);
    }
  }

  return declarations.join('\n');
}

function inferVaryingType(godotName: string): string {
  const typeMap: Record<string, string> = {
    'NORMAL': 'vec3',
    'UV': 'vec2',
    'UV2': 'vec2',
    'COLOR': 'vec4',
    'ALBEDO': 'vec3',
    'ALPHA': 'float',
    'EMISSION': 'vec3',
    'METALLIC': 'float',
    'ROUGHNESS': 'float',
  };
  return typeMap[godotName] || 'vec3';
}
```

### Shader Converter

```typescript
// packages/textscene-renderer/src/resources/shader/converter.ts
import type { ParsedShader } from './parser';
import { mapBuiltinVariables, vertexBuiltins, fragmentBuiltins } from './builtinMapper';

export interface ConvertedShader {
  vertexShader: string;
  fragmentShader: string;
  requiredUniforms: string[];
}

export function convertGodotShaderToGLSL(parsed: ParsedShader): ConvertedShader {
  const vertexShader = generateVertexShader(parsed);
  const fragmentShader = generateFragmentShader(parsed);
  const requiredUniforms = extractRequiredUniforms(parsed);

  return {
    vertexShader,
    fragmentShader,
    requiredUniforms,
  };
}

function generateVertexShader(parsed: ParsedShader): string {
  const parts: string[] = [];

  // Add precision
  parts.push('precision highp float;');
  parts.push('');

  // Add three.js automatic uniforms (already available, just document)
  parts.push('// Three.js automatic uniforms: modelMatrix, modelViewMatrix, projectionMatrix, normalMatrix');
  parts.push('// Three.js automatic attributes: position, normal, uv, uv2, color, tangent');
  parts.push('');

  // Add custom uniforms
  for (const uniform of parsed.uniforms) {
    if (uniform.type !== 'sampler2D') {
      parts.push(`uniform ${uniform.type} ${uniform.name};`);
    }
  }
  parts.push('');

  // Add time uniform if used
  if (parsed.vertexCode.includes('TIME')) {
    parts.push('uniform float time;');
    parts.push('');
  }

  // Add varyings
  for (const varying of parsed.varyings) {
    parts.push(`varying ${varying.type} ${varying.name};`);
  }

  // Add standard varyings for fragment shader
  if (parsed.fragmentCode) {
    parts.push('varying vec2 vUv;');
    parts.push('varying vec3 vNormal;');
    parts.push('varying vec3 vPosition;');
  }
  parts.push('');

  // Add global code
  if (parsed.globalCode) {
    parts.push(parsed.globalCode);
    parts.push('');
  }

  // Add main function
  parts.push('void main() {');

  // Initialize varyings
  parts.push('  vUv = uv;');
  parts.push('  vNormal = normalize(normalMatrix * normal);');
  parts.push('  ');

  // Convert vertex code
  let vertexCode = parsed.vertexCode || '';
  vertexCode = mapBuiltinVariables(vertexCode, vertexBuiltins);
  vertexCode = convertTextureCalls(vertexCode);

  // Indent vertex code
  const indentedVertexCode = vertexCode.split('\n').map(line => '  ' + line).join('\n');
  parts.push(indentedVertexCode);
  parts.push('  ');

  // Calculate position if not explicitly set
  if (!vertexCode.includes('gl_Position')) {
    parts.push('  vec3 transformed = position;');
    parts.push('  vPosition = (modelViewMatrix * vec4(transformed, 1.0)).xyz;');
    parts.push('  gl_Position = projectionMatrix * modelViewMatrix * vec4(transformed, 1.0);');
  }

  parts.push('}');

  return parts.join('\n');
}

function generateFragmentShader(parsed: ParsedShader): string {
  const parts: string[] = [];

  // Add precision
  parts.push('precision highp float;');
  parts.push('');

  // Add custom uniforms
  for (const uniform of parsed.uniforms) {
    parts.push(`uniform ${uniform.type} ${uniform.name};`);
  }
  parts.push('');

  // Add varyings (matching vertex shader)
  for (const varying of parsed.varyings) {
    parts.push(`varying ${varying.type} ${varying.name};`);
  }
  parts.push('varying vec2 vUv;');
  parts.push('varying vec3 vNormal;');
  parts.push('varying vec3 vPosition;');
  parts.push('');

  // Add global code
  if (parsed.globalCode) {
    parts.push(parsed.globalCode);
    parts.push('');
  }

  // Add main function
  parts.push('void main() {');

  // Declare output variables
  parts.push('  vec3 _albedo = vec3(1.0);');
  parts.push('  float _alpha = 1.0;');
  parts.push('  vec3 _emission = vec3(0.0);');
  parts.push('  ');

  // Convert fragment code
  let fragmentCode = parsed.fragmentCode || '';
  fragmentCode = mapBuiltinVariables(fragmentCode, fragmentBuiltins);
  fragmentCode = convertTextureCalls(fragmentCode);

  // Indent fragment code
  const indentedFragmentCode = fragmentCode.split('\n').map(line => '  ' + line).join('\n');
  parts.push(indentedFragmentCode);
  parts.push('  ');

  // Output final color
  parts.push('  gl_FragColor = vec4(_albedo + _emission, _alpha);');

  parts.push('}');

  return parts.join('\n');
}

function convertTextureCalls(code: string): string {
  // Convert Godot's texture() to GLSL's texture2D()
  return code.replace(/\btexture\s*\(/g, 'texture2D(');
}

function extractRequiredUniforms(parsed: ParsedShader): string[] {
  const uniforms: string[] = [];

  // Add custom uniforms
  for (const uniform of parsed.uniforms) {
    uniforms.push(uniform.name);
  }

  // Add time if used
  if (parsed.vertexCode.includes('TIME') || parsed.fragmentCode.includes('TIME')) {
    uniforms.push('time');
  }

  return uniforms;
}
```

### Integration with ShaderMaterial

```typescript
// packages/textscene-renderer/src/resources/shader/renderer.ts
import * as THREE from 'three';
import type { ParsedShader } from './parser';
import type { ConvertedShader } from './converter';
import { parseGodotShader } from './parser';
import { convertGodotShaderToGLSL } from './converter';

export async function loadAndConvertShader(
  shaderPath: string
): Promise<ConvertedShader> {
  // Load shader file content
  const shaderCode = await loadShaderFile(shaderPath);

  // Parse Godot shader
  const parsed = parseGodotShader(shaderCode);

  // Convert to GLSL
  const converted = convertGodotShaderToGLSL(parsed);

  return converted;
}

export function createShaderMaterialFromConverted(
  converted: ConvertedShader,
  uniforms: { [key: string]: { value: any } }
): THREE.ShaderMaterial {
  // Add time uniform if required
  if (converted.requiredUniforms.includes('time')) {
    uniforms.time = { value: 0.0 };
  }

  const material = new THREE.ShaderMaterial({
    uniforms,
    vertexShader: converted.vertexShader,
    fragmentShader: converted.fragmentShader,
    lights: false,
```
