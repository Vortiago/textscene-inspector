# WI-53: External Material Loading

## Overview
Implement loading and application of external material resources (.tres files) referenced in TSCN files. This enables material reuse across multiple scenes and nodes - a common optimization pattern in Godot projects.

## Current State

**What Exists:**
- ✅ `ResourceRegistry` parses and registers `[ext_resource type="StandardMaterial3D"]` headings
- ✅ `ResourceProvider` interface supports loading text resources (returns `string`)
- ✅ Material parsing logic exists for SubResource materials

**What's Missing:**
- ❌ No loading of external .tres material files
- ❌ No parsing of Godot resource format (.tres)
- ❌ External materials are registered but never loaded
- ❌ No support for `surface_material_override/0 = ExtResource("mat_id")`

## Godot Resource Format (.tres)

External materials are saved in Godot's text resource format:

```tres
[gd_resource type="StandardMaterial3D" format=3]

[resource]
albedo_color = Color(0.8, 0.2, 0.2, 1)
metallic = 0.7
roughness = 0.3
emission_enabled = true
emission = Color(1, 0.5, 0, 1)
emission_energy_multiplier = 2.0
```

This is similar to TSCN format but:
- Starts with `[gd_resource ...]` instead of `[gd_scene ...]`
- Has a single `[resource]` section with properties
- No nodes, just resource data

## Implementation Requirements

### 1. Resource Format Parser

Create a parser for .tres files:

```typescript
// packages/textscene-core/src/parser/resourceParsers.ts

/**
 * Parse Godot resource file (.tres) format
 */
export function parseResourceFile(content: string): {
  type: string;
  properties: Record<string, unknown>;
} {
  const lines = content.split('\n');

  // Parse header: [gd_resource type="StandardMaterial3D" format=3]
  const headerLine = lines.find(line => line.startsWith('[gd_resource'));
  if (!headerLine) {
    throw new Error('Invalid .tres file: missing [gd_resource] header');
  }

  const typeMatch = headerLine.match(/type="([^"]+)"/);
  if (!typeMatch) {
    throw new Error('Invalid .tres file: missing type attribute');
  }
  const resourceType = typeMatch[1];

  // Find [resource] section
  const resourceIndex = lines.findIndex(line => line.trim() === '[resource]');
  if (resourceIndex === -1) {
    throw new Error('Invalid .tres file: missing [resource] section');
  }

  // Parse properties until next section or EOF
  const properties: Record<string, unknown> = {};
  for (let i = resourceIndex + 1; i < lines.length; i++) {
    const line = lines[i].trim();

    // Stop at next section
    if (line.startsWith('[')) break;

    // Skip empty lines and comments
    if (!line || line.startsWith(';')) continue;

    // Parse property: key = value
    const match = line.match(/^(\w+)\s*=\s*(.+)$/);
    if (match) {
      const [, key, valueStr] = match;
      properties[key] = parsePropertyValue(valueStr);
    }
  }

  return { type: resourceType, properties };
}

/**
 * Parse property value (Color, Vector3, numbers, strings, etc.)
 */
function parsePropertyValue(valueStr: string): unknown {
  // Color(r, g, b, a)
  const colorMatch = valueStr.match(/Color\(([^)]+)\)/);
  if (colorMatch) {
    const [r, g, b, a] = colorMatch[1].split(',').map(s => parseFloat(s.trim()));
    return { type: 'Color', r, g, b, a };
  }

  // Vector3(x, y, z)
  const vec3Match = valueStr.match(/Vector3\(([^)]+)\)/);
  if (vec3Match) {
    const [x, y, z] = vec3Match[1].split(',').map(s => parseFloat(s.trim()));
    return { type: 'Vector3', x, y, z };
  }

  // Boolean
  if (valueStr === 'true') return true;
  if (valueStr === 'false') return false;

  // Number
  const num = parseFloat(valueStr);
  if (!isNaN(num)) return num;

  // String (remove quotes)
  if (valueStr.startsWith('"') && valueStr.endsWith('"')) {
    return valueStr.slice(1, -1);
  }

  // Default: return as string
  return valueStr;
}
```

### 2. Extend ResourceRegistry

Add material loading method:

```typescript
// packages/textscene-core/src/resources/ResourceRegistry.ts

/**
 * Load external material resource (.tres file)
 */
async loadMaterial(idOrPath: string): Promise<THREE.Material> {
  // 1. Get resource metadata
  const resource = this.getMetadata(idOrPath);
  if (!resource || !resource.type.includes('Material')) {
    throw new Error(`Not a material resource: ${idOrPath}`);
  }

  // 2. Load raw content via provider (returns string)
  const content = await this.loadByPath(resource.path);
  if (typeof content !== 'string') {
    throw new Error(`Material must be text content: ${resource.path}`);
  }

  // 3. Parse .tres file
  const { type, properties } = parseResourceFile(content);

  // 4. Parse material based on type
  switch (type) {
    case 'StandardMaterial3D':
      const matProps = await parseStandardMaterial3D(properties, this);
      return createStandardMaterial(matProps);

    case 'ShaderMaterial':
      // Future: WI-16
      throw new Error('ShaderMaterial not yet supported');

    default:
      throw new Error(`Unsupported material type: ${type}`);
  }
}
```

### 3. Update MeshInstance3D Parser

Detect external material references:

```typescript
// packages/textscene-core/src/nodes/3d/meshinstance3d/parser.ts

export async function parseMeshInstance3D(
  node: TscnNode,
  scene: TscnScene
): Promise<MeshInstance3DProperties> {
  // ... existing code ...

  // Check for external material override
  const registry = scene.resourceRegistry;
  if (registry) {
    const materialOverride = node.properties.surface_material_override;

    if (typeof materialOverride === 'object') {
      // Check each surface override (0, 1, 2, ...)
      for (const [surfaceIdx, materialRef] of Object.entries(materialOverride)) {
        const extRef = ResourceRegistry.parseReference(materialRef as string);
        if (extRef) {
          // Load external material
          const material = await registry.loadMaterial(extRef);
          properties.materialOverrides = properties.materialOverrides || {};
          properties.materialOverrides[surfaceIdx] = material;
        }
      }
    } else if (typeof materialOverride === 'string') {
      // Single material override
      const extRef = ResourceRegistry.parseReference(materialOverride);
      if (extRef) {
        const material = await registry.loadMaterial(extRef);
        properties.materialOverrides = { '0': material };
      }
    }
  }

  return properties;
}
```

### 4. TSCN Usage Pattern

External materials are referenced like this:

```tscn
[gd_scene format=3]

[ext_resource type="StandardMaterial3D" path="res://materials/metal.tres" id="1_metal"]
[ext_resource type="StandardMaterial3D" path="res://materials/wood.tres" id="2_wood"]

[sub_resource type="BoxMesh" id="mesh_1"]

[node name="MetalCube" type="MeshInstance3D"]
mesh = SubResource("mesh_1")
surface_material_override/0 = ExtResource("1_metal")

[node name="WoodenCube" type="MeshInstance3D"]
transform = Transform3D(1, 0, 0, 0, 1, 0, 0, 0, 1, 3, 0, 0)
mesh = SubResource("mesh_1")
surface_material_override/0 = ExtResource("2_wood")
```

  it('should parse StandardMaterial3D .tres file', () => {

albedo_color = Color(0.8, 0.2, 0.2, 1)
metallic = 0.7
roughness = 0.3

    expect(properties.albedo_color).toEqual({
      type: 'Color',
      r: 0.8,

      b: 0.2,
      a: 1

    expect(properties.roughness).toBe(0.3);

    expect(Object.keys(properties)).toHaveLength(0);

## Architecture Considerations

### Material Caching

External materials should be cached and reused:

```typescript
private materialCache: Map<string, THREE.Material> = new Map();

async loadMaterial(idOrPath: string): Promise<THREE.Material> {
  // Check cache first
  const cached = this.materialCache.get(idOrPath);
  if (cached) return cached;

  // Load and cache
  const material = await this.loadMaterialImpl(idOrPath);
  this.materialCache.set(idOrPath, material);
  return material;
}
```

**Benefits:**
- Multiple nodes can share the same material instance
- Memory efficient
- Changes to material properties affect all users

### Parser Reuse

The `.tres` parser should be generic enough to support other resource types:
- StandardMaterial3D ✅
- ShaderMaterial (future)
- Environment (future)
- Custom resources (future)

### Error Handling

When material loading fails:
1. Log warning with material path
2. Return default gray material (fallback)
3. Continue rendering with fallback material
4. Optionally call `onResourceNeeded` callback
