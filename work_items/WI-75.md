# WI-75: Proximity Fade Enable Flag (StandardMaterial3D)

**Status**: Deferred
**Priority**: Low
**Complexity**: Moderate
**Impact**: Distance-based transparency fade

## Overview

Proximity fade makes materials transparent when near other objects or the camera, useful for foliage, walls, or UI elements. Godot's `proximity_fade_enabled`.

**Note**: This is **NOT a texture feature** - it's a distance-based effect.

**TSCN Properties**:
- `proximity_fade_enabled` - Enable flag
- `proximity_fade_distance` - Fade distance threshold

**Three.js Support**: Requires custom shader with depth buffer access.

## Defer Reason

- Not a texture feature (different from other WI-63 follow-ups)
- Requires depth buffer access and custom shader
- Not found in current repository fixtures
- No user requests
