# WI-67: Rim Lighting Enable Flag (StandardMaterial3D)

**Status**: Not Started
**Priority**: Medium
**Complexity**: Moderate
**Impact**: Edge highlighting effect for stylized rendering

## Overview

### Problem Statement

Rim lighting (Fresnel effect) increases brightness at glancing angles, creating edge highlights. Commonly used for stylized rendering, sci-fi effects, and character outlines. Godot's `FEATURE_RIM` requires an enable flag.

**Godot Feature**: `FEATURE_RIM` → `rim_enabled` in TSCN

**TSCN Format**:
```tscn
[sub_resource type="StandardMaterial3D" id="Material_1"]
albedo_color = Color(0.2, 0.4, 0.9, 1)
rim_enabled = true
rim = 1.0
rim_tint = 0.5
rim_texture = ExtResource("1_rim")
```

### Three.js Implementation Challenge

Three.js `MeshStandardMaterial` does **NOT have native rim lighting support**. Two implementation options:

**Option 1: Emissive Approximation** (Simple, Limited)
- Use emissive channel to approximate rim effect
- Calculate Fresnel in shader uniform
- Limited control, may conflict with actual emission

**Option 2: Custom Shader** (Accurate, Complex)
- Extend MeshStandardMaterial with custom shader chunks
- Implement proper Fresnel rim calculation
- Full control over rim tint and intensity

**Recommendation**: Start with Option 1 (emissive approximation), document limitations, consider custom shader in future work item.

## Implementation Plan (Emissive Approximation)

### 1. Update Types

```typescript
export interface StandardMaterial3DProperties {
  // Feature enable flags
  rim_enabled?: boolean;  // ADD

  // Texture maps
  rim_texture?: THREE.Texture;  // ADD

  // Rim properties
  rim?: number;  // Rim strength (0-inf), default 1.0
  rim_tint?: number;  // Blend between light and albedo (0-1), default 0.5
}
```

### 2. Update Parser

```typescript
if (properties.rim_enabled !== undefined) {
  result.rim_enabled = properties.rim_enabled === 'true';
}

// Parse rim strength
if (properties.rim !== undefined) {
  const rim = parseFloat(properties.rim);
  if (!isNaN(rim)) {
    result.rim = rim;
  }
}

// Parse rim tint
if (properties.rim_tint !== undefined) {
  const tint = parseFloat(properties.rim_tint);
  if (!isNaN(tint)) {
    result.rim_tint = tint;
  }
}

// Parse rim texture
if (registry && properties.rim_texture) {
  const rimTexRef = ResourceRegistry.parseReference(properties.rim_texture);
  if (rimTexRef) {
    const texture = await registry.loadTexture(rimTexRef);
    if (texture) {
      result.rim_texture = texture;
    }
  }
}
```

### 3. Update Renderer (Approximation)

```typescript
if (properties.rim_enabled) {
  // APPROXIMATION: Use emissive to simulate rim lighting
  // Note: This is a simplified implementation. Full Fresnel rim requires custom shader.

  // Calculate rim color based on rim_tint
  // rim_tint blends between light color and albedo
  // For now, use a fixed rim color (white scaled by rim strength)

  const rimStrength = properties.rim !== undefined ? properties.rim : 1.0;
  const rimTint = properties.rim_tint !== undefined ? properties.rim_tint : 0.5;

  // Set emissive color to approximate rim effect
  // This is a placeholder - proper implementation needs shader modification
  const rimColor = new THREE.Color(1, 1, 1).multiplyScalar(rimStrength * 0.3);
  materialOptions.emissive = rimColor;

  // Apply rim texture if present
  if (properties.rim_texture) {
    // Note: This won't create proper Fresnel falloff without custom shader
    materialOptions.emissiveMap = properties.rim_texture;
  }

  // TODO: Consider implementing custom shader for proper Fresnel rim lighting
  warn('[Rim Lighting] Using emissive approximation. For accurate rim lighting, custom shader required.');
}
```
