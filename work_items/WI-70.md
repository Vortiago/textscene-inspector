# WI-70: Backlight Enable Flag (StandardMaterial3D)

**Status**: Deferred
**Priority**: Low
**Complexity**: Moderate
**Impact**: Translucency effect for light passing through objects

## Overview

Backlight simulates light passing through thin or translucent objects. Godot's `FEATURE_BACKLIGHT` → `backlight_enabled`.

**TSCN Properties**:
- `backlight_enabled` - Enable flag
- `backlight` - Color tint for transmitted light
- `backlight_texture` - Per-pixel control

**Three.js Support**: `MeshPhysicalMaterial.transmission` can approximate, but not exact match.

## Defer Reason

- Specialized use case (cloth, leaves, skin)
- Three.js transmission may not match Godot behavior
- Not found in current repository fixtures
- No user requests
