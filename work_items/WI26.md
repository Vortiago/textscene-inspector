# WI-26: GetNode() IntelliSense and Autocomplete

## Overview

Implement IntelliSense/autocomplete for Godot GetNode() calls in C# scripts. This feature provides intelligent code completion suggestions for node paths based on the actual scene tree structure, enabling developers to quickly navigate and select nodes without typing full paths or checking the scene file manually.

## Implementation Requirements

From TODO.md Phase 7: C# Integration:

- Register CompletionItemProvider for C# language
- Detect when user is typing inside GetNode() string argument
- Load associated .tscn file and parse scene tree
- Generate completion suggestions from available node paths
- Support both absolute and relative path completions
- Provide completion for child nodes, sibling nodes, parent navigation
- Show node types in completion item details
- Support unique name (%) completions
- Filter suggestions based on partial input
- Trigger on "/" character for path segment completion
- Show documentation/hover information for nodes
- Support multi-level path completion

## Implementation Notes

### Detection Strategy

**Determine if Inside GetNode() Call:**

```typescript
function isInsideGetNodeCall(
  document: vscode.TextDocument,
  position: vscode.Position
): { inside: boolean; currentPath: string; range: vscode.Range } | null {
  const line = document.lineAt(position.line).text;
  const charPos = position.character;

  // Find GetNode patterns before cursor
  const regex = /GetNode(?:<\w+>)?\s*\(\s*"([^"]*)$/g;
  let match;
  let lastMatch: RegExpExecArray | null = null;

  while ((match = regex.exec(line.substring(0, charPos))) !== null) {
    lastMatch = match;
  }

  if (!lastMatch) {
    return null;
  }

  const currentPath = lastMatch[1];
  const startPos = lastMatch.index + lastMatch[0].indexOf('"') + 1;
  const range = new vscode.Range(
    position.line,
    startPos,
    position.line,
    charPos
  );

  return { inside: true, currentPath, range };
}
```

### Completion Generation

**Path Completion Strategies:**

1. **Empty String**: Show children of current node + % for unique names
2. **Partial Path**: Show matching children at current level
3. **Path with /**:  Show children of specified path
4. **../**:  Show siblings
5. **%**: Show all unique names in scene

**Example Completions:**

```typescript
// User types: GetNode<Label>("")

//   UI/
//   Player/
//   %Player

// User types: GetNode<Label>("UI/")
// Suggestions:
//   UI/Label
//   UI/Button
//   UI/Panel

// User types: GetNode<Node>("../")
// Suggestions:
//   ../Sibling1
//   ../Sibling2
```

### Node Tree Traversal

```typescript
interface NodeCompletionItem {
  path: string;
  node: TscnNode;
  isDirectory: boolean;  // Has children
}

function generateCompletions(
  currentPath: string,
  sceneTree: TscnNode,
  contextNode: TscnNode
): NodeCompletionItem[] {
  // Handle unique name prefix
  if (currentPath.startsWith('%')) {
    return findAllUniqueNames(sceneTree).map(node => ({
      path: `%${node.uniqueName}`,
      node,
      isDirectory: false,
    }));
  }

  // Handle absolute paths
  if (currentPath.startsWith('$') || currentPath.startsWith('/root')) {
    const cleanPath = currentPath.replace(/^\$/, '').replace(/^\/root/, '');
    return findChildrenAtPath(cleanPath, sceneTree);
  }

  // Handle relative paths
  return findChildrenAtPath(currentPath, contextNode);
}

function findChildrenAtPath(
  path: string,
  fromNode: TscnNode
): NodeCompletionItem[] {
  const segments = path.split('/').filter(s => s.length > 0);
  let current = fromNode;

  // Navigate to the path location
  for (let i = 0; i < segments.length - 1; i++) {
    const segment = segments[i];

    if (segment === '..') {
      current = current.parent || current;
    } else {
      const child = current.children?.find(c => c.name === segment);
      if (!child) return [];
      current = child;
    }
  }

  // Get children at this location
  const lastSegment = segments[segments.length - 1] || '';

  return (current.children || [])
    .filter(child => child.name.startsWith(lastSegment))
    .map(child => ({
      path: buildFullPath(fromNode, child),
      node: child,
      isDirectory: (child.children?.length || 0) > 0,
    }));
}
```

### Key Considerations

**1. Performance**

- Cache parsed scene trees
- Use incremental completion (set isIncomplete when appropriate)
- Limit number of suggestions shown
- Lazy load node details

**2. Smart Filtering**

VS Code handles filtering automatically based on:
- `label`: What user sees
- `filterText`: What is matched against input
- `sortText`: Order of suggestions

**3. Multi-Level Navigation**

Support completing multiple path segments:

```csharp
GetNode<Label>("UI/Panel/Label")
//                  ^     ^
//              Trigger  Trigger
```

Each "/" triggers new completion for next segment.

**4. Context Awareness**

- Show only relevant nodes based on generic type (if available)
- Prioritize commonly used paths
- Group suggestions by type

## Code Examples

### CompletionItemProvider Implementation

```typescript
// completionProvider.ts
import * as vscode from 'vscode';
import { parseTscn } from '@tscn-renderer/core';
import type { TscnNode } from '@tscn-renderer/core';

export class GetNodeCompletionProvider implements vscode.CompletionItemProvider {
  private sceneCache: Map<string, any> = new Map();

  async provideCompletionItems(
    document: vscode.TextDocument,
    position: vscode.Position,
    token: vscode.CancellationToken,
    context: vscode.CompletionContext
  ): Promise<vscode.CompletionItem[] | vscode.CompletionList | undefined> {
    // Check if inside GetNode() call
    const getNodeContext = this.isInsideGetNodeCall(document, position);
    if (!getNodeContext) {
      return undefined;
    }

    // Find associated scene file
    const sceneUri = await this.findSceneForScript(document.uri);
    if (!sceneUri) {
      return undefined;
    }

    // Load scene
    const scene = await this.loadScene(sceneUri);
    if (!scene) {
      return undefined;
    }

    // Generate completions
    const completions = this.generateCompletions(
      getNodeContext.currentPath,
      scene.rootNode,
      scene.rootNode  // TODO: Find context node from script attachment
    );

    // Convert to VS Code completion items
    const items = completions.map(comp => this.createCompletionItem(
      comp,
      getNodeContext.range
    ));

    return new vscode.CompletionList(items, false);
  }

  private isInsideGetNodeCall(
    document: vscode.TextDocument,
    position: vscode.Position
  ): { currentPath: string; range: vscode.Range } | null {
    const line = document.lineAt(position.line).text;
    const charPos = position.character;

    // Match GetNode pattern before cursor
    const beforeCursor = line.substring(0, charPos);
    const regex = /GetNode(?:<\w+>)?\s*\(\s*"([^"]*)$/;
    const match = regex.exec(beforeCursor);

    if (!match) {
      return null;
    }

    const currentPath = match[1];
    const startPos = match.index + match[0].indexOf('"') + 1;

    return {
      currentPath,
      range: new vscode.Range(
        position.line,
        startPos,
        position.line,
        charPos
      ),
    };
  }

  private generateCompletions(
    currentPath: string,
    sceneRoot: TscnNode,
    contextNode: TscnNode
  ): NodeCompletion[] {
    const completions: NodeCompletion[] = [];

    // Handle empty path - show immediate children and unique names
    if (currentPath === '') {
      // Add children
      for (const child of contextNode.children || []) {
        completions.push({
          label: child.name,
          path: child.name,
          node: child,
          kind: 'child',
        });
      }

      // Add unique name option
      completions.push({
        label: '%',
        path: '%',
        node: sceneRoot,
        kind: 'unique',
      });

      return completions;
    }

    // Handle unique names
    if (currentPath.startsWith('%')) {
      const partial = currentPath.substring(1);
      const uniqueNodes = this.findAllUniqueNames(sceneRoot);

      for (const node of uniqueNodes) {
        if (node.uniqueName && node.uniqueName.startsWith(partial)) {
          completions.push({
            label: `%${node.uniqueName}`,
            path: `%${node.uniqueName}`,
            node,
            kind: 'unique',
          });
        }
      }

      return completions;
    }

    // Handle path segments
    const segments = currentPath.split('/');
    const lastSegment = segments[segments.length - 1];
    const parentPath = segments.slice(0, -1).join('/');

    // Navigate to parent path
    const parentNode = this.resolvePathToNode(parentPath, contextNode);
    if (!parentNode) {
      return completions;
    }

    // Find children matching last segment
    for (const child of parentNode.children || []) {
      if (child.name.startsWith(lastSegment)) {
        const fullPath = parentPath
          ? `${parentPath}/${child.name}`
          : child.name;

        completions.push({
          label: child.name,
          path: fullPath,
          node: child,
          kind: 'child',
        });
      }
    }

    return completions;
  }

  private createCompletionItem(
    completion: NodeCompletion,
    range: vscode.Range
  ): vscode.CompletionItem {
    const item = new vscode.CompletionItem(
      completion.label,
      this.getCompletionKind(completion.node, completion.kind)
    );

    // What to insert
    item.insertText = completion.path;

    // Replace range (overwrites partial input)
    item.range = range;

    // Additional details
    item.detail = `${completion.node.type}`;
    item.documentation = new vscode.MarkdownString(
      `Node: \`${completion.node.name}\`\n\nType: \`${completion.node.type}\``
    );

    // Sort order (children before unique names)
    item.sortText = completion.kind === 'unique'
      ? `9_${completion.label}`
      : `1_${completion.label}`;

    // If this node has children, trigger completion again after insert
    if (completion.node.children && completion.node.children.length > 0) {
      item.command = {
        command: 'editor.action.triggerSuggest',
        title: 'Trigger Suggest',
      };
      // Add trailing / to indicate directory
      item.insertText = `${completion.path}/`;
      item.label += '/';
    }

    return item;
  }

  private getCompletionKind(
    node: TscnNode,
    kind: string
  ): vscode.CompletionItemKind {
    if (kind === 'unique') {
      return vscode.CompletionItemKind.Constant;
    }

    if (node.children && node.children.length > 0) {
      return vscode.CompletionItemKind.Folder;
    }

    // Map node types to completion kinds
    switch (node.type) {
      case 'MeshInstance3D':
      case 'Sprite2D':
      case 'Sprite3D':
        return vscode.CompletionItemKind.Property;
      case 'Node3D':
      case 'Node2D':
      case 'Node':
        return vscode.CompletionItemKind.Class;
      default:
        return vscode.CompletionItemKind.Field;
    }
  }

  private resolvePathToNode(
    path: string,
    fromNode: TscnNode
  ): TscnNode | null {
    if (!path) return fromNode;

    const segments = path.split('/').filter(s => s.length > 0);
    let current = fromNode;

    for (const segment of segments) {
      if (segment === '..') {
        current = current.parent || current;
      } else {
        const child = current.children?.find(c => c.name === segment);
        if (!child) return null;
        current = child;
      }
    }

    return current;
  }

  private findAllUniqueNames(root: TscnNode): TscnNode[] {
    const nodes: TscnNode[] = [];

    function traverse(node: TscnNode) {
      if (node.uniqueName) {
        nodes.push(node);
      }

      for (const child of node.children || []) {
        traverse(child);
      }
    }

    traverse(root);
    return nodes;
  }

  private async loadScene(uri: vscode.Uri): Promise<any> {
    const fsPath = uri.fsPath;

    if (this.sceneCache.has(fsPath)) {
      return this.sceneCache.get(fsPath);
    }

    const document = await vscode.workspace.openTextDocument(uri);
    const scene = parseTscn(document.getText());

    this.sceneCache.set(fsPath, scene);

    return scene;
  }

  private async findSceneForScript(
    scriptUri: vscode.Uri
  ): Promise<vscode.Uri | undefined> {
    // Same logic as WI-25
    const scriptPath = scriptUri.fsPath;
    const scriptName = path.basename(scriptPath, '.cs');
    const tscnPath = scriptPath.replace('.cs', '.tscn');

    try {
      await vscode.workspace.fs.stat(vscode.Uri.file(tscnPath));
      return vscode.Uri.file(tscnPath);
    } catch {
      return undefined;
    }
  }
}

interface NodeCompletion {
  label: string;
  path: string;
  node: TscnNode;
  kind: 'child' | 'unique' | 'parent';
}
```
