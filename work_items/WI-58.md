# WI-58: PlaneMesh center_offset Property

**Status**: Not Started
**Priority**: High
**Estimated Effort**: Small Complexity
**Impact**: Extensively used in ld-58 HallwayGeometry.tscn for walls

## Overview

### Current State

PlaneMesh sub-resources render correctly with size and orientation, but **center_offset property is not implemented**:
- ✅ PlaneMesh renders with correct size and orientation
- ❌ `center_offset` property is ignored (mesh pivot remains at center)
- ❌ Walls and planes with offset pivots render at incorrect positions

### Evidence from ld-58

**Example: WallSection.tscn (line 13)** - Wall plane with pivot at bottom edge:
```tscn
[sub_resource type="PlaneMesh" id="PlaneMesh_fgsl3"]
material = SubResource("StandardMaterial3D_mt8pv")
size = Vector2(2, 4)
center_offset = Vector3(0, 2, 0)
orientation = 0
```

**Analysis**: 4-unit tall wall (size.y = 4) with `center_offset.y = 2` places pivot at the bottom edge. This allows placing walls at y=0 without half the wall going underground.

**Impact**: Used in multiple wall components throughout ld-58. Without this, walls render with pivot at center, requiring manual transform adjustments.

## Implementation Overview

### Parser Changes

Add `center_offset` property parsing:

```typescript
export interface PlaneMeshProperties {
  size?: THREE.Vector2;
  center_offset?: THREE.Vector3; // NEW
  orientation?: number;
  material?: string;
}
```

### Renderer Changes

Apply center_offset by translating geometry vertices:

```typescript
// Apply center_offset by translating geometry vertices
if (props.center_offset) {
  const offset = props.center_offset;
  geometry.translate(offset.x, offset.y, offset.z);
  logger.info(
    `[PlaneMesh] Applied center_offset: (${offset.x}, ${offset.y}, ${offset.z})`
  );
}
```

**Explanation**: `geometry.translate()` shifts all vertices by the offset, effectively moving the pivot point relative to the mesh geometry.

## Linter Requirements

**Validation Rule**: Validate center_offset format (must be Vector3)

```typescript
const planeMeshValidationRule: LintRule = {
  meta: {
    name: 'valid-planemesh-center-offset',
    description: 'Validates PlaneMesh center_offset property',
  },
  check: (context: LintContext) => {
    // Validate Vector3 format
    const centerOffset = subResource.properties.center_offset;
    if (centerOffset && typeof centerOffset === 'string') {
      const vector3Regex = /^Vector3\(\s*-?[\d.]+\s*,\s*-?[\d.]+\s*,\s*-?[\d.]+\s*\)$/;
      if (!vector3Regex.test(centerOffset)) {
        // Error: Invalid format
      }
    }
  },
};
```
