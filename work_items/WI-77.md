# WI-77: Advanced Environment Features (Post-Processing & Lighting)

**Status**: Deferred (Not Started)
**Priority**: Medium
**Estimated Effort**: Very High Complexity (20+ hours)
**Dependencies**: WI-57 (WorldEnvironment + Environment SubResource basics)

## Overview

Implement advanced Environment resource features that were deferred from WI-57 v1. These include advanced post-processing effects, ambient lighting, tonemapping, glow/bloom, SSAO, SDFGI, and sky rendering.

### Current State (WI-57 v1)

**Implemented**:
- ✅ Background color (BG_COLOR mode)
- ✅ Basic volumetric fog (THREE.FogExp2 approximation)
- ⚠️ Color adjustments (log warning - requires post-processing)
- ⚠️ Screen-space reflections (log warning - complex)

**Not Implemented** (this work item):
- ❌ Sky background (BG_SKY mode)
- ❌ Canvas background (BG_CANVAS mode)
- ❌ Camera feed background (BG_CAMERA_FEED mode)
- ❌ Ambient lighting configuration
- ❌ Reflection probes configuration
- ❌ Tonemapping (exposure, white point, tone mapper modes)
- ❌ Glow/Bloom effects
- ❌ SSAO (Screen-Space Ambient Occlusion)
- ❌ SDFGI (Signed Distance Field Global Illumination)
- ❌ Color adjustments implementation (brightness, contrast, saturation)
- ❌ SSR (Screen-Space Reflections) implementation
- ❌ Fog volumes (FogVolume nodes)

## Deferred Properties

### Background Modes (High Priority)
```typescript
// From Godot BGMode enum
BG_CLEAR_COLOR = 0,  // Use default clear color
BG_COLOR = 1,        // ✅ Implemented in WI-57
BG_SKY = 2,          // ❌ Sky resource rendering
BG_CANVAS = 3,       // ❌ CanvasLayer background
BG_KEEP = 4,         // ❌ Keep previous frame
BG_CAMERA_FEED = 5,  // ❌ Camera feed texture
```

**THREE.js Challenges**:
- Sky requires procedural sky shader or cube map texture
- Canvas requires 2D rendering pipeline integration
- Camera feed requires video texture support

### Ambient Lighting (Medium Priority)
```typescript
interface AmbientLightProperties {
  ambient_source: number;        // AMBIENT_SOURCE_BG/DISABLED/COLOR/SKY
  ambient_color: Color;          // Ambient light color
  ambient_energy: number;        // Ambient light intensity
  ambient_sky_contribution: number; // How much sky contributes
  reflection_source: number;     // REFLECTION_SOURCE_BG/DISABLED/SKY
}
```

**THREE.js Mapping**:
- Use `scene.environment` for image-based lighting
- Requires cube map generation from sky
- Reflection probes need environment maps

### Tonemapping (Medium Priority)
```typescript
interface TonemappingProperties {
  tonemap_mode: number;          // LINEAR/REINHARDT/FILMIC/ACES/AGX
  tonemap_exposure: number;      // Default 1.0
  tonemap_white: number;         // Default 1.0
}
```

**THREE.js Mapping**:
- `renderer.toneMapping` = THREE.ACESFilmicToneMapping, etc.
- `renderer.toneMappingExposure` = exposure value
- Supports: Linear, Reinhardt, Cineon, ACESFilmic

### Glow/Bloom (Medium Priority)
```typescript
interface GlowProperties {
  glow_enabled: boolean;
  glow_intensity: number;        // Default 0.8
  glow_strength: number;         // Default 1.0
  glow_mix: number;              // Default 0.05
  glow_bloom: number;            // Default 0.0
  glow_blend_mode: number;       // ADDITIVE/SCREEN/SOFTLIGHT/REPLACE/MIX
  glow_hdr_threshold: number;    // Default 1.0
  glow_hdr_scale: number;        // Default 2.0
}
```

**THREE.js Implementation**:
- Requires post-processing pipeline (EffectComposer)
- Use UnrealBloomPass from three/examples
- Performance impact consideration

### Color Adjustments (Medium Priority)

interface ColorAdjustmentProperties {

### SSR - Screen-Space Reflections (Low Priority)

## Implementation Strategy

### Phase 1: Post-Processing Infrastructure
1. Add EffectComposer to TscnRenderer
2. Create post-processing pipeline setup
3. Add render pass management

### Phase 2: Priority 1 Features
1. Tonemapping (easy, high impact)
2. Bloom/Glow (medium difficulty, high impact)
3. Color adjustments (medium difficulty, medium impact)

### Phase 3: Priority 2 Features
1. Ambient lighting (requires environment maps)
2. Sky background mode (requires sky shader)
3. SSAO (high performance cost)

### Phase 4: Priority 3 Features
1. SSR (experimental, very high cost)
2. SDFGI (not supported in THREE.js)
3. Canvas/Camera feed backgrounds
