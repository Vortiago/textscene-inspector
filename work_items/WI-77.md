# WI-77: Multi-Panel Scene Invalidation & Node Update System

**Status**: Not Started
**Priority**: High
**Impact**: Core architecture for multi-panel editing workflow with large game scenes
**Dependency**: WI-76 (Event-Based Resource Loading)

## Overview

### Problem Statement

**Current Architecture Limitation:**

The current system updates nodes using full destroy-recreate pattern, with no coordination between multiple open panels:

```typescript
// User edits props/chair.tscn (external scene)
// Current behavior:
updateScene('props/chair.tscn')
  → removeNode(instance)  // Destroys entire 50-node chair subtree
  → addNode(instance)     // Re-renders all 50 nodes from scratch
  → NO COORDINATION with other panels showing this scene
```

**Multi-Panel Scenario (Target Use Case):**

1. User opens **main scene** from large game (1000+ nodes across sub-scenes)
2. User opens **10+ preview panels** showing different parts of the game
3. Many panels reference same **external scenes** (props, characters, environments)
4. User **edits `props/chair.tscn`** (changes one material property)
5. **Expected:** All panels using `chair.tscn` update automatically
6. **Current:** No cross-panel coordination, panels show stale data OR require manual refresh

**Scale Impact:**

- **Scene size:** 1000+ nodes in complex game scenes
- **Sub-scene references:** Dozens of external scenes (props, characters, levels)
- **Open panels:** 10+ simultaneously (different views of same project)
- **Edit frequency:** Constant (core development workflow, not rare edge case)
- **Performance requirement:** Updates must be smooth, not janky

**Problems to Solve:**

1. **No scene dependency tracking:** Can't determine which scenes use a given sub-scene
2. **No multi-panel coordination:** Panels don't know about each other
3. **Inefficient destroy-recreate:** Updating 50-node chair = destroy + rebuild 50 THREE.js objects
4. **No selective updates:** Property change requires full subtree re-render

### Why This Matters

**Current Use Case:**
- Single panel, small scenes → destroy-recreate is acceptable
- Rare updates (file uploads) → performance doesn't matter

**Future Use Case (Multi-Panel Editing):**
- 10+ panels, large scenes → destroy-recreate is janky
- Frequent updates (every edit) → performance critical
- Sub-scene editing → need cross-panel invalidation

**This is core architecture, not optimization.**

## Architecture

### Four-Layer System

```
Layer 4: Multi-Panel Coordinator
  ↓ (coordinates invalidation across panels)
Layer 3: Scene Dependency Graph
  ↓ (tracks which scenes use which sub-scenes)
Layer 2: Node Invalidation Manager
  ↓ (batches updates within a panel)
Layer 1: Selective Update Strategy
  ↓ (updates properties without destroy-recreate)
```

### Layer 1: Node Invalidation Manager (Per-Panel)

**Purpose:** Mark nodes as "dirty" and batch updates using microtask queue.

**API:**
```typescript
class NodeInvalidationManager {
  // Mark node as needing update
  markDirty(nodePath: string, reason: 'property' | 'subtree' | 'resource'): void;

  // Schedule batched flush
  private scheduleFlush(): void;

  // Process all dirty nodes
  private flush(): Promise<void>;

  // Check if node is dirty
  isDirty(nodePath: string): boolean;
}
```

**Batching Strategy:**
```typescript
// Multiple edits in same JavaScript turn
markDirty('Chair1', 'property');
markDirty('Chair2', 'property');
markDirty('Table', 'subtree');

// Flush on next microtask (batched)
queueMicrotask(() => {
  updateNode('Chair1');  // Batched
  updateNode('Chair2');  // Batched
  updateNode('Table');   // Batched
});
```

**Benefits:**
- ✅ Multiple edits = one render pass (not 3)
- ✅ Deferred execution (non-blocking)
- ✅ Foundation for multi-panel coordination

### Layer 2: Scene Dependency Graph

**Purpose:** Track which parent scenes reference which sub-scenes.

**Data Structure:**
```typescript
class SceneDependencyGraph {
  // parent scene → Set<sub-scenes it uses>
  private dependencies = new Map<string, Set<string>>();

  // sub-scene → Set<parent scenes using it>
  private dependents = new Map<string, Set<string>>();

  // Record dependency during scene loading
  recordDependency(parentScene: string, subScene: string): void;

  // Find all scenes that use a sub-scene
  getDependentScenes(subScene: string): Set<string>;

  // Find all sub-scenes used by a parent
  getSubScenes(parentScene: string): Set<string>;

  // Clean up when scene unloaded
  removeDependencies(scenePath: string): void;
}
```

**Example:**
```
Scene hierarchy:
- level1.tscn
  ├─ props/chair.tscn (external)
  ├─ props/table.tscn (external)
  └─ characters/player.tscn (external)
- level2.tscn
  ├─ props/chair.tscn (same external)
  └─ props/lamp.tscn (external)

Graph:
dependencies:
  level1.tscn → [props/chair.tscn, props/table.tscn, characters/player.tscn]
  level2.tscn → [props/chair.tscn, props/lamp.tscn]

dependents:
  props/chair.tscn → [level1.tscn, level2.tscn]
  props/table.tscn → [level1.tscn]
  props/lamp.tscn  → [level2.tscn]
  characters/player.tscn → [level1.tscn]

Query: getDependentScenes('props/chair.tscn')
Result: [level1.tscn, level2.tscn]
```

**Benefits:**
- ✅ Know which scenes to invalidate when sub-scene changes
- ✅ Avoid scanning entire scene tree
- ✅ O(1) lookup by scene path

**Purpose:** Coordinate invalidation across multiple open panels.

**API:**

```typescript
  renderer: TscnRenderer;
  sceneManager: SceneManager;
```

**Invalidation Flow:**
```
User edits props/chair.tscn
  ↓
coordinator.invalidateSubScene('props/chair.tscn')
  ↓
sceneDeps.getDependentScenes('props/chair.tscn')
  → [level1.tscn, level2.tscn]
  ↓

  → [panel1, panel3]
  ↓
getPanelsShowingScene('level2.tscn')
  → [panel5, panel7]
  ↓
For each panel:
  invalidationManager.markDirty(instancePath, 'subtree')
  ↓
Each panel flushes on next microtask (batched)
```

**Benefits:**
- ✅ All affected panels update automatically
- ✅ Panels update independently (non-blocking)
- ✅ Batched updates (smooth, not janky)

### Layer 4: Selective Update Strategy

**Purpose:** Update properties without destroy-recreate.

**Update Types:**

**1. Transform-Only Update** (position, rotation, scale):
```typescript
updateTransform(nodePath: string, newTransform: Transform3D): void {
  const object = nodeTracker.getObject(nodePath);
  object.position.fromArray(newTransform.position);
  object.quaternion.fromArray(newTransform.rotation);
  object.scale.fromArray(newTransform.scale);
  // No destroy-recreate
}
```

**2. Material-Only Update** (material override changed):
```typescript
updateMaterial(nodePath: string, newMaterial: THREE.Material): void {
  const mesh = nodeTracker.getObject(nodePath) as THREE.Mesh;
  const oldMaterial = mesh.material;
  mesh.material = newMaterial;
  oldMaterial.dispose(); // Clean up
  // No destroy-recreate of mesh
}
```

**3. Visibility Update** (visible property changed):
```typescript
updateVisibility(nodePath: string, visible: boolean): void {
  const object = nodeTracker.getObject(nodePath);
  object.visible = visible;
  // No destroy-recreate
}
```

**4. Full Update** (structure changed):
```typescript
updateFull(nodePath: string, node: TscnNode): void {
  // Fall back to destroy-recreate for structural changes
  // (children added/removed, node type changed)
  this.removeNode(nodePath);
  await this.addNode(nodePath, node);
}
```

**Decision Logic:**
```typescript
determineUpdateStrategy(oldNode: TscnNode, newNode: TscnNode): UpdateStrategy {
  if (oldNode.type !== newNode.type) return 'full';
  if (childrenChanged(oldNode, newNode)) return 'full';

  if (transformChanged(oldNode, newNode)) return 'transform';
  if (materialChanged(oldNode, newNode)) return 'material';
  if (visibilityChanged(oldNode, newNode)) return 'visibility';

  return 'property'; // Generic property update
}
```

**Benefits:**
- ✅ Preserve THREE.js object state (animations, gizmos)
- ✅ ~10x faster than destroy-recreate (property update vs. full re-render)
- ✅ Smooth UX (no flicker)

### Phase 1: Node Invalidation Manager (Foundation)

**Goal:** Add dirty tracking and batched updates to single panel.

**Implementation:**

1. Create `NodeInvalidationManager.ts`
2. Add `markDirty()` API with reason tracking
3. Implement microtask batching with `queueMicrotask()`
4. Integrate with `NodeLifecycleManager`
5. Add `isDirty()` query API

**Code Structure:**
```typescript
export class NodeInvalidationManager {
  private dirtyNodes = new Map<string, DirtyReason>();
  private flushScheduled = false;

  markDirty(nodePath: string, reason: DirtyReason): void {
    this.dirtyNodes.set(nodePath, reason);
    this.scheduleFlush();
  }

  private scheduleFlush(): void {
    if (!this.flushScheduled) {
      this.flushScheduled = true;
      queueMicrotask(() => this.flush());
    }
  }

  private async flush(): Promise<void> {
    const nodes = Array.from(this.dirtyNodes.entries());
    this.dirtyNodes.clear();
    this.flushScheduled = false;

    for (const [nodePath, reason] of nodes) {
      await this.updateNode(nodePath, reason);
    }
  }

  private async updateNode(nodePath: string, reason: DirtyReason): Promise<void> {
    const node = this.nodeTracker.getNode(nodePath);
    if (!node) return; // Node was removed

    // Delegate to NodeLifecycleManager
    await this.lifecycle.updateNode(nodePath, node, this.sceneData);
  }
}

type DirtyReason = 'property' | 'subtree' | 'resource';
```

### Phase 2: Scene Dependency Graph

**Goal:** Track which parent scenes use which sub-scenes.

**Implementation:**

1. Create `SceneDependencyGraph.ts`
2. Implement bidirectional tracking (dependencies + dependents)
3. Record dependencies during external scene loading
4. Query API for dependency lookups
5. Cleanup when scenes unloaded

**Code Structure:**
```typescript
export class SceneDependencyGraph {
  // parent → Set<sub-scenes>
  private dependencies = new Map<string, Set<string>>();

  // sub-scene → Set<parents>
  private dependents = new Map<string, Set<string>>();

  recordDependency(parentScene: string, subScene: string): void {
    // Track parent → sub-scene
    if (!this.dependencies.has(parentScene)) {
      this.dependencies.set(parentScene, new Set());
    }
    this.dependencies.get(parentScene)!.add(subScene);

    // Track sub-scene → parent
    if (!this.dependents.has(subScene)) {
      this.dependents.set(subScene, new Set());
    }
    this.dependents.get(subScene)!.add(parentScene);
  }

  getDependentScenes(subScene: string): Set<string> {
    return this.dependents.get(subScene) || new Set();
  }

  getSubScenes(parentScene: string): Set<string> {
    return this.dependencies.get(parentScene) || new Set();
  }

  removeDependencies(scenePath: string): void {
    // Remove as parent
    const subScenes = this.dependencies.get(scenePath);
    if (subScenes) {
      for (const subScene of subScenes) {
        this.dependents.get(subScene)?.delete(scenePath);
      }
      this.dependencies.delete(scenePath);
    }

    // Remove as dependent
    const parents = this.dependents.get(scenePath);
    if (parents) {
      for (const parent of parents) {
        this.dependencies.get(parent)?.delete(scenePath);
      }
      this.dependents.delete(scenePath);
    }
  }
}
```

### Phase 3: Multi-Panel Coordinator

**Goal:** Coordinate invalidation across multiple open panels.

**Implementation:**

1. Create `MultiPanelCoordinator.ts` (singleton or global instance)
2. Register/unregister panels on open/close
3. Track which scene each panel is showing
4. Implement `invalidateSubScene()` to update all affected panels
5. Event-based communication between coordinator and panels

**Code Structure:**
```typescript
export class MultiPanelCoordinator {
  private panels = new Map<string, PanelContext>();

  registerPanel(panelId: string, context: PanelContext): void {
    this.panels.set(panelId, context);
    logger.info(`[MultiPanel] Registered panel ${panelId} showing ${context.currentScene}`);
  }

  unregisterPanel(panelId: string): void {
    this.panels.delete(panelId);
    logger.info(`[MultiPanel] Unregistered panel ${panelId}`);
  }

  invalidateSubScene(subScenePath: string): void {
    logger.info(`[MultiPanel] Invalidating sub-scene: ${subScenePath}`);

    const affectedPanels: PanelContext[] = [];

    // Find all panels affected by this sub-scene change
    for (const context of this.panels.values()) {
      const sceneDeps = context.sceneManager.getSceneDependencies();
      const dependentScenes = sceneDeps.getDependentScenes(subScenePath);

      if (dependentScenes.has(context.currentScene)) {
        affectedPanels.push(context);
      }
    }

    logger.info(`[MultiPanel] Found ${affectedPanels.length} affected panels`);

    // Invalidate instances in each panel
    for (const context of affectedPanels) {
      this.invalidateInstancesInPanel(context, subScenePath);
    }
  }

  private invalidateInstancesInPanel(context: PanelContext, subScenePath: string): void {
    // Find all instance nodes using this sub-scene
    const instances = context.sceneManager.getInstancesOfScene(subScenePath);

    // Mark each instance as dirty
    for (const instancePath of instances) {
      context.invalidationManager.markDirty(instancePath, 'subtree');
    }

    logger.info(`[MultiPanel] Marked ${instances.length} instances dirty in panel`);
  }
}

interface PanelContext {
  renderer: TscnRenderer;
  sceneManager: SceneManager;
  invalidationManager: NodeInvalidationManager;
  currentScene: string;
}

// Singleton instance
```

### Phase 4: Selective Update Strategy

**Goal:** Update properties without destroy-recreate.

**Implementation:**

1. Add property diff utility to detect what changed
2. Implement update strategies (transform, material, visibility, full)
3. Decision logic to choose strategy
4. Update NodeLifecycleManager to use selective updates
5. Fallback to destroy-recreate for structural changes

**Code Structure:**
```typescript
export class SelectiveUpdateStrategy {
  updateNode(nodePath: string, oldNode: TscnNode, newNode: TscnNode): void {
    const strategy = this.determineStrategy(oldNode, newNode);

    switch (strategy) {
      case 'transform':
        this.updateTransform(nodePath, newNode);
        break;
      case 'material':
        this.updateMaterial(nodePath, newNode);
        break;
      case 'visibility':
        this.updateVisibility(nodePath, newNode);
        break;
      case 'full':
        this.updateFull(nodePath, newNode);
        break;
    }
  }

  private determineStrategy(oldNode: TscnNode, newNode: TscnNode): UpdateStrategy {
    if (oldNode.type !== newNode.type) return 'full';
    if (this.childrenChanged(oldNode, newNode)) return 'full';

    const changes = this.detectChanges(oldNode, newNode);

    if (changes.has('transform')) return 'transform';
    if (changes.has('material')) return 'material';
    if (changes.has('visible')) return 'visibility';

    return 'full'; // Fallback
  }

  private updateTransform(nodePath: string, node: TscnNode): void {
    const object = this.nodeTracker.getObject(nodePath);
    const transform = parseTransform3D(node.properties.transform);

    object.position.fromArray(transform.position);
    object.quaternion.fromArray(transform.rotation);
    object.scale.fromArray(transform.scale);

    logger.info(`[Selective Update] Transform updated: ${nodePath}`);
  }

  private updateMaterial(nodePath: string, node: TscnNode): void {
    const mesh = this.nodeTracker.getObject(nodePath) as THREE.Mesh;
    const newMaterial = this.resolveMaterial(node.properties.material_override);

    if (mesh.material) {
      (mesh.material as THREE.Material).dispose();
    }

    mesh.material = newMaterial;

    logger.info(`[Selective Update] Material updated: ${nodePath}`);
  }

  private updateVisibility(nodePath: string, node: TscnNode): void {
    const object = this.nodeTracker.getObject(nodePath);
    object.visible = node.properties.visible !== 'false';

    logger.info(`[Selective Update] Visibility updated: ${nodePath}`);
  }

  private async updateFull(nodePath: string, node: TscnNode): Promise<void> {
    // Fallback to destroy-recreate
    await this.lifecycle.removeNode(nodePath);
    await this.lifecycle.addNode(nodePath, node, this.sceneData);

    logger.info(`[Selective Update] Full update (destroy-recreate): ${nodePath}`);
  }

  private detectChanges(oldNode: TscnNode, newNode: TscnNode): Set<string> {
    const changes = new Set<string>();

    if (oldNode.properties.transform !== newNode.properties.transform) {
      changes.add('transform');
    }

    if (oldNode.properties.material_override !== newNode.properties.material_override) {
      changes.add('material');
    }

    if (oldNode.properties.visible !== newNode.properties.visible) {
      changes.add('visibility');
    }

    return changes;
  }

  private childrenChanged(oldNode: TscnNode, newNode: TscnNode): boolean {
    return oldNode.children.length !== newNode.children.length;
  }
}

type UpdateStrategy = 'transform' | 'material' | 'visibility' | 'full';
```

```
  ↓
WI-77: Find affected panels
  ↓

  ↓
```
