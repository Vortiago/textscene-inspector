# WI-11: Implement DirectionalLight3D Node

## Overview
Implement parser and renderer for Godot's DirectionalLight3D node type in the TSCN renderer. DirectionalLight3D represents parallel light rays (like sunlight) and is the most common type for outdoor scenes and global lighting.

## Implementation Requirements
- Create parser and renderer in `packages/textscene-renderer/src/nodes/directionallight3d/`
- Parse light properties and shadow parameters
- Generate THREE.DirectionalLight
- **Common**: Standard sun/moon lighting in most scenes

## Godot Documentation

### DirectionalLight3D Properties

**Shadow Configuration**
```gdscript
# Example: Configuring a DirectionalLight3D for shadows
func setup_shadows():
    var dir_light = DirectionalLight3D.new()
    add_child(dir_light)

    # Enable shadows
    dir_light.shadow_enabled = true

    # Shadow settings (tune these for quality vs performance)
    dir_light.shadow_bias = 0.05 # Adjust to prevent self-shadowing artifacts
    dir_light.shadow_contact_clean_offset = 0.05 # Further bias for contact points

    # Shadow filter can improve quality but costs performance
    # Options: SHADOW_FILTER_NONE, SHADOW_FILTER_PCF3, SHADOW_FILTER_PCF5
    dir_light.shadow_filter = DirectionalLight3D.SHADOW_FILTER_PCF5

    # Using different shadow cascades for Directional lights
    # dir_light.directional_shadow_mode = DirectionalLight3D.SHADOW_ORTHOGONAL_SPLIT_4 # e.g., 4 cascades
```

**Key Properties:**
- `light_color` (Color) - The color of the light
- `light_energy` (float) - Light intensity/brightness
- `shadow_enabled` (bool) - Enable/disable shadow casting
- `shadow_bias` (float) - Prevents self-shadowing artifacts
- `shadow_normal_bias` (float) - Additional bias based on surface normal
- `shadow_filter` (enum) - Shadow quality filter
- `directional_shadow_mode` (enum) - Shadow cascade splits (1, 2, or 4 cascades)

**Shadow Filter Options:**
- `SHADOW_FILTER_NONE` - No filtering (fastest)
- `SHADOW_FILTER_PCF3` - 3x3 PCF filtering
- `SHADOW_FILTER_PCF5` - 5x5 PCF filtering (best quality)
- `SHADOW_FILTER_PCF13` - 13-tap PCF filtering (highest quality)

**Directional Shadow Modes:**
- `SHADOW_ORTHOGONAL_SPLIT_1` - Single shadow map
- `SHADOW_ORTHOGONAL_SPLIT_2` - 2 cascades
- `SHADOW_ORTHOGONAL_SPLIT_4` - 4 cascades (best for large scenes)

## Three.js Documentation

### THREE.DirectionalLight API

**Constructor and Basic Setup**
```javascript
const color = 0xFFFFFF;
const intensity = 3;
const light = new THREE.DirectionalLight(color, intensity);
light.castShadow = true;
light.position.set(4, 10, 5);
light.target.position.set(-4, 1, -4);
scene.add(light);
scene.add(light.target);
```

**Key Properties:**
- `color` (Color) - Light color
- `intensity` (float) - Light intensity
- `position` (Vector3) - Light position (defines direction with target)
- `target` (Object3D) - Target object that defines light direction

**Shadow Camera Configuration (Orthographic)**
DirectionalLight uses an orthographic camera for shadows:
```javascript
// Configure shadow camera (orthographic frustum)
light.shadow.camera.near = 0.1;
light.shadow.camera.far = 500;
light.shadow.camera.left = -17;
light.shadow.camera.right = 17;
light.shadow.camera.top = 17;
light.shadow.camera.bottom = -17;

// Shadow map settings
light.shadow.mapSize.width = 512;
light.shadow.mapSize.height = 512;
light.shadow.bias = -0.0005;
light.shadow.radius = 4;
```

**Shadow Properties:**
- `shadow.camera.near/far` - Near and far planes of shadow camera
- `shadow.camera.left/right/top/bottom` - Orthographic frustum bounds
- `shadow.mapSize` - Shadow map resolution (power of 2, e.g., 512, 1024, 2048)
- `shadow.bias` - Shadow bias to prevent artifacts
- `shadow.radius` - Shadow blur radius (soft shadows)

**Helper Visualization**

## Implementation Notes

### Property Mapping: Godot → Three.js

| Godot Property | Three.js Property | Conversion |
|---|---|---|
| `light_color` | `color` | Parse Color → hex |
| `light_energy` | `intensity` | Direct mapping (may need scaling) |
| `shadow_enabled` | `castShadow` | Direct boolean |
| `shadow_bias` | `shadow.bias` | May need sign flip |
| `shadow_normal_bias` | N/A | three.js uses single bias |
| `directional_shadow_mode` | Shadow camera bounds | Affects frustum size |

### Key Considerations

1. **Direction Calculation**:
   - DirectionalLight direction is defined by position → target
   - Extract direction from Godot's transform
   - Create target object at appropriate location

2. **Shadow Camera Frustum**:
   - Godot uses cascades for large scenes
   - three.js requires manual frustum configuration
   - Calculate frustum bounds based on scene size
   - Typical values: ±17 for moderate scenes, ±50 for large scenes

3. **Shadow Cascades**:
   - Godot supports 1, 2, or 4 shadow cascades
   - three.js doesn't have built-in cascades
   - For initial implementation, use single shadow map
   - Consider implementing cascades as future enhancement

4. **Intensity Scaling**:
   - Godot's `light_energy` typically ranges 0-2
   - three.js intensity depends on scene scale
   - May need multiplication factor (e.g., 1-5)

5. **Shadow Bias**:
   - Godot uses positive bias (0.05-0.1 typical)
   - three.js often uses negative bias (-0.0005 to -0.005)
   - Test to find appropriate conversion

6. **Shadow Quality**:
   - Map Godot's shadow_filter to shadow.mapSize
   - SHADOW_FILTER_NONE → 256x256
   - SHADOW_FILTER_PCF3 → 512x512
   - SHADOW_FILTER_PCF5 → 1024x1024
   - SHADOW_FILTER_PCF13 → 2048x2048

### Parser Structure
```typescript
// packages/textscene-renderer/src/nodes/directionallight3d/parser.ts
export interface DirectionalLight3DProperties {
  light_color: string;
  light_energy: number;
  shadow_enabled: boolean;
  shadow_bias?: number;
  shadow_normal_bias?: number;
  shadow_filter?: number;
  directional_shadow_mode?: number;
  directional_shadow_max_distance?: number;
}

export function parseDirectionalLight3D(node: TscnNode): DirectionalLight3DProperties {
  return {
    light_color: node.properties.light_color || 'Color(1, 1, 1, 1)',
    light_energy: parseFloat(node.properties.light_energy) || 1.0,
    shadow_enabled: node.properties.shadow_enabled === 'true',
    shadow_bias: node.properties.shadow_bias ? parseFloat(node.properties.shadow_bias) : undefined,
    shadow_normal_bias: node.properties.shadow_normal_bias ? parseFloat(node.properties.shadow_normal_bias) : undefined,
    shadow_filter: node.properties.shadow_filter ? parseInt(node.properties.shadow_filter) : undefined,
    directional_shadow_mode: node.properties.directional_shadow_mode ? parseInt(node.properties.directional_shadow_mode) : undefined,
  };
}
```

### Renderer Structure
```typescript
// packages/textscene-renderer/src/nodes/directionallight3d/renderer.ts
import * as THREE from 'three';

export function createDirectionalLight3D(
  properties: DirectionalLight3DProperties,
  transform: Transform3D
): THREE.Group {
  // Parse color
  const color = parseGodotColor(properties.light_color);

  // Create light with intensity scaling
  const light = new THREE.DirectionalLight(color, properties.light_energy * 2);

  // Apply transform position
  light.position.copy(transform.position);

  // Calculate target from transform rotation
  const direction = new THREE.Vector3(0, 0, -1);
  direction.applyQuaternion(transform.rotation);
  const target = new THREE.Object3D();
  target.position.copy(light.position).add(direction.multiplyScalar(10));

  // Configure shadows
  if (properties.shadow_enabled) {
    light.castShadow = true;

    // Shadow camera (orthographic frustum)
    const frustumSize = 20; // Adjust based on scene size
    light.shadow.camera.left = -frustumSize;
    light.shadow.camera.right = frustumSize;
    light.shadow.camera.top = frustumSize;
    light.shadow.camera.bottom = -frustumSize;
    light.shadow.camera.near = 0.1;
    light.shadow.camera.far = 100;

    // Shadow map size based on filter quality
    const mapSize = getShadowMapSize(properties.shadow_filter);
    light.shadow.mapSize.width = mapSize;
    light.shadow.mapSize.height = mapSize;

    // Shadow bias
    if (properties.shadow_bias !== undefined) {
      light.shadow.bias = -properties.shadow_bias * 0.01; // Sign flip and scale
    } else {
      light.shadow.bias = -0.0005; // Default
    }

    light.shadow.radius = 4; // Soft shadows
  }

  // Group light and target
  const group = new THREE.Group();
  group.add(light);
  group.add(target);
  light.target = target;

  return group;
}

function getShadowMapSize(filter?: number): number {
  // Map Godot shadow filter to shadow map size
  // SHADOW_FILTER_NONE = 0, PCF3 = 1, PCF5 = 2, PCF13 = 3
  switch (filter) {
    case 0: return 256;
    case 1: return 512;
    case 2: return 1024;
    case 3: return 2048;
    default: return 512; // Default to PCF3 equivalent
  }
}
```
