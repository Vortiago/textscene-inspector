# WI-52: External Texture Loading

## Overview
Implement loading and application of external texture resources referenced in TSCN files. This enables materials to use external image files (PNG, JPG, SVG) for albedo, normal, metallic, roughness, and other texture maps - a fundamental feature for realistic 3D rendering.

## Current State

**What Exists:**
- ✅ `ResourceRegistry` parses and registers `[ext_resource type="Texture2D"]` headings
- ✅ `ResourceProvider` interface supports loading binary resources (returns `ArrayBuffer`)
- ✅ Infrastructure for resource path resolution and caching

**What's Missing:**
- ❌ No actual texture loading implementation
- ❌ No texture application to StandardMaterial3D
- ❌ No THREE.js Texture creation from loaded data
- ❌ External textures are registered but never loaded or displayed

**Evidence:**
```typescript
// scenes/fixtures/unit-external-texture.tscn
[ext_resource type="Texture2D" path="res://textures/test_texture.png" id="1_texture"]

// This is parsed and registered, but the texture is NEVER loaded or applied
```

## Implementation Requirements

### 1. Texture Loading in ResourceRegistry

Extend `ResourceRegistry` to load textures as THREE.js `Texture` objects:

```typescript
// packages/textscene-core/src/resources/ResourceRegistry.ts

/**
 * Load texture resource and return THREE.js Texture
 */
async loadTexture(idOrPath: string): Promise<THREE.Texture> {
  // 1. Get resource metadata
  const resource = this.getMetadata(idOrPath);
  if (!resource || !resource.type.includes('Texture')) {
    throw new Error(`Not a texture resource: ${idOrPath}`);
  }

  // 2. Load raw content via provider (returns ArrayBuffer)
  const content = await this.loadByPath(resource.path);
  if (!(content instanceof ArrayBuffer)) {
    throw new Error(`Texture must be binary data: ${resource.path}`);
  }

  // 3. Convert ArrayBuffer to Blob
  const blob = new Blob([content], { type: this.getMimeType(resource.path) });
  const blobUrl = URL.createObjectURL(blob);

  // 4. Load with THREE.js TextureLoader
  const loader = new THREE.TextureLoader();
  return new Promise((resolve, reject) => {
    loader.load(
      blobUrl,
      (texture) => {
        texture.colorSpace = THREE.SRGBColorSpace;
        URL.revokeObjectURL(blobUrl); // Clean up
        resolve(texture);
      },
      undefined,
      (error) => {
        URL.revokeObjectURL(blobUrl);
        reject(new Error(`Failed to load texture: ${resource.path}`));
      }
    );
  });
}

/**
 * Get MIME type from file extension
 */
private getMimeType(path: string): string {
  const ext = path.split('.').pop()?.toLowerCase();
  switch (ext) {
    case 'png': return 'image/png';
    case 'jpg':
    case 'jpeg': return 'image/jpeg';
    case 'svg': return 'image/svg+xml';
    case 'webp': return 'image/webp';
    default: return 'application/octet-stream';
  }
}
```

### 2. Update StandardMaterial3D Parser

Detect and load external texture references:

```typescript
// packages/textscene-core/src/resources/materials/standardmaterial3d/parser.ts

export async function parseStandardMaterial3D(
  data: Record<string, unknown>,
  registry?: ResourceRegistry
): Promise<StandardMaterial3DProperties> {
  const props: StandardMaterial3DProperties = {
    // ... existing properties
  };

  // Check for external texture references
  if (registry) {
    // Albedo texture
    const albedoTexRef = ResourceRegistry.parseReference(data.albedo_texture as string);
    if (albedoTexRef) {
      props.albedoTexture = await registry.loadTexture(albedoTexRef);
    }

    // Normal map
    const normalTexRef = ResourceRegistry.parseReference(data.normal_texture as string);
    if (normalTexRef) {
      props.normalTexture = await registry.loadTexture(normalTexRef);
    }

    // Metallic texture
    const metallicTexRef = ResourceRegistry.parseReference(data.metallic_texture as string);
    if (metallicTexRef) {
      props.metallicTexture = await registry.loadTexture(metallicTexRef);
    }

    // Roughness texture
    const roughnessTexRef = ResourceRegistry.parseReference(data.roughness_texture as string);
    if (roughnessTexRef) {
      props.roughnessTexture = await registry.loadTexture(roughnessTexRef);
    }
  }

  return props;
}
```

### 4. Update StandardMaterial3D Renderer

Apply loaded textures to THREE.js material:

```typescript
// packages/textscene-core/src/resources/materials/standardmaterial3d/renderer.ts

export function createStandardMaterial(
  props: StandardMaterial3DProperties
): THREE.MeshStandardMaterial {
  const material = new THREE.MeshStandardMaterial({
    color: props.albedoColor,
    metalness: props.metallic,
    roughness: props.roughness,
    // ... existing properties
  });

  // Apply textures if present
  if (props.albedoTexture) {
    material.map = props.albedoTexture;
  }

  if (props.normalTexture) {
    material.normalMap = props.normalTexture;
  }

  if (props.metallicTexture) {
    material.metalnessMap = props.metallicTexture;
  }

  if (props.roughnessTexture) {
    material.roughnessMap = props.roughnessTexture;
  }

  if (props.aoTexture) {
    material.aoMap = props.aoTexture;
  }

  if (props.emissionTexture) {
    material.emissiveMap = props.emissionTexture;
  }

  return material;
}
```

### 5. Godot Texture Property Reference

From Godot documentation, StandardMaterial3D supports these texture properties:

| Godot Property | THREE.js Equivalent | Description |
|----------------|---------------------|-------------|
| `albedo_texture` | `map` | Base color/diffuse texture |
| `normal_texture` | `normalMap` | Surface normal details |
| `metallic_texture` | `metalnessMap` | Metallic surface areas |
| `roughness_texture` | `roughnessMap` | Surface roughness |
| `ao_texture` | `aoMap` | Ambient occlusion |
| `emission_texture` | `emissiveMap` | Light emission areas |
| `height_texture` | `displacementMap` | Height/displacement |

## Architecture Considerations

### Async Material Parsing

Texture loading is async, which impacts material resolution:

```typescript
// Current (synchronous)
const material = resolveMaterial(ref, scene);

// New (asynchronous)
const material = await resolveMaterial(ref, scene);
```

This requires updating all callers to handle promises.

### Texture Caching Strategy

**Option 1: Cache at ResourceRegistry level** (Recommended)
- Cache THREE.Texture objects
- Share textures across multiple materials
- Automatic cleanup when registry is cleared

**Option 2: Cache at THREE.js level**
- Use THREE.TextureLoader cache
- Less control over lifecycle
- May leak textures

**Decision: Use ResourceRegistry caching with separate texture cache:**

```typescript
private textureCache: Map<string, THREE.Texture> = new Map();
```

### Error Handling

When texture loading fails:
1. Log warning with texture path
2. Return default white/gray texture
3. Continue rendering with fallback
4. Optionally call `onResourceNeeded` callback

### Performance Considerations

- **Lazy loading**: Load textures only when materials are rendered
- **Preloading**: Option to preload all textures upfront
- **Texture compression**: Support for compressed texture formats (.ctex)
- **Mipmaps**: Generate mipmaps for better quality
