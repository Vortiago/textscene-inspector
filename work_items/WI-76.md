# WI-76: Event-Based Resource Loading System

**Status**: Not Started
**Priority**: High
**Impact**: Architectural improvement for stability, extensibility, and graceful degradation during missing resource scenarios

## Overview

### Problem Statement

The current **promise-based resource loading** creates blocking behavior with challenging user experience scenarios:

**Current Flow:**
```typescript
// Material parser BLOCKS waiting for all textures
const albedoTexture = await registry.loadTexture(albedoRef);  // WAIT
const normalTexture = await registry.loadTexture(normalRef);  // WAIT
// ... 4 more sequential waits

// Mesh renderer BLOCKS waiting for material
const material = await registry.loadMaterial(materialRef);    // WAIT
mesh.material = material;  // Only now does user see the mesh
```

**Pain Points:**

1. **Missing Resource Scenario** (Web App):
   - User loads scene
   - Scene references external texture (not yet uploaded)
   - Promise created: `loadTexture('res://wall.png')`
   - **Promise hangs indefinitely** waiting for user upload
   - Mesh never renders (blocked on missing texture)
   - User sees nothing (no visual feedback)
   - Could be **minutes** before user notices and uploads file

2. **Sequential Loading** (Performance):
   - Materials with 6 textures: 300ms (6 × 50ms sequential)
   - Could be 50ms if parallel (6 × 50ms concurrent)
   - **6x slower than necessary**

3. **Deep Promise Chains** (Maintainability):
   - 4-5 levels of nested async calls
   - Error handling complex (try-catch at multiple levels)
   - Hard to add progress tracking or cancellation

4. **Hot-Reload Cascades** (Fragility):
   - Manual cache invalidation required
   - Easy to miss invalidation steps (texture → material → mesh)
   - Bugs from incomplete updates

### Solution: Event-Based Architecture

**Event-Driven Flow:**
```typescript
// Material parser REQUESTS textures (non-blocking)
registry.request('texture', albedoRef);   // Request, don't wait
registry.request('texture', normalRef);   // All 6 in parallel

// Material created immediately with placeholders
const material = createPlaceholderMaterial();

// Listen for texture events
eventBus.on('texture:loaded', (id, texture) => {
  if (id === albedoRef) material.map = texture;
  material.needsUpdate = true;
});

// Mesh renders IMMEDIATELY with placeholder material
mesh.material = material;
return mesh;  // User sees mesh right away
```

**Benefits:**

✅ **Graceful Degradation**: Mesh renders immediately with placeholder, updates when resources arrive
✅ **Parallel Loading**: All textures load concurrently (6x faster)
✅ **Progress Tracking**: Can emit progress events for loading indicators
✅ **Cancellation**: Can cancel superseded operations
✅ **Decoupled**: Multiple consumers can react to same resource load
✅ **Hot-Reload**: Invalidation events cascade automatically

### Scope

**Resources Covered:**
- Textures (PNG, SVG, WebP, etc.)
- Materials (StandardMaterial3D, ORMMaterial3D)
- External Scenes (PackedScene .tscn files)

**Future Extensions:**
- Audio files (AudioStreamPlayer)
- Custom mesh files
- Script resources

## Architecture

### Custom ResourceEventBus (No External Dependencies)

**Why custom implementation:**
- Simple use case (~100 lines of code)
- Full understanding and control
- No external maintenance burden
- Follows KISS principle
- Type-safe with TypeScript generics

**Core API:**
```typescript
class ResourceEventBus {
  // Subscribe to events
  on<T>(resourceType: string, eventType: string, handler: (id: string, data: T) => void): void;

  // Unsubscribe
  off(resourceType: string, eventType: string, handler: Function): void;

  // Emit events
  emit<T>(resourceType: string, eventType: string, id: string, data?: T): void;

  // Promise wrapper for backward compatibility
  once<T>(resourceType: string, eventType: string, id: string): Promise<T>;
}
```

**Event Types:**
- `requested` - Resource load initiated
- `loading` - Resource loading in progress
- `progress` - Loading progress update (optional)
- `loaded` - Resource successfully loaded
- `failed` - Resource failed to load

**Event Naming Convention:**
```
${resourceType}:${eventType}
Examples:
  texture:requested
  texture:loaded
  material:failed
  scene:loading
```

### Loader Architecture

**Pattern: Separate Loaders + Shared Event Bus**

```
ResourceRegistry (coordinator)
  ↓
  ├─ ResourceEventBus (shared)
  ├─ TextureLoader (uses bus)
  ├─ MaterialLoader (uses bus + TextureLoader)
  └─ SceneLoader (uses bus)
```

**TextureLoader:**
- Loads texture files (PNG, SVG, WebP)
- Wraps THREE.TextureLoader
- Emits texture events
- Deduplication (same texture requested twice = load once)
- Caching

**MaterialLoader:**
- Parses material properties
- Requests textures via TextureLoader (6 in parallel)
- Listens for texture:loaded events
- Emits material events as textures arrive
- Returns material immediately with placeholders

**SceneLoader:**
- Loads external .tscn files
- Handles nested scenes (scene references another scene)
- Emits scene events
- Deduplication and caching

### Step 2: TextureLoader - Event-Based, Promise-Compatible

**Goal**: Replace direct THREE.TextureLoader calls with event-based loader, keep existing API working.

**Implementation:**

1. Create `packages/textscene-core/src/resources/loaders/TextureLoader.ts`
2. Event-based texture loading:
   - Request texture → emit `texture:requested`
   - Load with THREE.TextureLoader → emit `texture:loading`
   - Success → emit `texture:loaded`
   - Error → emit `texture:failed`
3. Deduplication (multiple requests for same texture = single load)
4. Caching
5. Update `ResourceRegistry.loadTexture()` to use TextureLoader internally
6. Keep promise API (use `eventBus.once()`)

**Code Structure:**
```typescript
export class TextureLoader {
  private cache = new Map<string, THREE.Texture | null>();
  private inflight = new Map<string, boolean>();

  constructor(
    private eventBus: ResourceEventBus,
    private resourceProvider: ResourceProvider
  ) {}

  request(id: string): void {
    if (this.cache.has(id)) {
      this.eventBus.emit('texture', 'loaded', id, this.cache.get(id));
      return;
    }

    if (this.inflight.has(id)) {
      return; // Already loading
    }

    this.eventBus.emit('texture', 'requested', id);
    this.loadAsync(id);
  }

  private async loadAsync(id: string): Promise<void> {
    this.inflight.set(id, true);
    this.eventBus.emit('texture', 'loading', id);

    try {
      const texture = await this.loadTextureFromProvider(id);
      this.cache.set(id, texture);
      this.eventBus.emit('texture', 'loaded', id, texture);
    } catch (error) {
      this.eventBus.emit('texture', 'failed', id, error);
      this.cache.set(id, null);
    } finally {
      this.inflight.delete(id);
    }
  }
}
```

**Integration with ResourceRegistry:**
```typescript
export class ResourceRegistry {
  private textureLoader: TextureLoader;
  private eventBus: ResourceEventBus;

  constructor(/* ... */) {
    this.eventBus = new ResourceEventBus();
    this.textureLoader = new TextureLoader(this.eventBus, this.resourceProvider);
  }

  // Backward-compatible promise API
  async loadTexture(id: string): Promise<THREE.Texture | null> {
    this.textureLoader.request(id);
    return this.eventBus.once<THREE.Texture>('texture', 'loaded', id);
  }

  // New event API
  getEventBus(): ResourceEventBus {
    return this.eventBus;
  }
}
```

### Step 4: MaterialLoader - Event-Based

**Goal**: Materials emit events as textures load progressively.

**Implementation:**

1. Create `packages/textscene-core/src/resources/loaders/MaterialLoader.ts`
2. Material loading flow:
   - Parse material properties
   - Request all textures via TextureLoader (parallel)
   - Emit `material:loading` (waiting for textures)
   - Listen for `texture:loaded` events
   - Update material as each texture arrives
   - Emit `material:loaded` when all textures ready
3. Handles all material types (StandardMaterial3D, ORMMaterial3D)

**Progressive Material Updates:**
```typescript
export class MaterialLoader {
  request(id: string): void {
    const properties = this.parseMaterialProperties(id);
    this.eventBus.emit('material', 'requested', id);

    // Create material with placeholders
    const material = this.createMaterialWithPlaceholders(properties);

    // Request all textures in parallel
    const textureIds = this.extractTextureIds(properties);
    textureIds.forEach(texId => this.textureLoader.request(texId));

    this.eventBus.emit('material', 'loading', id, material);

    // Listen for textures
    const loaded = new Set<string>();
    this.eventBus.on('texture', 'loaded', (texId, texture) => {
      if (textureIds.includes(texId)) {
        this.applyTexture(material, texId, texture);
        loaded.add(texId);

        if (loaded.size === textureIds.length) {
          this.eventBus.emit('material', 'loaded', id, material);
        }
      }
    });
  }
}
```

**Graceful Degradation (Missing Textures):**
```typescript
// If texture fails, material still emits 'loaded' (with placeholder)
this.eventBus.on('texture', 'failed', (texId, error) => {
  if (textureIds.includes(texId)) {
    loaded.add(texId); // Count as "done" even if failed

    if (loaded.size === textureIds.length) {
      this.eventBus.emit('material', 'loaded', id, material);
    }
  }
});
```

**New (Progressive):**
```typescript
export function createMeshInstance3D(/* ... */): THREE.Mesh {
  const geometry = resolveGeometrySync(properties.mesh, scene);

  // Create mesh with placeholder material immediately
  const placeholderMaterial = new THREE.MeshStandardMaterial({ color: 0x808080 });
  const mesh = new THREE.Mesh(geometry, placeholderMaterial);

  // Request real material (non-blocking)
  const materialRef = properties.materialOverride || getMeshMaterialRef(properties.mesh);
  if (materialRef && scene?.resourceRegistry) {
    const eventBus = scene.resourceRegistry.getEventBus();

    eventBus.on('material', 'loaded', (id, material) => {
      if (id === materialRef) {
        mesh.material = material;
        mesh.material.needsUpdate = true;
      }
    });

    scene.resourceRegistry.requestMaterial(materialRef);
  }

  return mesh;  // Returns immediately
}
```

**Goal**: External scenes load with events, handle nested scenes.

**Implementation:**

2. Event-based scene loading:

   - Parse scene → emit `scene:loading`
   - Success → emit `scene:loaded`
   - Error → emit `scene:failed`
3. Handle nested scenes (scene references another scene)

**Nested Scene Handling:**
```typescript
export class SceneLoader {
  request(id: string): void {
    if (this.cache.has(id)) {
      this.eventBus.emit('scene', 'loaded', id, this.cache.get(id));
      return;
    }

    this.eventBus.emit('scene', 'requested', id);
    this.loadAsync(id);
  }

  private async loadAsync(id: string): Promise<void> {
    this.eventBus.emit('scene', 'loading', id);

    try {
      const content = await this.resourceProvider.loadFile(id);
      const scene = TscnParser.parse(content);

      // Check for nested external scenes
      const nestedScenes = this.extractNestedScenePaths(scene);
      nestedScenes.forEach(nestedId => this.request(nestedId));

      this.cache.set(id, scene);
      this.eventBus.emit('scene', 'loaded', id, scene);
    } catch (error) {
      this.eventBus.emit('scene', 'failed', id, error);
    }
  }
}
```

### Step 7: ResourceRecoveryManager - Event Integration

**Goal**: User uploads missing resource → events trigger automatic updates.

**Current (Callback-Based):**
```typescript
// Callback when resource needed
registry.setOnResourceNeeded(async (resource) => {
  // User uploads file
  const content = await userUploadDialog(resource.path);
  registry.provideResource(resource.path, content);

  // Manually clear caches and re-render
  registry.clearTextureCache(resource.path);
  registry.clearMaterialCache();
  // ... manual cascade
});
```

**New (Event-Based):**
```typescript
export class ResourceRecoveryManager {
  constructor(private eventBus: ResourceEventBus) {
    // Listen for failed resources
    this.eventBus.on('texture', 'failed', (id, error) => {
      this.recordMissing({ type: 'texture', id, error });
    });

    this.eventBus.on('material', 'failed', (id, error) => {
      this.recordMissing({ type: 'material', id, error });
    });
  }

  // User provides missing resource
  async provideResource(id: string, content: ArrayBuffer): Promise<void> {
    // Store in registry
    this.registry.provideResource(id, content);

    // Emit 'provided' event
    this.eventBus.emit('resource', 'provided', id, content);

    // Loaders listen and auto-retry
    // TextureLoader: texture:provided → reload texture → emit texture:loaded
    // MaterialLoader: hears texture:loaded → updates material → emit material:loaded
    // MeshRenderer: hears material:loaded → updates mesh
    // Auto-cascade!
  }
}
```

**Auto-Retry on Provided:**
```typescript
// TextureLoader listens for 'provided' events
this.eventBus.on('resource', 'provided', (id) => {
  if (this.cache.has(id) && this.cache.get(id) === null) {
    // Previous load failed, retry now
    this.cache.delete(id);
    this.request(id);
  }
});
```

### Custom ResourceEventBus Implementation

```typescript
/**
 * Custom event bus for resource loading events.
 * Provides type-safe event emission and subscription.
 */
export class ResourceEventBus {
  private handlers = new Map<string, Set<EventHandler>>();
  private threeManager = new THREE.LoadingManager();

  constructor() {
    // Integrate with THREE.LoadingManager for automatic progress
    this.threeManager.onProgress = (url, loaded, total) => {
      this.emit('texture', 'progress', url, { loaded, total });
    };
  }

  /**
   * Subscribe to resource events
   */
  on<T = unknown>(
    resourceType: string,
    eventType: string,
    handler: EventHandler<T>
  ): void {
    const key = `${resourceType}:${eventType}`;
    if (!this.handlers.has(key)) {
      this.handlers.set(key, new Set());
    }
    this.handlers.get(key)!.add(handler as EventHandler);
  }

  /**
   * Unsubscribe from resource events
   */
  off(
    resourceType: string,
    eventType: string,
    handler: EventHandler
  ): void {
    const key = `${resourceType}:${eventType}`;
    this.handlers.get(key)?.delete(handler);
  }

  /**
   * Emit resource event to all subscribers
   */
  emit<T = unknown>(
    resourceType: string,
    eventType: string,
    id: string,
    data?: T
  ): void {
    const key = `${resourceType}:${eventType}`;
    const handlers = this.handlers.get(key);
    if (handlers) {
      handlers.forEach(handler => handler(id, data));
    }
  }

  /**
   * Promise wrapper for one-time event subscription
   * Used for backward-compatible promise API
   */
  once<T = unknown>(
    resourceType: string,
    eventType: string,
    id: string
  ): Promise<T> {
    return new Promise((resolve, reject) => {
      const loadedHandler = (eventId: string, data: T) => {
        if (eventId === id) {
          this.off(resourceType, eventType, loadedHandler);
          this.off(resourceType, 'failed', failedHandler);
          resolve(data);
        }
      };

      const failedHandler = (eventId: string, error: Error) => {
        if (eventId === id) {
          this.off(resourceType, eventType, loadedHandler);
          this.off(resourceType, 'failed', failedHandler);
          reject(error);
        }
      };

      this.on(resourceType, eventType, loadedHandler);
      this.on(resourceType, 'failed', failedHandler);
    });
  }

  /**
   * Get THREE.js LoadingManager for integration
   */
  getThreeManager(): THREE.LoadingManager {
    return this.threeManager;
  }

  /**
   * Get handler count for memory leak testing
   */
  getHandlerCount(resourceType: string, eventType: string): number {
    const key = `${resourceType}:${eventType}`;
    return this.handlers.get(key)?.size || 0;
  }

  /**
   * Clear all handlers (for cleanup)
   */
  clear(): void {
    this.handlers.clear();
  }
}

type EventHandler<T = unknown> = (id: string, data?: T) => void;
```

```typescript
export class ResourceRegistry {
  private eventBus = new ResourceEventBus();
  private textureLoader: TextureLoader;

  constructor(private resourceProvider: ResourceProvider) {
    this.textureLoader = new TextureLoader(this.eventBus, resourceProvider);
  }

  /**
   * Load texture (promise API for backward compatibility)
   */
  async loadTexture(id: string): Promise<THREE.Texture | null> {
    this.textureLoader.request(id);
    try {
      return await this.eventBus.once<THREE.Texture>('texture', 'loaded', id);
    } catch (error) {
      // Failed to load, return null (matches old behavior)
      return null;
    }
  }

  /**
   * Request texture (non-blocking, event-based API)
   */
  requestTexture(id: string): void {
    this.textureLoader.request(id);
  }

  /**
   * Get event bus for direct event subscription
   */
  getEventBus(): ResourceEventBus {
    return this.eventBus;
  }
}
```

```typescript
export async function parseStandardMaterial3D(
  properties: Record<string, string>,
  registry?: ResourceRegistry
): Promise<StandardMaterial3DProperties> {
  const result: StandardMaterial3DProperties = { /* ... */ };

  if (!registry) {
    return result;
  }

  const eventBus = registry.getEventBus();
  const texturePromises: Promise<void>[] = [];

  // Request all textures in parallel
  if (properties.albedo_texture) {
    const texRef = properties.albedo_texture;
    registry.requestTexture(texRef);
    texturePromises.push(
      eventBus.once<THREE.Texture>('texture', 'loaded', texRef)
        .then(tex => { result.albedoTexture = tex; })
        .catch(() => { /* gracefully handle missing */ })
    );
  }

  if (properties.normal_texture && properties.normal_enabled === 'true') {
    const texRef = properties.normal_texture;

        .catch(() => { /* gracefully handle missing */ })
    );
  }

  // ... repeat for all 6 textures

  // Wait for all textures to load (or fail)
  await Promise.allSettled(texturePromises);

  return result;
```

### Progressive Rendering with Placeholders

```typescript
/**
 * Render mesh immediately with placeholder material
 * Update when real material loads
 */
export function createMeshInstance3D(
  nodeName: string,
  properties: MeshInstance3DProperties,
  scene?: TscnScene
): THREE.Mesh {
  const geometry = resolveGeometrySync(properties.mesh, scene);

  // Create mesh with placeholder material (immediate render)
  const placeholderMaterial = new THREE.MeshStandardMaterial({
    color: 0x808080,
    name: `${nodeName}_placeholder`
  });

  const mesh = new THREE.Mesh(geometry, placeholderMaterial);
  mesh.name = nodeName;

  // Request real material (non-blocking)
  if (properties.materialOverride && scene?.resourceRegistry) {
    const materialRef = properties.materialOverride;
    const eventBus = scene.resourceRegistry.getEventBus();

    // One-time listener (cleans up after first load)
    const handler = (id: string, material: THREE.Material) => {
      if (id === materialRef) {
        mesh.material.dispose(); // Clean up placeholder
        mesh.material = material;
        mesh.material.needsUpdate = true;
        eventBus.off('material', 'loaded', handler); // Clean up listener
      }
    };

    eventBus.on('material', 'loaded', handler);
    scene.resourceRegistry.requestMaterial(materialRef);
  }

  return mesh; // Returns immediately
}
```

### Event Handler Cleanup Pattern

```typescript
/**
 * Proper event handler cleanup to prevent memory leaks
 */
export class MeshRenderer {
  private cleanupHandlers = new Map<string, () => void>();

  createMesh(nodeName: string, properties: MeshProperties): THREE.Mesh {
    const mesh = new THREE.Mesh(/* ... */);

    if (properties.materialRef) {
      const eventBus = this.registry.getEventBus();

      // Store cleanup function
      const cleanup = () => {
        eventBus.off('material', 'loaded', handler);
        eventBus.off('material', 'failed', failedHandler);
      };

      const handler = (id: string, material: THREE.Material) => {
        if (id === properties.materialRef) {
          mesh.material = material;
          cleanup();
          this.cleanupHandlers.delete(nodeName);
        }
      };

      const failedHandler = (id: string, error: Error) => {
        if (id === properties.materialRef) {
          console.warn(`Material failed to load: ${id}`, error);
          cleanup();
          this.cleanupHandlers.delete(nodeName);
        }
      };

      eventBus.on('material', 'loaded', handler);
      eventBus.on('material', 'failed', failedHandler);

      this.cleanupHandlers.set(nodeName, cleanup);
    }

    return mesh;
  }

  /**
   * Clean up all event handlers when renderer destroyed
   */
  dispose(): void {
    this.cleanupHandlers.forEach(cleanup => cleanup());
    this.cleanupHandlers.clear();
  }
}
```
