# WI-76: Ambient Occlusion Enable Flag (StandardMaterial3D)

**Status**: Complete
**Priority**: High
**Complexity**: Simple
**Impact**: Completes high-priority texture enable flag pattern

## Overview

### Problem Statement

Ambient occlusion textures are currently applied **unconditionally** when present, violating Godot's feature flag pattern:

- ✅ `normal_enabled` flag correctly controls normal map application (WI-59)
- ✅ `emission_enabled` flag controls emission map application (WI-62)
- ❌ `ao_enabled` flag is **NOT parsed or checked** in renderer
- ❌ AO texture applied even when `ao_enabled = false`

**Current Behavior**:
```typescript
// renderer.ts:54-56 - WRONG: No flag check
if (properties.ao_texture) {
  materialOptions.aoMap = properties.ao_texture;  // Applied unconditionally!
}
```

**Expected Behavior**:
```typescript
// Should check both flag and texture
if (properties.ao_enabled && properties.ao_texture) {
  materialOptions.aoMap = properties.ao_texture;
}
```

### Godot Feature System

From `godot/scene/resources/material.h`:
```cpp
FEATURE_AMBIENT_OCCLUSION  // Maps to ao_enabled in TSCN
```

**TSCN Format**:
```tscn
[sub_resource type="StandardMaterial3D" id="Material_1"]
albedo_color = Color(1, 1, 1, 1)
ao_enabled = true              # ← Feature flag
ao_texture = ExtResource("1")  # ← Texture reference
ao_light_affect = 0.5          # ← Additional property
ao_texture_channel = 0         # ← Channel selection
```

```typescript
describe('Parser - ao_enabled flag', () => {
  it('should parse ao_enabled as true from string "true"', async () => {
    const properties = { ao_enabled: 'true' };
    const result = await parseStandardMaterial3D(properties);
    expect(result.ao_enabled).toBe(true);
  });

  it('should parse ao_enabled as false from string "false"', async () => {
    const properties = { ao_enabled: 'false' };
    const result = await parseStandardMaterial3D(properties);
    expect(result.ao_enabled).toBe(false);
  });

  it('should parse ao_enabled as false for any non-"true" value', async () => {
    const properties = { ao_enabled: 'invalid' };
    const result = await parseStandardMaterial3D(properties);
    expect(result.ao_enabled).toBe(false);
  });

  it('should leave ao_enabled undefined when not specified', async () => {
    const properties = {};
    const result = await parseStandardMaterial3D(properties);
    expect(result.ao_enabled).toBeUndefined();
  });

  it('should parse ao_enabled independently of ao_texture', async () => {
    const properties = {
      ao_enabled: 'true',
      ao_texture: 'ExtResource("1")'
    };
    const result = await parseStandardMaterial3D(properties);
    expect(result.ao_enabled).toBe(true);
  });

  it('should handle ao_enabled=true without texture', async () => {
    const properties = { ao_enabled: 'true' };
    const result = await parseStandardMaterial3D(properties);
    expect(result.ao_enabled).toBe(true);
    expect(result.ao_texture).toBeUndefined();
  });

  it('should handle ao_enabled=false with texture present', async () => {
    const properties = {
      ao_enabled: 'false',
      ao_texture: 'ExtResource("1")'
    };
    const result = await parseStandardMaterial3D(properties);
    expect(result.ao_enabled).toBe(false);
  });
});
```
