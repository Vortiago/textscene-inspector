# WI-66: Clearcoat Enable Flag (StandardMaterial3D)

**Status**: Not Started
**Priority**: Medium
**Complexity**: Simple
**Impact**: Glossy finish layer for car paint, plastic materials

## Overview

### Problem Statement

Clearcoat adds a secondary transparent layer over the base material, simulating glossy finishes like car paint or varnished wood. Godot's `FEATURE_CLEARCOAT` requires an enable flag.

**Godot Feature**: `FEATURE_CLEARCOAT` → `clearcoat_enabled` in TSCN

**TSCN Format**:
```tscn
[sub_resource type="StandardMaterial3D" id="Material_1"]
albedo_color = Color(0.8, 0.1, 0.1, 1)
clearcoat_enabled = true
clearcoat = 1.0
clearcoat_roughness = 0.1
clearcoat_texture = ExtResource("1_clearcoat")
```

### Three.js Support

Three.js `MeshStandardMaterial` has **native clearcoat support**:
- `clearcoat` - Clearcoat strength (0-1)
- `clearcoatMap` - Clearcoat texture
- `clearcoatRoughness` - Clearcoat layer roughness (0-1)
- `clearcoatRoughnessMap` - Clearcoat roughness texture
- `clearcoatNormalMap` - Clearcoat layer normal map

**Implementation Complexity**: ✅ Direct mapping (simple)

## Implementation Plan

### 1. Update Types

```typescript
export interface StandardMaterial3DProperties {
  // Feature enable flags
  clearcoat_enabled?: boolean;  // ADD

  // Texture maps
  clearcoat_texture?: THREE.Texture;  // ADD

  // Clearcoat properties
  clearcoat?: number;  // Strength (0-1), default 1.0
  clearcoat_roughness?: number;  // Roughness (0-1), default 0.5
}
```

### 2. Update Parser

```typescript
if (properties.clearcoat_enabled !== undefined) {
  result.clearcoat_enabled = properties.clearcoat_enabled === 'true';
}

// Parse clearcoat strength
if (properties.clearcoat !== undefined) {
  const clearcoat = parseFloat(properties.clearcoat);
  if (!isNaN(clearcoat)) {
    result.clearcoat = clearcoat;
  }
}

// Parse clearcoat roughness
if (properties.clearcoat_roughness !== undefined) {
  const roughness = parseFloat(properties.clearcoat_roughness);
  if (!isNaN(roughness)) {
    result.clearcoat_roughness = roughness;
  }
}

// Parse clearcoat texture
if (registry && properties.clearcoat_texture) {
  const clearcoatTexRef = ResourceRegistry.parseReference(properties.clearcoat_texture);
  if (clearcoatTexRef) {
    const texture = await registry.loadTexture(clearcoatTexRef);
    if (texture) {
      result.clearcoat_texture = texture;
    }
  }
}
```

### 3. Update Renderer

```typescript
if (properties.clearcoat_enabled) {
  // Apply clearcoat strength (default 1.0 in Godot)
  if (properties.clearcoat !== undefined) {
    materialOptions.clearcoat = properties.clearcoat;
  } else {
    materialOptions.clearcoat = 1.0;  // Godot default
  }

  // Apply clearcoat roughness (default 0.5 in Godot)
  if (properties.clearcoat_roughness !== undefined) {
    materialOptions.clearcoatRoughness = properties.clearcoat_roughness;
  } else {
    materialOptions.clearcoatRoughness = 0.5;  // Godot default
  }

  // Apply clearcoat texture if present
  if (properties.clearcoat_texture) {
    materialOptions.clearcoatMap = properties.clearcoat_texture;
  }
}
```
