# Code of conduct

This code applies to every issue, pull request, discussion and review.

## Expected behaviour

- Be respectful.
- Assume good intent.
- Criticise the work, not the person.
- Accept a decision you disagree with, and give your reason once.

## Not accepted

- Harassment, insults or threats.
- Comments about a person's identity, appearance or background.
- Publishing another person's private information.

## Enforcement

The maintainer can edit or remove a comment, lock a thread, or block a person who breaks
this code.

## Report a breach

To report an issue, a pull request or a comment to the maintainer:

1. Open its `...` menu.
2. Select **Report content**.
3. Select **Report to repository admins**.

Only the maintainer sees the report. To report anything else, use GitHub's
[abuse report form](https://github.com/contact/report-abuse).
