# WI-15: Implement Camera3D Node

**Phase**: 4 - Advanced Features
**Priority**: Medium
**Status**: Not Started
**Type**: Feature

## Summary

Implement Camera3D node parser and renderer for photo frame cameras in scenes.

## Implementation Details

- Create parser and renderer in `packages/textscene-renderer/src/nodes/camera3d/`
- Parse FOV, near/far planes, projection type
- Generate THREE.PerspectiveCamera
- Handle orthographic vs perspective projection
- Support camera transform (position, rotation)

## Frequency Analysis

10+ instances in test scenes (photo frame cameras).

## Implementation Steps

1. Create `packages/textscene-renderer/src/nodes/camera3d/parser.ts`
2. Create `packages/textscene-renderer/src/nodes/camera3d/renderer.ts`
3. Create `packages/textscene-renderer/src/nodes/camera3d/index.ts`
4. Add tests in `camera3d.test.ts`
5. Register with NodeRegistry
6. Import in TscnParser.ts

## Testing Notes

- Test orthographic camera
